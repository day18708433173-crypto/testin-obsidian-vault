# 功能总览

> 本页是 web/pc处理服务（real-web）功能维度的总索引：每个模块一句话定位 + 核心能力清单 + 深入阅读链接。代码级细节见 [03-Web任务执行链路实现](../03-实现逻辑/Web任务执行链路实现.md) 与 [04-专题索引](../04-复杂功能细节/专题-索引.md)。

## 功能地图

```
web/pc处理服务
├── 任务管理
│   ├── 任务创建/取消/批量取消   → ApiServlet action=task, op=Task.*
│   ├── 暂停/恢复/继续执行       → Task.pause / Task.resume / Task.execute
│   ├── 批量补测                 → Task.repeatTest
│   ├── 任务详情/运行信息查询    → Task.detail / scriptRunInfos / browserRunInfos / clientRunInfos
│   └── 任务修改/忽略/回调通知   → Task.modify / ignore / sendEmail
├── 任务模板与定时调度
│   ├── 模板 CRUD/复制/内容更新  → TestTemplateController（/v3/realweb/template/*）
│   ├── Quartz 定时注册与执行    → WebQuartz / McPcQuartz / AppQuartz
│   └── 执行日志                 → quartz_job_log + QuartzLogController
├── 报告
│   ├── 报告查询/列表/汇总       → ReportController（/v3/report/*）
│   ├── Excel 报告导出           → ApiServlet action=report, op=Excel.reportExcel
│   ├── PDF 报告                 → ApiServlet action=report, op=Pdf.parse
│   └── 测试计划报告/计划发送    → TestPlanController / TaskController
├── 问题分析
│   ├── 失败脚本列表/错误步骤    → ProblemAnalysisReportController
│   ├── 错误原因规则匹配         → ReportServiceImpl + ErrorCauseTypeV3Api（平台配置）
│   └── 错误原因人工修正         → ReportController.modify_error_cause_type
└── 基础设施
    ├── 心跳检测（Mongo/Redis/MySQL）→ HeartBeatController
    └── 外部服务代理（~40+ ApiServlet 类）→ 脚本服务/数据源/平台配置 等
```

## 任务管理

> 界面入口：[Web 任务管理页](任务管理.md) `/platform/executeManager/auto/web` 或 [桌面任务管理页](任务管理.md) `/platform/executeManager/auto/desktop`。

任务的完整生命周期在本服务内闭环：创建（`Task.create`，`src/main/java/cn/testin/realweb/service/task/Task.java`）→ 装配 → 下发 任务调度服务 → 过程/结果上报 → 完成通知。支持取消（`Task.cancel`）、批量取消、暂停/恢复（`TaskServiceImpl.pause`/`resume`，`src/main/java/cn/testin/realweb/business/impl/TaskServiceImpl.java`）、继续执行（`execute`，仅测试计划渠道重发 TASK_ASSEMBLY）、批量补测（`Task.repeatTest`，`Task.java`）。

## 任务模板与定时调度

> 界面入口：[任务管理页](任务管理.md)的定时任务模版管理。

模板存 MySQL `db_common.quartz_job`，经 `TestTemplateController` 维护；`QuartzJobServiceImpl` 把模板注册进内嵌 Quartz（`SchedulerManager` 单例），触发后由 `WebQuartz`/`McPcQuartz`/`AppQuartz` 分别发起 Web/PC/App 提测；每次执行写 `quartz_job_log`。详见 [核心链路-定时任务执行](../04-复杂功能细节/核心链路-定时任务执行.md) 与 [端到端-定时任务](../../跨模块链路/端到端-定时任务.md)。

## 报告

> 界面入口：[任务管理页](任务管理.md)执行记录详情的报告查看与导出，详见 [报告概述](报告概述.md)。

- **查询类**：`ReportController`（/v3/report/report/{task_id}、list、summary、modify_error_cause_type）。
- **导出类**：ApiServlet `action=report` 下的 `Excel.reportExcel` / `Pdf.parse` / `Report.*`，异步生成后回写任务详情中的 `content.excel{status,url,updatetime}`，报告文件上传到 文件管理服务。
- 详见 [核心链路-报告生成](../04-复杂功能细节/核心链路-报告生成.md) 与 [批量补测与报告实现](../03-实现逻辑/批量补测与报告实现.md)。

## 问题分析

> 界面入口：[任务管理页](任务管理.md)报告内的失败脚本与问题分析。

`ProblemAnalysisReportController`（/v3/realweb/report/*）提供失败脚本列表、错误步骤明细、设备列表、输入参数刷新；错误原因的自动匹配在结果回收阶段完成（`ReportServiceImpl` 调 平台配置 的 `ErrorCauseTypeV3Api.getErrorCauseMathRule`），人工修正走 `ReportController.modify_error_cause_type`。

## 数据模型要点

### MongoDB：任务域 6 类集合 × 100 分片

| 集合（前缀） | 内容 | 对应 POJO |
|---|---|---|
| `pmwebTaskDetail_XX` / `pmpcTaskDetail_XX` | 任务明细（顶层单位） | [PmTaskDetail](../../数据库管理/web-pc处理服务-mongo/PmTaskDetail.md) |
| `pmwebScriptSummary_XX` | 脚本汇总树（装配产物） | [PmScriptSummary](../../数据库管理/web-pc处理服务-mongo/PmScriptSummary.md) |
| `pmwebDeviceRunInfo_XX` | 设备（浏览器/PC）运行状态 | [PmDeviceRunInfo](../../数据库管理/web-pc处理服务-mongo/PmDeviceRunInfo.md) |
| `pmwebScriptRunInfo_XX` | 脚本运行状态（补测打 `repeatTestMark`） | [PmScriptRunInfo](../../数据库管理/web-pc处理服务-mongo/PmScriptRunInfo.md) |
| `pmwebReportDetail_XX` | 报告明细（脚本级结果） | [PmReportDetail](../../数据库管理/web-pc处理服务-mongo/PmReportDetail.md) |
| `pmwebTaskSummary_XX` | 任务统计汇总 | [PmTaskSummary](../../数据库管理/web-pc处理服务-mongo/PmTaskSummary.md) |

分片规则：taskid 末 2 位 → `00~99` 共 100 个物理集合；`pt` 前缀走 `pmpc_db`，其余走 `pmweb_db`，表名计算见 `PmTaskDetail.table`（`src/main/java/cn/testin/realweb/pojo/mongo/PmTaskDetail.java`）。总索引见 [mongo 集合索引](../../数据库管理/web-pc处理服务-mongo/00-集合索引.md)。

### MySQL db_common：模板与应用域

| 表 | 内容 |
|---|---|
| [quartz_job](../../数据库管理/db_common/quartz_job.md) | 定时任务模板主表 |
| [job_task_relation](../../数据库管理/db_common/job_task_relation.md) | 模板与已创建任务的关联 |
| [quartz_job_log](../../数据库管理/db_common/quartz_job_log.md) | 定时执行日志 |
| [app_info](../../数据库管理/db_common/app_info.md) | 应用信息 |

另：`mq_info_notice`（db_mq，来自公共库 cn.testin.common）是本服务全部异步通知的持久化队列。
