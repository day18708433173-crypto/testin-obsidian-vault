# 横切-后台线程全景

## 概述

web/pc处理服务 的后台线程分三类：CommandLineRunner 启动线程、Quartz 定时调度、@Async 线程池。

## 1. StartRunner 启动线程

`StartRunner`（`@Component implements CommandLineRunner`），在应用启动时创建：

| 线程 | 类型 | 周期 | 说明 |
|------|------|------|------|
| PDFThread | `new Thread(...)` | 常驻 | PDF 处理 |
| NoticeDispatchThread | MQ dispatch | 常驻（batch 100, pool 10, interval 100ms） | 从 "realweb" channel 消费通知 |
| MqNoticeDataThread | `Executors.newSingleThreadScheduledExecutor` | `scheduleAtFixedRate` 1000ms | 轮询 19 种 MQ 通知类型，分发到 NoticeServiceImpl.handle |
| QuartzListenerThread | 单线程 | 常驻 | 重启后恢复已注册的 Quartz 调度 |

## 2. Quartz 定时调度

通过 `SchedulerManager`（单例）+ `QuartzHelper` 管理，三种 Job：

| Job 类 | 对应 businessType | 触发后的执行 | 注册位置 |
|--------|------------------|-------------|---------|
| `AppQuartzJob` | APP | `AppQuartz.execute()` → RealTestApi.execute | `InitQuartz.APP` |
| `WebQuartzJob` | WEB | `WebQuartz.execute()` → RealWebApi.add | `InitQuartz."2"` / `WEB` |
| `McPcQuartzJob` | PC | `McPcQuartz.execute()` → McPcTaskApi.add | `InitQuartz.PC` |

**调度生命周期**（`QuartzJobServiceImpl.addScheduler`）：
1. 验证 Cron 表达式有效性
2. 删除旧 schedule（如有）
3. 构建 `JobDataMap`（QUARTZ_JOB_ID, QUARTZ_CRON_PARAMS, QUARTZ_JOB_NAME, QUARTZ_EID, QUARTZ_PROJECT_ID, QUARTZ_JOB_TYPE, QUARTZ_CUSTOM_JOB_RULE）
4. 注册相应的 Quartz Job + Cron Trigger
5. 失败时删除 `quartz_job` DB 记录（非 modifyFlag 时）

**高级调度**（`BaseQuartz.execAdvancedJob`）：
- 检查 `timeMaxTimes` / `jobMaxTimes` / `endDate`
- 检查上一次同 job 的任务是否已完成
- 记录 `job_task_relation`
- 使用 `McPcTaskApi.add` / `RealWebApi.add` / `RealTestApi.execute`

**普通调度**（`BaseQuartz.execCommonJob`）：
- 直接调用各端 add 方法创建任务

## 3. @Async 线程池

`AsyncConfig.operateLogExecutor`：

| 参数 | 值 | 说明 |
|------|-----|------|
| corePoolSize | cpu × 2 | 核心线程数 |
| maxPoolSize | cpu × 2 + 1 | 最大线程数 |
| queueCapacity | 1000 | 等待队列 |
| threadNamePrefix | "operate_log_" | 线程名 |

使用场景：
- `OperateLogAspect`: `@Around` 中 `@Async` 执行 `postOperateLog` / `exceptionOperateLog` 写入 Redis 队列 `queue:operate_log`

## 定时任务列表

| 任务 | 周期 | 类型 | 说明 |
|------|------|------|------|
| MqNoticeDataThread | 1000ms | ScheduledExecutor | MQ 通知消费 |
| Quartz Cron Jobs | 各模板自定义 | Quartz | 定时创建测试任务 |
| QuartzListenerThread | 启动时一次 + 监听 | Thread | 恢复 Quartz 调度 |

注：web/pc处理服务 **不使用** `@Scheduled` 注解，所有定时逻辑走 Quartz 或 `ScheduledExecutorService`。
