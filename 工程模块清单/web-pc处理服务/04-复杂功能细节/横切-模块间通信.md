# 横切-模块间通信

## 概述

web/pc处理服务 作为 Web/PC 端任务执行服务，需要与 10+ 个外部微服务交互。

## 通信方式

| 方式 | 技术 | 用于 |
|------|------|------|
| ApiServlet（V1） | OkHttp3 + `ApiUtil.doPress(prefName, json)` | UserManager, NoticeManager, RealPortal, Script, DataSource, RealCfg, ControlCenter, RealScheduling, RealTest, RealCross |
| REST（V3） | RestTemplate + `ServiceRemoteV3Api` | RealLogfile, Script（V3接口）, DeviceManager |
| HttpClient 直连 | Apache HttpClient | PlanRecordApi, PlanRecordTaskApi, ParameterSourceApi.getParamTableInfo, TestPlanApi.report, TimeoutApi.getTimeoutConfig |
| MQ | `IMqInfoNoticeDAO` → channel "realweb" | 内部通知队列 |
| Redis | Jedis 双连接池 | 队列/锁/缓存/去重 |

## 请求路方式别

### V1 模式
```
real-web api class → AbstractApi reqJson(action, op, data) → ApiUtil.doPress(prefixName, reqJson) → 目标服务 ApiServlet
```
### V3 模式
```
real-web api class → ServiceRemoteV3Api.remotePost/remoteGet(url, body, typeRef) → RestTemplate → 目标服务 DispatcherServlet /v3/*
```
### 直连模式
```
real-web api class → HttpClient GET/POST/PUT → 目标服务 URL
```
