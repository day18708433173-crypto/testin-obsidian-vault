# 存储总览

> 表文档统一集中在 [数据库管理](../../数据库管理/00-数据库总览.md) 维护，本页仅列本服务使用的库并做引用。

web/pc处理服务 使用以下存储层：

## MySQL（1 个本地库 + 2 个 legacy 库）

| 库名 | 用途 | 索引页 |
|------|------|--------|
| db_common | 定时任务模板、执行日志、应用信息、任务关联 | [00-表索引](../../数据库管理/db_common/00-表索引.md) |
| db_mq（legacy，cn.testin.common） | MQ 通知持久化（`MqInfoNotice` 表，jar 内定义） | — |
| db_web（legacy，预留，无直接使用） | 预留 Web 数据库 | — |

### 备注：不属于 web/pc处理服务 直接管理的库

以下库在其他微服务中管理，web/pc处理服务 通过 HTTP API 间接访问：

- **db_user** — 用户、企业、项目、角色（由 UserManager 服务管理）
- **db_plan** — 测试计划、执行记录（由 RealLogfile 服务管理）
- **db_notice** — 通知渠道、邮件/短信/消息任务（由 NoticeManager 服务管理）
- **db_realcfg** — 环境配置、超时配置、错误原因（由 RealCfg 服务管理）
- **db_client / db_device / db_pc** — 客户端/设备/PC 管理（由 ControlCenter/RealScheduling 管理）
- **db_file** — 文件存储（由 File 服务管理）
- **db_portal** — 门户任务表（由 RealPortal 服务管理）

## MongoDB（2 个库）

| 库名 | 用途 | 数据模板 |
|------|------|---------|
| pmweb_db | Web 端任务详情、报告、脚本/设备运行记录 | `pmweb*_XX`（6 类 × 100 分片 = 600 集合） |
| pmpc_db | PC 端任务详情、报告、脚本/设备运行记录 | `Pmpc*_XX`（6 类 × 100 分片 = 600 集合） |

分片规则：`taskId` 末 2 位数字 → `_00` ~ `_99` 共 100 个物理集合。taskId 以 `pt` 开头走 `pmpc_db`，否则走 `pmweb_db`。

| 逻辑集合 | Web 物理集合 | PC 物理集合 | 说明 |
|---------|-------------|------------|------|
| PmTaskDetail | pmwebTaskDetail_XX | PmpcTaskDetail_XX | 任务详情 |
| PmTaskSummary | pmwebTaskSummary_XX | PmpcTaskSummary_XX | 报告统计汇总 |
| PmReportDetail | pmwebReportDetail_XX | PmpcReportDetail_XX | 报告详情（每脚本/步骤） |
| PmScriptRunInfo | pmwebScriptRunInfo_XX | PmpcScriptRunInfo_XX | 脚本运行记录 |
| PmScriptSummary | pmwebScriptSummary_XX | PmpcScriptSummary_XX | 脚本汇总树 |
| PmDeviceRunInfo | pmwebBrowserRunInfo_XX | PmpcClientRunInfo_XX | 设备/浏览器运行记录 |

**总集合数**：2 库 × 6 逻辑类 × 100 分片 = **1200 个物理集合**。

## Redis

**双连接池**：

| 连接池 | 数据库 | 用途 |
|--------|--------|------|
| legacy `jedisPool` | `realtestcenter` | 操作日志队列、Excel 导出缓存、心跳检测、通用锁/去重 |
| `springBootJedisPool` | DB 0 | 通用队列/锁操作（`RedisService`） |

**关键 Key 模式**：

| Key 模式 | 用途 |
|----------|------|
| `queue:action_log` | Action 日志队列（Excel 导出触发） |
| `queue:operate_log` | 操作日志队列（模板增删改记录） |
| `action_log:excel:{requestId}` | Excel 导出文件名缓存（TTL 1天） |
| `{taskid}_handleNewNotice` | 任务完成邮件去重（TTL 60s） |
| `{taskid}_handleScriptFailSendNotice_web` | 脚本失败通知去重（TTL 60s） |
| `{taskid}_device_with_row_id` | 数据驱动：scriptNo→deviceId→rowId 映射 |

## MQ 消息队列

`IMqInfoNoticeDAO`（cn.testin.common）管理 `MqInfoNotice` 持久化，channel `"realweb"`。

主要通知类型（19 种）：`TASK_ASSEMBLY`、`WEB_TASK_INIT`、`REPORT_STAT`、`FINISH_EMAIL`、`SEND_MSG`、`FINISH_NOTICE`、`TASK_CALLBACK`、`SCRIPT_FAIL_SEND_ALL_NOTICE`、`REPORT_GENERATE`、`REPORT_GENERATE_PLAN`、`TASK_COMPLETE_NOTICE` 等。
