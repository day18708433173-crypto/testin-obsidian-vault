# 存储总览 (任务管理服务)

> 表文档统一集中在 [数据库管理](../../数据库管理/00-数据库总览.md) 维护，本页仅列本服务使用的库并做引用。

任务管理服务 使用以下存储层：

## MySQL（1 个库）

| 库名 | 用途 | 索引页 |
|------|------|--------|
| [db_task](../../数据库管理/db_task/00-表索引.md) | 任务模板、执行记录、执行报告、用例结果、调度记录 | [00-表索引](../../数据库管理/db_task/00-表索引.md) |

> 注意：任务管理服务 仅管理 `db_task` 一个库。其他库（如 `db_user`、`db_plan`、`db_device` 等）由对应微服务管理，任务管理服务 通过 HTTP API 跨服务访问。

## Redis

- **用途**：任务消息队列（List 结构）、分布式锁（Redisson RLock）
- 关键 Key 前缀定义在 `cn.testin.common.constant.RedisQueueConstants`
- 队列：
  - `task_execute_record_init_queue` / `_bak` — 任务初始化
  - `task_execute_record_exec_queue` / `_bak` — 任务开始执行
  - `task_execute_record_execute_queue_` / `_bak_` — 任务执行中
  - `task_result_parse_queue_` / `_bak` — 结果解析
  - `task_result_analysis_queue_` / `_bak` — 结果分析
  - `task_send_plan_queue_` / `_bak` — 结果回传计划
  - `task_cancel_queue_` / `_bak` — 任务取消
- 消费模式：`brPopLPush` 阻塞式可靠消费，每条消息在消费前先备份到 bak 队列

## 外部存储（非本模块管理）

以下存储层由其他微服务管理，任务管理服务 通过 HTTP API 访问：

| 存储 | 管理服务 | 用途 |
|------|---------|------|
| MongoDB 执行日志 | [real-logfile](../../平台基础功能服务/00-首页.md) | 脚本执行日志存储 |
| ES Portal Summary | [real-portal](../../平台基础功能服务/00-首页.md) | 门户任务摘要搜索 |
| 文件存储 | [file-service](../../文件管理服务/00-首页.md) | 报告附件、截图、日志文件 |
