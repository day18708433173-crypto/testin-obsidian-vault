# 功能总览

> 本页是功能维度的总索引：每个功能一句话定位 + 核心能力 + 入口与深入阅读。代码级细节见 [数据源管理实现](../03-实现逻辑/数据源管理实现.md)、[脚本变量填充实现](../03-实现逻辑/脚本变量填充实现.md) 及 04-复杂功能细节 各专题。

## 功能地图

```
数据源（datasource-manage）
├── 数据源管理（legacy 表族）
│   ├── 目录树        → 项目根/目录/数据源/全局表/实例表，五级层级限制
│   ├── 树节点 CRUD   → 新增/改名/删除(级联)/移动/复制
│   ├── 脚本绑定      → 实例表按 script_no 绑脚本，bindDefaultSource / bindOtherSource
│   └── 数据表操作    → 行列增删、列属性(scope/报告可见)、单元格编辑、批量替换
├── 执行时变量消费（对外核心能力）
│   ├── 按脚本查数据源   → POST /v3/datasource/datasources/scripts
│   ├── 执行时取值注入   → POST /v3/datasource/getScriptParamDataNew（标签筛选/全局引用解析）
│   └── 表达式取值       → DataTableCtrl.selectValueByExpression（全局表.变量.行）
├── 用例数据源（case 表族）
│   └── 用例-数据行绑定 → case_source_relation（回放指定 case_table_row_id）
├── 普通数据源（normal 表族）
│   └── 通用表格数据管理 → /table/data/format 免登格式化输出
├── 项目全局变量
│   └── project_global_variables → 普通/加密变量（RSA），按变量名更新
├── 标签系统
│   ├── 行标签  → datatable_tag_config / case_source_tag_config
│   └── 批量标签操作 → /datasource/tag/operate（造数失败标记）、/common/tag/operate
├── SQL 管理
│   └── source_sql → SQL 表达式定义，供单元格 value_type=SQL 取值
├── 数据检索
│   └── SelectCtrl → 按目录树/变量名/变量值/标签名四维搜索
└── 导入导出与迁移
    ├── Excel 导入 → importVerify 预检 + importDataSourceInfo 策略导入
    ├── 树导出     → getExportSourceTreeNode（每实例表一个 Excel）
    └── 运维工具   → historyDataMigration / batchCopyDataTableByScriptNos / syncSourceName
```

## 各功能详述

### 数据源管理（legacy，`source_config` 表族）

> 界面入口：[数据源页](存储数据源.md) `/platform/data-manage/data-source`。

数据源以**树形**组织在 `source_config` 一张表里（`parent_id` 自关联），节点类型（`SourceConfig.java`）：

| type | 含义 | 说明 |
|---|---|---|
| 0 | 目录 | 纯分组，最多五层（`SourceConfigServiceImpl.java`） |
| 1 | 数据源 | 树根；创建时自动生成全局表 + SQL 管理目录（`SourceConfigServiceImpl.java`） |
| 2 | 全局表 | 数据源级共享变量，实例表可用 `${变量名}` 引用 |
| 3 | 实例表 | 绑定脚本的变量表（`script_no`），是执行时参数的主要来源 |
| 4 / 5 | SQL 管理目录 / 具体 SQL | 关联 `source_sql` |

- 树节点 CRUD：`SourceConfigCtrl`（add / updateById / delete / moveTo / copyTo / getTree），删除为级联软删。
- 数据表操作：`DataTableCtrl`（insertRowOrCol / deleteRowOrCol / configCol / updateData / selectData / batchReplaceVarValue 等，12 个端点）。
- 接口清单：[SourceConfigCtrl](../07-开放接口文档/其他ApiServlet/service-SourceConfigCtrl.md)、[DataTableCtrl](../07-开放接口文档/其他ApiServlet/service-DataTableCtrl.md)。

### 执行时变量消费

> 界面入口：无独立页面，执行时由 app处理服务/平台基础功能服务调用，详见 [脚本变量填充](脚本变量填充.md)。

本服务存在的核心价值，两个主力接口：

| 接口 | 消费方 | 干什么 |
|---|---|---|
| `POST /v3/datasource/datasources/scripts` | app处理服务 | 按 scriptNos（或脚本条件）批量查数据源基本信息，自动扩展子脚本 |
| `POST /v3/datasource/getScriptParamDataNew` | 平台基础功能服务（提测） | 按 scriptNoList 取回实例表行列数据 + 全局变量，支持行标签 include/exclude 与全局引用解析 |

代码级链路见 [脚本变量填充实现](../03-实现逻辑/脚本变量填充实现.md)；自然语言版说明见 [脚本变量填充](脚本变量填充.md)（按脚本批量取数、行标签筛选、全局引用解析的执行侧取值规则）。

### 用例数据源（case 表族）

> 界面入口：[数据源页](存储数据源.md) `/platform/data-manage/data-source`，详见 [用例数据源](用例数据源.md)。

较新的用例关联数据源体系（MVC 风格，`CaseSourceController` 27 端点）：`case_source` 树 + `case_column_info` / `case_value_info` / `case_table_config` + **用例绑定** `case_source_relation`（case_id → 数据源 + 行，用于回放调度指定数据行）。接口清单：[CaseSourceController](../07-开放接口文档/数据源管理/CaseSourceController.md)。

### 普通数据源（normal 表族）

> 界面入口：[数据源页](存储数据源.md) `/platform/data-manage/data-source`。

简化版通用表格数据（`NormalSourceController` 15 端点），仅支持 String 列、无标签/无用例关联；`/table/data/format` 提供免登格式化输出。接口清单：[NormalSourceController](../07-开放接口文档/数据源管理/NormalSourceController.md)。

### 项目全局变量

> 界面入口：[全局变量页](全局变量.md) `/platform/data-manage/global-variable`。

`project_global_variables`：项目级 KV 变量，支持**加密变量**（RSA，`/encryption` / `/getSecretKey` 端点，`ProjectGlobalVariablesController.java`）。接口清单：[ProjectGlobalVariablesController](../07-开放接口文档/数据源管理/ProjectGlobalVariablesController.md)。

### 标签系统

> 界面入口：[数据标签页](存储数据源.md) `/platform/data-manage/data-label`。

- 标签定义：`tag_info`（全表族共用）；行关联：`datatable_tag_config`（legacy）/ `case_source_tag_config`（case）。
- 执行侧按标签 include（`tagList`）/ exclude（`noHasTagList`）筛选数据行，exclude 行以 `skip=1` 下发。
- 批量打标：`/datasource/tag/operate`（国金证券定制：标记造数失败的变量值，`DataSourceController.java`）、`/datasource/common/tag/operate`（通用版，`DataSourceController.java`）。

### 导入导出与迁移

> 界面入口：[数据源页](存储数据源.md) `/platform/data-manage/data-source` 内的导入导出。

- **导入**：`importVerify`（下载 Excel → sheet 名解析脚本编号 → 查 db_file 检测重复旧脚本编号）→ `importDataSourceInfo`（按节点类型策略分发：目录/数据源/全局表/实例表四个策略类）。
- **导出**：`getExportSourceTreeNode` 按脚本选定数据源，每实例表导出一个 Excel。
- **运维**：`historyDataMigration`（历史迁移）、`batchCopyDataTableByScriptNos`（批量复制脚本时连带复制数据源）、`syncSourceName`（脚本改名同步数据源表名）；`syncEs` 接口保留但已为空实现（ES 已废弃，`SourceConfigServiceImpl.java`）。
- 详见 [核心链路-数据源导入导出](../04-复杂功能细节/核心链路-数据源导入导出.md)、[横切-数据源导入策略](../04-复杂功能细节/横切-数据源导入策略.md)；产品级说明（预检流程、唯一性约束、复制/改名联动）见 [数据驱动数据源](数据驱动数据源.md)「导入导出」一节。

## 数据模型要点

### legacy 表族（db_source）

```
source_config (树: 目录/数据源/全局表/实例表/SQL)
    │ source_id = 数据源根 id, parent_id 自关联, script_no 绑脚本
    ├── datatable_config      行列顺序（colOrder/rowOrder 逗号分隔串）
    ├── datatable_col_config  列=变量：name/type/scope(global/local)/show_in_report
    ├── datatable_values      单元格：row_index/col_index/param_value/value_type(手动/全局引用/SQL/随机)
    └── datatable_tag_config  行标签关联 → tag_info
```

关键约束与规则：

- **`unique_scriptno` 唯一索引**：同一数据源内脚本编号不可重复；新增/移动/复制撞约束时前端提示"存在重复脚本编号"（`SourceConfigCtrl.java`）。
- **逻辑删除**：MyBatis-Plus 全局配置 `status` 字段 0=已删 1=有效（`src/main/resources/application.yml`）；因唯一索引存在，批量删除实例表前会**先物理删除 status=0 的记录**再逻辑删（`SourceConfigServiceImpl.java`）。
- **值引用**：单元格 `param_value` 为 `${变量名}` 时表示引用全局表变量，取值时替换为全局表实际值（`DatatableValuesServiceImpl.java`）。
- **scope**：列的 `scope=global` 时下发 `isGlobal=1`，执行侧按全局变量处理。

表详情：[source_config](../../数据库管理/db_source/source_config.md)、[datatable_config](../../数据库管理/db_source/datatable_config.md)、[datatable_col_config](../../数据库管理/db_source/datatable_col_config.md)、[datatable_values](../../数据库管理/db_source/datatable_values.md)、[datatable_tag_config](../../数据库管理/db_source/datatable_tag_config.md)、[tag_info](../../数据库管理/db_source/tag_info.md)、[source_sql](../../数据库管理/db_source/source_sql.md)。

### case / normal 表族

- case：`case_source`（树）+ `case_column_info` + `case_value_info` + `case_table_config` + `case_source_relation`（用例绑定）+ `case_source_tag_config`。
- normal：`normal_source` + `normal_column_info` + `normal_value_info` + `normal_table_config`。
- 三套表族的差异对比见 [横切-三套数据源表族](../04-复杂功能细节/横切-三套数据源表族.md)。

### 跨库只读关联

| 库 | 用途 |
|---|---|
| `db_file` | 脚本文件信息（导入预检查重复脚本编号、FileApi 查子脚本），只读 |
| `db_user` | 项目信息（`getProjectInfo`），只读 |
