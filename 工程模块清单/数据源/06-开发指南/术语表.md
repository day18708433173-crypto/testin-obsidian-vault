# 术语表

> 按拼音/字母排序。每条给"一句话定义 + 深入阅读"。

## A

**ApiServlet** — 本服务的旧入口 Servlet（`/openapi/*`），反射路由到 `service/source/*Ctrl`，方法签名 `String xxx(ApiRequest)`；与 `/openapi/v3/*` 的 MVC 入口并存。见 [横切-双入口路由机制](../04-复杂功能细节/横切-双入口路由机制.md)。

## B

**bind（默认绑定）** — `source_config.bind=1` 表示该实例表是脚本的默认绑定表；`bindDefaultSource` / `bindOtherSource` 接口维护。见 [数据源管理实现](../03-实现逻辑/数据源管理实现.md)。

## C

**case 表族** — 用例数据源体系（`case_source` / `case_column_info` / `case_value_info` / `case_source_relation` / `case_table_config`），支持用例-数据行绑定。见 [横切-三套数据源表族](../04-复杂功能细节/横切-三套数据源表族.md)。

**case_source_relation（用例数据源绑定）** — 记录 case_id → 用例数据源 + `case_table_row_id`，用于回放调度时指定用哪一行数据。

## D

**datatable（数据表）** — 实例表/全局表的表格实体，由 `datatable_config`（行列序）+ `datatable_col_config`（变量列）+ `datatable_values`（单元格值）三张表组成。

**dataset / 数据行（Row）** — datatable 的一行 = 一组参数取值；执行时按行循环驱动脚本参数化，行可用标签筛选。

**source_id** — `source_config` 上指向"所属数据源根节点"的字段；同一数据源下所有节点共享同一个 source_id。

**unique_scriptno** — `source_config` 的唯一索引，保证同一数据源内脚本编号不重复；逻辑删除（status=0）的记录仍占索引，批量删除前需先物理清理。见 [数据源管理实现](../03-实现逻辑/数据源管理实现.md)。

## E

**eid** — 企业 ID，全表族通用的租户隔离字段；与 projectId（项目组）一起做数据隔离。

## G

**全局表（Global Source）** — 数据源级共享变量表（type=2），创建数据源时自动生成；实例表单元格用 `${变量名}` 引用其值。

**全局变量（Project Global Variables）** — `project_global_variables` 表的项目级 KV 变量，支持 RSA 加密变量；与"全局表"是两个体系，勿混淆。

## J

**脚本编号（script_no）** — 脚本服务/文件管理服务 侧脚本的唯一编号；实例表通过它绑定脚本，执行侧按它查数据源。

**实例表（Local Source）** — 绑定脚本的变量表（type=3），是执行时参数注入的主要来源。见 [脚本变量填充实现](../03-实现逻辑/脚本变量填充实现.md)。

## L

**legacy 表族** — 最早的 `source_config` + `datatable_*` 体系，功能最全（全局引用/SQL/随机值/行标签），ApiServlet 入口为主。见 [横切-三套数据源表族](../04-复杂功能细节/横切-三套数据源表族.md)。

**列（ColConfig / 变量）** — datatable 的一列即一个变量，含 name、type（String/数字/对象/数组）、scope、descr、show_in_report。

## N

**normal 表族** — 简化通用数据源体系（`normal_source` / `normal_*`），仅 String 列、无标签无用例关联，MVC 入口。

**noHasTagList** — 取值接口的 exclude 标签参数：命中行的单元格打 `skip=1` 下发（行不删），由执行侧跳过。对照 tagList（include，直接过滤行）。

## Q

**queue:operate_log** — 操作日志 Redis 队列；`OperateLogService` 同步 LPUSH，平台基础功能服务 消费入库。见 [横切-操作日志与异步任务](../04-复杂功能细节/横切-操作日志与异步任务.md)。

## S

**scope（变量作用域）** — 列属性：`global`（下发 isGlobal=1，作全局变量处理）/ `local`（脚本局部）。

**skip** — 单元格/行下发标记：1 表示执行侧跳过该行（exclude 标签命中的结果）。

**source_sql** — SQL 表达式定义表；单元格 `value_type=SQL` 时按表达式动态取值。

## T

**tagList** — 取值接口的 include 标签参数：先过滤数据源（无标签整表剔除），再过滤行（命中才保留）。

**标签（Tag）** — 打在数据行上的标记（定义在 `tag_info`，关联在 `datatable_tag_config` / `case_source_tag_config`）；典型用途：执行时选数据行、标记造数失败记录（`/datasource/tag/operate`，国金证券定制）。

**提测** — 平台基础功能服务 的提测业务，`getScriptParamDataNew` 的主要消费方（接口注释"提测业务获取数据源数据"）。

## V

**value_type** — 单元格值来源类型：手动录入 / 全局引用（`${var}`）/ SQL 表达式 / 随机生成；仅 legacy 表族支持。

## X

**下划线转驼峰（@UnderlineToCamel）** — GET 请求参数自动转换注解，由 `QueryMethodArgumentResolver` 实现，双入口共用。

## Y

**环境数据源** — `source_config.type=20` 的特殊数据源，按环境（envId）区分的变量表，注释中写作"1 数据源（20 环境数据源）"。

## Z

**造数失败标签** — 外部造数系统（如国金证券）通过 `/datasource/tag/operate` 给指定变量值所在行打的失败标记，供执行侧排除。

**子脚本（childScriptNo）** — 脚本内引用的其他脚本；`datasources/scripts` 查询时经 `FileApi.getChildScriptNos` 自动扩展，子脚本变量一并下发。
