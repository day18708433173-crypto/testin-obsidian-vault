# 横切-三套数据源表族

> 数据源 维护三套独立的数据源表族，服务于不同场景，反映架构演进。

## 对比

| 特性 | legacy（source_config 体系） | case 体系 | normal 体系 |
| --- | --- | --- | --- |
| 表前缀 | `source_config` + `datatable_*` | `case_source` + `case_*` | `normal_source` + `normal_*` |
| 节点类型 | 目录/数据源/全局表/实例表/SQL(5种) | 目录/实例表/数据源(3种) | 目录/实例表(2种) |
| 时间字段 | bigint Unix 时间戳 | datetime | bigint Unix 时间戳 |
| 用户字段 | `update_by` (varchar 用户名) | `create_user_id` / `update_user_id` (int 用户ID) | `create_user` / `update_user` (varchar 用户名) |
| 列类型 | 0=默认 1=String 2=数字 3=对象 4=数组 | 仅支持 String | 仅支持 String |
| 报告可见性 | `show_in_report` | `show_in_report` | 不支持 |
| 标签配置 | `datatable_tag_config` | `case_source_tag_config` | 不支持 |
| 用例关联 | 不支持 | `case_source_relation` | 不支持 |
| 值来源类型 | `value_type`（手动/全局引用/SQL/随机） | 无 | 无 |
| SQL 关联 | `source_sql` 表 | 不支持 | 不支持 |
| 入口 | SourceConfigCtrl / DataTableCtrl / SelectCtrl | CaseSourceController | NormalSourceController |

## 演进路径

1. **legacy 体系**：最早设计，功能最全（支持 SQL 生成、随机生成、全局引用等 value_type），接口为 ApiServlet 风格。
2. **normal 体系**：简化版通用数据源，去除了复杂特性，接口为 MVC 风格。
3. **case 体系**：为测试用例场景定制的数据源，增加了用例关联绑定（`case_source_relation`）和回放行指定（`case_table_row_id`），接口为 MVC 风格。

## 共存策略

- legacy 体系通过 ApiServlet 入口继续服务，维护为主
- case 和 normal 体系通过 MVC 入口服务，为主要开发方向
- 三套表族共用 `tag_info` 标签定义表
