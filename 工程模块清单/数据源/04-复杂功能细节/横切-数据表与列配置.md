# 横切-数据表与列配置

> 分支无关。数据表三表结构（datatable_config / datatable_col_config / datatable_values）与列/单元格的设计要点。

## 三表定位

一张 `source_config` 表节点（全局表 type=2 / 实例表 type=3）对应一套表格实体：

| 表 | 职责 | 关键字段 |
|---|---|---|
| `datatable_config` | 行列「顺序」而非行列本身 | `rowOrder`/`colOrder` 逗号序号串 + `rowMaxIndex`/`colMaxIndex` |
| `datatable_col_config` | 列 = 变量定义 | `name`/`type`/`scope`/`quoteType`/`showInReport`/`sqlCol`/`colIndex` |
| `datatable_values` | 单元格值 | `rowIndex`/`colIndex`/`paramValue`/`valueType` |

## 行列顺序的字符串设计

`datatable_config.rowOrder`/`colOrder` 用逗号分隔的序号串（如 `"1,3,2,5"`）表示行列的真实展示顺序；`rowMaxIndex`/`colMaxIndex` 是已分配的最大序号（不回退）。增删行列本质是修改这两个序号串：

- 插入：`insertRowOrCol` 分配新序号并插入到指定位置（前端 `startNumber` 指定锚点，0 表示最前）。
- 删除：`deleteRowOrCol` 从序号串移除，并级联删 `datatable_values`/`datatable_col_config`（删列）或 `datatable_tag_config`（删行）。
- 并发：多人在线编辑同一表时，锚点序号可能已被他人删除，此时抛「请重新插入」。

## 列的类型与作用域

- `ColConfigEnums` 定义列类型 `type`：DEFAULT(0)/STRING(1)/NUMBER(2)/OBJECT(3)/ARRAY(4)；`quoteType`：ALL_COLUMN(1，全局整列引用)/MANUAL_SET(2，手动设置单元格)。
- `scope` 分 GLOBAL/LOCAL：`scope=global` 的列在取值时下发 `isGlobal=1`，执行侧按全局变量处理（整轮只取一次）。
- `showInReport`（0/1）控制列是否进入报告执行摘要（`getExecutiveSummaries` 只取 `show_in_report=1` 的列）。
- 唯一约束：`unique_name`（变量名）、`unique_colIndex`（列号）、`unique_tag`（行标签）。

## 单元格值的四种来源

`DatatableValuesEnums` 定义 `valueType`：

| valueType | 含义 | 本服务是否计算 |
|---|---|---|
| 0 MANUAL_INPUT | 手动输入 | 直接存 |
| 1 GLOBAL | 全局表引用（`${变量名}`） | 读取时替换为全局表实际值 |
| 2 SQL | SQL 生成 | 只存标记，表达式在 `source_sql`，执行侧算 |
| 3 RANDOM | 随机生成 | 只存标记，执行侧生成 |

## 默认表与脚本变量解析

- 全局表/无脚本实例表：`setDefaultInfo` 建默认四行四列。
- 实例表首次创建：`createConfig` 调 `FileApi.findFinalScript` 取脚本主串，`analyzeScript` 解析脚本 `var` 数组，把脚本声明的 LOCAL 变量自动建成列并带入初值。
