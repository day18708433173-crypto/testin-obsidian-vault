## 接口文档

### 数据源管理（6 Controller + 7 ApiServlet）

#### MVC Controller（/openapi/v3/*）

- [DataSourceController](07-开放接口文档/数据源管理/DataSourceController.md) — 数据源主控制器（脚本条件查询/执行概要/树/配置/标签操作/脚本参数/批量移动）
- [NormalSourceController](07-开放接口文档/数据源管理/NormalSourceController.md) — 普通数据源 CRUD + 树 + 表数据 + 批量（15 端点）
- [CaseSourceController](07-开放接口文档/数据源管理/CaseSourceController.md) — 用例数据源 CRUD + 树 + 用例关联 + 标签 + 批量（27 端点）
- [ProjectGlobalVariablesController](07-开放接口文档/数据源管理/ProjectGlobalVariablesController.md) — 项目全局变量 CRUD + RSA 加密（7 端点）
- [TagInfoController](07-开放接口文档/数据源管理/TagInfoController.md) — 标签查询/更新（MVC 风格，2 端点）
- [HeartBeatController](07-开放接口文档/数据源管理/HeartBeatController.md) — 心跳检测

#### ApiServlet 入口（/openapi/*）

- [SourceConfigCtrl](07-开放接口文档/其他ApiServlet/service-SourceConfigCtrl.md) — 数据源配置 CRUD + 导入导出 + 树操作 + ES 同步（~20 方法）
- [DataTableCtrl](07-开放接口文档/其他ApiServlet/service-DataTableCtrl.md) — 数据表行列操作 + 单元格编辑 + 标签配置 + 数据查询（~10 方法）
- [SelectCtrl](07-开放接口文档/其他ApiServlet/service-SelectCtrl.md) — 多维度数据检索（变量名/值/标签/目录）（4 方法）
- [SqlCtrl](07-开放接口文档/其他ApiServlet/service-SqlCtrl.md) — SQL 表达式 CRUD（4 方法）
- [TagInfoCtrl](07-开放接口文档/其他ApiServlet/service-TagInfoCtrl.md) — 标签列表 CRUD + 数据源标签查询（4 方法）
- [ColConfigCtrl](07-开放接口文档/其他ApiServlet/service-ColConfigCtrl.md) — 列配置批量更新/添加列/脚本同步（3 方法）
- [MigrateCtrl](07-开放接口文档/其他ApiServlet/service-MigrateCtrl.md) — 全局信息填充/空行删除（2 方法）
