# 数据源 总览

> 数据源管理系统：脚本和用例数据源的管理中心，记录和管理数据源并提供给其他组件消费。本页为分支无关的通用介绍，分支强相关内容见下方分支索引。

## 定位

数据源 是测试平台的"数据中心"，负责所有数据源的存储与检索：

| --- | --- | --- | --- |
| 数据源（脚本变量表）CRUD / 树管理 | **核心** | — | — |
| 全局表 / 实例表 数据存储 | **核心** | — | — |
| 用例数据源关联 / 行绑定 | **核心** | — | — |
| 普通数据源（通用表）管理 | **核心** | — | — |
| 项目全局变量管理 | **核心** | — | — |
| SQL 表达式管理 | **核心** | — | — |
| 标签管理 / 批量操作 | **核心** | — | — |
| 数据源导入 / 导出 / ES 同步 | **核心** | — | — |
| 数据源消费（脚本执行时变量填充） | — | 调用方 | **调用方** |

## 双入口架构

| 入口 | 路径 | 技术 | 路由方式 |
| --- | --- | --- | --- |
| ApiServlet | `/openapi/*` | 原生 Servlet + Spring MVC | `@RequestMapping` 注解路由到 `service/source/*Ctrl`，方法签名 `String xxx(ApiRequest)` |
| DispatcherServlet | `/openapi/v3/*` | Spring MVC | `@RestController` + `@RequestMapping` 注解路由 |

- `/openapi/*` → `ApiServlet`：注册在 Boot 类，处理 `service/source/` 包下的 Ctrl 类（ColConfigCtrl / DataTableCtrl / MigrateCtrl / SelectCtrl / SourceConfigCtrl / SqlCtrl / TagInfoCtrl），方法入参 `ApiRequest`，返回 JSON 字符串
- `/openapi/v3/*` → `DispatcherServlet`：标准 Spring MVC，处理 `controller/` 包下的 Controller 类

双入口均依赖 `QueryMethodArgumentResolver` 实现 GET 请求下划线参数自动转驼峰（`@UnderlineToCamel`）。

## 核心业务域

### 1. 数据源管理（db_source.source_config）

数据源按树形结构组织：`source_config` 表通过 `parent_id` 自关联。节点类型（type）：
- 0 = 目录
- 1 = 数据源（环境数据源 20）
- 2 = 全局表
- 3 = 实例表
- 4 = SQL 语句管理目录
- 5 = 具体 SQL

每个数据源按 `source_id` 关联一个脚本（通过 `script_no` 脚本编号）。`unique_scriptno` 唯一约束确保一个数据源下只有一个相同的脚本编号。

数据源配置 → 数据表配置（`datatable_config`：行列顺序）→ 列定义（`datatable_col_config`）→ 单元格值（`datatable_values`）。

### 2. 数据表操作

核心数据表为 `datatable_config`（行列排序）、`datatable_col_config`（列/变量定义，含 `scope` 全局/局部、`show_in_report` 报告可见）、`datatable_values`（单元格值，含 `value_type`：手动/全局引用/SQL/随机生成）。

表操作包含：插入行/列、删除行/列、配置列属性、配置行标签、更新单元格数据、查询表格数据。`DataTableCtrl` 是主要入口（ApiServlet 风格）。

### 3. 用例数据源（db_source.case_* 表族）

较新的用例关联数据源体系，独立于 legacy 数据源：

- `case_source`：用例数据源树（目录/实例表/数据源）
- `case_column_info`：列定义
- `case_value_info`：单元格值
- `case_source_relation`：用例与数据源绑定（case_id → case_source_id + case_table_row_id），用于回放调度
- `case_source_tag_config`：行标签
- `case_table_config`：表行列顺序

CaseSourceController（25 端点）提供完整 CRUD + 树查询 + 用例关联（add_case_relation / remove_case_relation / sync_case / edit_case_row_id / unbind_case_row_id）。

### 4. 普通数据源（db_source.normal_* 表族）

通用表数据源（`normal_source` / `normal_column_info` / `normal_value_info` / `normal_table_config`），提供基础的表格数据管理。NormalSourceController（15 端点）提供 CRUD + 格式化数据输出（`/table/data/format` 无需登录）。

### 5. 项目全局变量（db_source.project_global_variables）

项目级别的全局变量管理，支持普通变量和加密变量（RSA 加密）。`ProjectGlobalVariablesController` 提供 CRUD + 按变量名更新 + 加密/获取密钥。

### 6. 标签系统

`tag_info` 表存储标签定义；`datatable_tag_config` 和 `case_source_tag_config` 存储行标签关联。标签用于数据行的标记和筛选，支持批量操作。

### 7. 数据检索

`SelectCtrl` 提供四种搜索维度：
- 按数据源目录树搜索（`selectSourceConfig`）
- 按变量名搜索（`selectByVariableName`）
- 按变量值搜索（`selectByParamValue`）
- 按标签名搜索（`selectByTagName`）

### 8. 数据导入导出与迁移

`SourceConfigCtrl` 提供完整的导入导出能力（`importDataSourceInfo` / `importVerify` / `getExportSourceTreeNode`），以及历史数据迁移（`historyDataMigration`）、脚本编号同步（`syncSourceName`）、批量复制（`batchCopyDataTableByScriptNos`）。`syncEs` 接口保留但实现为空（ES 同步能力已废弃）。

## 外部服务依赖

数据源 通过 `api/` 包中的远程调用客户端调用以下外部服务：

| 服务 | 前缀名 | 用途 | 相关类 |
| --- | --- | --- | --- |
| [user-manager](../平台基础功能服务/00-首页.md) | UserManager | 用户在线状态、项目列表查询 | `OnlineApi`、`UserProjectGroupApi`、`OemSystemApi` |
| [script-service](../脚本服务/00-首页.md) | Script | 脚本信息查询（最新脚本、子脚本列表） | `FileApi` |
| [设备控制中心](../设备控制中心（real-controlcenter）/07-开放接口文档/00-模块索引.md) | ControlCenter | 控制中心通信 | `BaseApi.CONTROL_CENTER_PREFIXNAME` |
| [real-logfile](../平台基础功能服务/00-首页.md) | RealLogfile | 日志文件服务 | `AbstractApi` 常量 |
| [real-portal](../平台基础功能服务/00-首页.md) | RealPortal | Portal 服务 | `AbstractApi` 常量 |
| notice-manager | NoticeManager | 通知管理 | `AbstractApi` 常量 |
| [平台配置](../平台配置（real-cfg）/07-开放接口文档/00-模块索引.md) | RealCfg | 配置服务 | `AbstractApi` 常量 |
| [任务调度服务](../任务调度服务（real-scheduling）/07-开放接口文档/00-模块索引.md) | RealScheduling | 调度服务 | `AbstractApi` 常量 |
| [app处理服务](../app处理服务（real-test）/07-开放接口文档/00-模块索引.md) | RealTest | 测试执行服务 | `AbstractApi` 常量 |

调用方式：`ApiUtil.doPress(prefixName, reqJson)` 通过 `BaseApi.exec()` 构建签名（MD5）后发送 to 远程服务。

被调用方式：外部服务（如 app处理服务 执行脚本时需要变量数据）通过 `/openapi/v3/datasource/*` 或 `/openapi/source/*` 接口消费数据源数据。

## 后台线程

- `@EnableAsync` + `AsyncConfig` 线程池（`ThreadPoolTaskExecutor`，核心线程 = CPU × 2）
- `task/` 包提供 `AsyncManager` / `AsyncFactory` / `ShutdownManager` 异步框架（从 平台基础功能服务 平移），**当前无业务提交任务**，仅关停钩子被使用
- 操作日志不走该框架：`OperateLogService` 同步 LPUSH 到 Redis 队列 `queue:operate_log`，由 平台基础功能服务 消费入库（见 [横切-操作日志与异步任务](04-复杂功能细节/横切-操作日志与异步任务.md)）
