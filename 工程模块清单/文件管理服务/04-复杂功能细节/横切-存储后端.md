# 横切-存储后端

> 文件实体（App 包、脚本 ZIP、步骤 JSON、测试结果、图标等）统一落在 FastDFS 或 MinIO 两个后端之一。本专题讲清楚"二选一怎么决定、两套实现差异在哪、URL 怎么拼、删除怎么删"。存储层总览见 [00-存储总览](../02-技术架构/00-存储总览.md)。

## 后端选择：部署期二选一

```
FileUploadServiceFactory.getInstance()
  └─ Config.MINIO_USABLE == true
       ├─ true  → Spring bean "minioUploadService"（MinioFileUploadServiceImpl → MinioService）
       └─ false → Spring bean "fastDFSFileUploadService"（FastDFSFileUploadServiceImpl → FastDFSService）
```

- `FileUploadServiceFactory.fileUploadService` 是**静态字段**，首次 `getInstance()` 后进程内不再切换；`afterPropertiesSet()` 在启动即初始化一次。
- `Config.MINIO_USABLE` 优先读环境变量 `MINIO_USABLE`，其次 `config.properties` 的 `minio.usable`。
- 两个实现类都实现 `IFileUploadService`，但内部调用链不同（FastDFS 走 `FastDFSService`，MinIO 走 `MinioService`）。

## FastDFS 上传：10M 分档

`FastDFSService.upload`（`core/fdfs/FastDFSService.java`）按文件大小分档：

| 大小 | 路径 | 说明 |
|---|---|---|
| ≤10M | `storageClient1.upload_file1(filePath, extension, meta)` | 一次性上传 |
| >10M | `uploadFileByChunk`（`filechunksize = 10485760L`，10M 一块） | 断点续传式分块上传 |

删除走 `FastDFSService.deleteRemoteFile(group, remote_filename)`，先由 `FastDFSFileUploadServiceImpl.deleteRemoteFile` 用正则 `.*(group[\d]+)\/(.*)` 从 URL 提取 group 与 M00 相对路径。

## MinIO 上传

`MinioService.upload`（`core/minio/MinioService.java`）：S3 兼容对象存储，objectName 形如 `bucket/yyyyMMdd/...`。删除走 `MinioFileUploadServiceImpl.deleteRemoteFile` 用正则 `^https?://[^/]+/(?<bucketName>[^/]+)/(.*)$` 提取 bucket 与 objectName 后调 `MinioService.delete`。

## URL 拼接（两后端一致）

对外 URL = `Config.getPublicFileBaseUrl()` + 存储返回的 fileId/objectName：

- MinIO 模式 `getPublicFileBaseUrl()` 取 `MINIO_BASE_URL`；FastDFS 模式取 `TRACKER_SERVICE_PATH`；
- 原始文件名非空时追加 `?filename={fileName}.{suffix}`（`FastDFSFileUploadServiceImpl.up` / `MinioFileUploadServiceImpl.upLoadFileToRemote`）。

`getPublicFileBaseUrl()` 为空时抛 nodeInitializing 错误（OEM 初始化未完成）。

## 分片合并（存储侧）

两个实现类的 `merge` 逻辑一致：按分片文件名数字排序（数字用数值比较，非数字用字符串比较），`FileChannel.transferTo` 逐片拼到目标临时文件，再上传并删除分片目录。

注意区分两条合并路径：

| 路径 | 入口 | 合并方式 |
|---|---|---|
| V1 `File.merge` | `cn.testin.service.fs.File.merge` | 投递 `FileMergeUtils` 队列，`FileMergeThread` 异步合并 |
| V3 `AppUploadController.mergeChunk` | `/app/mergeChunk` | Controller 内同步合并后进责任链 |

## 删除与清理

文件删除不是单一入口，分几类（详见 [横切-后台线程全景](横切-后台线程全景.md)）：

| 途径 | 触发 |
|---|---|
| `OperationController`（`/operation/delete`） | 手动删除，本地 + 远程存储 |
| `FastDFSFileUploadServiceImpl.deleteRemoteFile` / `MinioFileUploadServiceImpl.deleteRemoteFile` | 各清理 worker 调用的底层删除 |
| `DeleteRemoteFileByExpireTimeWorker` | 定时清理 common_file 超期文件（代码注释标 TODO MINIO 上线后移除） |
| `DeleteRemoteFileExecutorWorker` | 从 Redis SET 取 URL 删除 |
| `CleanResultScheduleWorker` | 清理过期 script_result 的 FastDFS 文件 |
