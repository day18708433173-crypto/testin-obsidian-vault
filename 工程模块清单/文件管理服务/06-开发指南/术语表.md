# 术语表

> 按拼音/字母排序。每条给"一句话定义 + 深入阅读"。代码标识（表名/类名/队列名）保留原名。

## A

**ApiServlet** — 原生 Servlet 兜底入口（`/*`），按 `action=fs&op=类.方法` 反射调用 `cn.testin.service.fs.*`，兼容旧调用方。见 [00-首页](../00-首页.md)。

**appUrl / scriptUrl** — 文件在平台上的流转凭证：文件实体只存一份（FastDFS/MinIO），全链路只传 URL，消费方自行下载。拼接规则见 [App包上传与解析实现](../03-实现逻辑/App包上传与解析实现.md)。

## B

**BizCode** — 上传业务编码枚举（`filecloud/common/enums/BizCode`），如 `parseApp`，责任链处理器按它 + 扩展名匹配。

## C

**common_file** — 文件注册中心表：所有上传文件的 MD5、URL、大小、过期时间统一登记，package_file / script_file / script_result 均以 `fileid` 挂靠。见 [common_file](../../数据库管理/db_file/common_file.md)。

**common_app** — 应用注册表，以 `(packageName, platformId, ostype)` 唯一；注意其 `appMd5` 列实际存 Android RSA 签名。

## D

**db_file** — 文件域 MySQL 库，与脚本服务（filesystem）共享；db_mq 为通知消息库。见 [表关系总览](../02-技术架构/表关系总览.md)。

## F

**FastDFS / MinIO** — 两套文件实体存储后端，由 `Config.MINIO_USABLE` **部署期二选一**（`FileUploadServiceFactory`），不是运行时主备兜底。见 [开发指南](开发指南.md)。

**分片上传（Chunk Upload）** — 大文件上传方式：`/app/checkChunk` → `/app/upload` → `/app/mergeChunk`，fileMark 标识同一文件的分片目录。见 [核心链路-分片上传](../04-复杂功能细节/核心链路-分片上传.md)。

## H

**HAP** — 鸿蒙应用包格式，与 APK/IPA 共用 App 解析链路（`HapFileProcessor` / `HapUtil`）。

## J

**校验引擎** — 脚本异步校验子系统：Redis 队列 `:fileupload:script.check` + `ScriptDispatchThread` 消费 + URL/步骤/依赖三类校验 Task，结果写 script_check。见 [脚本校验引擎实现](../03-实现逻辑/脚本校验引擎实现.md)。

**脚本服务（filesystem）** — 与本服务共享 db_file 的姊妹工程：本服务管文件"进"（上传/解析/校验），脚本服务管脚本"用"（查询/编辑/版本）。

## M

**MD5 查重** — 上传时按文件 MD5 命中 common_file 即复用已有存储与 URL，不重复占用存储；查重跨用户（uid 条件已被注释）。见 [App包上传与解析实现](../03-实现逻辑/App包上传与解析实现.md)。

## P

**package_file** — App 版本包表（appid + fileid），一个应用多个版本包，按 project_id + isdelete 做项目级查重。

**ParseAppUtils** — 多平台 App 解析统一入口，内部按平台分派 ApkUtil(AAPT) / PlistHandler / HapUtil。

## R

**责任链（FileProcessFactory）** — 上传处理器链：各处理器 `@ProcessorOrder` 排序，`care()` 命中即独占处理。见 [横切-文件上传责任链](../04-复杂功能细节/横切-文件上传责任链.md)。

## S

**ScriptCheckTask** — 脚本校验任务载体（gson 序列化进 Redis 队列），携带 scriptFile、scriptUrl、步骤列表、requestId、重试/传播标记。见 [脚本校验引擎实现](../03-实现逻辑/脚本校验引擎实现.md)。

**script_check / script_check_status_sync** — 校验结果表 / 校验状态同步表：前者存结果 JSON 与总状态，后者按 scriptNo 保留最新状态供同步用例侧。

**script_relation** — 脚本父子调用关系表，校验引擎据此做依赖检测与父脚本传播重检。

**sid** — 主平台会话凭证，`/file/upload-app` 等端点经 `AuthApi.getUserOnline(sid)` 换 uid/eid。

**suite（应用）** — 平台上的"应用"实体；上传 App 后通过 `SuiteApi.bind` 把 package_file 绑定到 suite（suite_app 表）。

## T

**Token（upload_service_auth）** — 开放上传的服务鉴权体系：`/token/registerService` 注册私钥，`/token/get` 签发上传凭证。

## Y

**延迟队列** — 校验重试队列 `:fileupload:script.check:delay`，靠任务上的 handleTime + 消费线程 sleep 实现延迟（当前实际为 6 秒，注释写 1 分钟）。见 [脚本校验引擎实现](../03-实现逻辑/脚本校验引擎实现.md)。
