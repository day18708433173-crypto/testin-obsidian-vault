# 设备控制中心 模块索引

> 云真机平台控制中心：与上位机（ucom）长连接、设备管理（App/Web/Pc/鸿蒙）、任务下发与结果回报、设备在线统计。
> 三入口：16 个 Spring MVC Controller + 30 个 ApiServlet service + 23 个 MINA TCP 长连接 handler，按功能域组织。
