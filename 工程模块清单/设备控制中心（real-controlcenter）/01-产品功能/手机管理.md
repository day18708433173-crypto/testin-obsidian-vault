# 手机管理

> 界面入口：顶部左侧菜单「App自动化管理 > 手机管理」，路由 `/platform/app/device/list`。接口 `GET /openapi/v3/ControlCenter/device/list`（设备控制中心，`device_type=1` 手机）。

真机设备的列表与状态管理：展示接入平台的手机设备（上位机 IP、设备 ID/别名、品牌、机型、系统类型、状态、电池温度、位置、备注），支持节能模式批量开关与「真机调试」入口。

## 核心能力

- **设备列表**：按上位机 IP / 设备 ID / 设备别名 / 品牌 / 机型 / 系统类型 / 状态筛选，列表展示设备别名、品牌、机型、设备 ID、版本、上位机 IP、节能模式、真机调试、状态、异常信息、位置、备注、电池温度。
- **节能模式**：批量开启 / 关闭节能模式。
- **真机调试**：从设备列表进入该设备的真机调试（`/platform/realmachine`）。

## 界面字段

| 字段 | 说明 |
|---|---|
| 上位机 IP | 设备所连上位机地址 |
| 设备 ID / 设备别名 | 设备唯一标识与别名 |
| 品牌 / 机型 / 系统类型 | 设备硬件信息 |
| 状态 | 空闲 / 占用等 |
| 节能模式 | 是否开启节能 |
| 异常信息 | 设备异常提示 |
| 位置 / 备注 | 设备物理位置与备注 |
| 电池温度 | 设备电池温度 |

## 接口入口

| 接口 | 说明 |
|---|---|
| `GET /openapi/v3/ControlCenter/device/list` | 设备列表查询，入参 `project_id`、`device_type=1`（手机）、`type=2`、分页 |
