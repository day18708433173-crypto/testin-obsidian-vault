# 术语表

> 设备控制中心（real-controlcenter）概念速查。按拼音/字母排序，每条"一句话定义 + 深入阅读"。

## A

**action** — ApiServlet V1 协议的一级分发字段，对应 `cn.testin.service.<action>` 包（control/device/client/pc/db/monitor/appointment…）。见 [开发指南](开发指南.md)。

**ApiServlet（V1）** — 本服务的 HTTP 老协议入口（`/*`），报文形如 `{action, op, data}`，反射调用 service 层方法；与 Spring MVC（/v3）、MINA TCP 三入口并存。见 `real-controlcenter/src/main/java/cn/testin/startup/Boot.java`。

## C

**CachePool（设备池）** — 内存态设备运行池：DevicePoolUtil / PcInfoPoolUtil / ClientInfoPoolUtil 三个，缓存设备状态与 DeviceTaskInfo 任务标记；DB 是持久层，两者由心跳与 Worker 线程双向同步。

**ClientInfo（PC 客户端）** — resourceType=pc 的资源形态，跑自动化客户端的 PC（含鸿蒙 PC，挂在来源上位机下），主键 pcId，落 db_client.client_info。

## D

**device_lock_pool（设备锁池）** — db_device 中的任务级互斥锁表：taskId + deviceId/ucomId 一行一把锁，下发前校验、任务结束删除；无自动过期，残留是高危运维点。见 [设备锁与心跳实现](../03-实现逻辑/设备锁与心跳实现.md)。

**DEVICE_TIMEOUT** — 设备心跳超时常量，默认 120000ms（`real-controlcenter/src/main/java/cn/testin/util/Config.java`），`device.timeout` 可覆盖；超时即判离线。

**DeviceProcess（占用）** — 设备被调试/任务占用的过程记录（App 用 device_process、Web 用 browser_process、Pc 用 client_process）；非测试类占用会被 `releaseByAbnormal` 异常回收。见 [核心链路-设备异常恢复](../04-复杂功能细节/核心链路-设备异常恢复.md)。

**DeviceTaskInfo / sstask** — 内存池中设备的当前任务标记：taskid/subtaskid + 子子任务（subsubtaskid）集合；precomplete/reportResult 逐个 `removeSstask`，清空即释放。见 [任务下发与结果回传实现](../03-实现逻辑/任务下发与结果回传实现.md)。

**deviceid / ucomid / pcId** — 三类资源主键：真机 deviceid、上位机/浏览器 ucomid、PC 客户端 pcId。

## J

**机柜（cabinet）** — 设备托管的物理机柜配置（cabinet_space_cfg），设备资产管理的一部分。

## M

**mkey** — 长连接/协议报文的模块键（如下发任务的 `mkey="script"`），与 op 一起做二级分发。

**ModuleNodeId** — 模块节点号（config.properties `module.node.id`），多实例部署时按它隔离协议表与队列归属；缺失时服务拒绝启动（`Boot.java`）。

## O

**op** — 协议二级分发字段，如 `Task.distributeTask`（ApiServlet）/ `Task.execute.v2`（下发给上位机）/ `Authentication.confim`（长连接认证，注意 confim 是历史拼写）。

## P

**PccProtocol（协议）** — 本服务"请求-响应异步化"的载体表：下发指令先落协议行（type=activity/passivity，status=pendingRequest），ProtocolDispatchThread 送上长连接，响应回来回填 resContent。见 [核心链路-上位机长连接](../04-复杂功能细节/核心链路-上位机长连接.md)。

**precomplete（预完成）** — 上位机脚本执行完的即时回报（`/UcomDeivce/task/precomplete`），携带 runinfo 与输入/输出参数；转发任务侧后清理 sstask 标记。见 `real-controlcenter/src/main/java/cn/testin/business/impl/TaskInfoServiceImpl.java`。

## R

**reportResult（结果回报）** — 上位机结果产物就绪后的最终回报，携带 resultUrl/retryNum；`retryNum=0` 才清池标记。见 `TaskInfoServiceImpl.java`。

**resourceType** — 下发资源类型：`app`（真机）/ `web`（浏览器）/ `pc`（客户端），`Task.distributeTask` 按它分三个校验分支。

## S

**sessionKey** — 协议/长连接的寻址键，通常等于 ucomid；鸿蒙 PC 场景会改写为来源上位机（`fromUcomDevice`，`Task.java`）。

**上位机（ucom）** — 托管机房里挂载真机的宿主机器（PC/树莓派），MINA TCP 长连接的连接主体；以 ucomid 标识。见 [核心链路-上位机长连接](../04-复杂功能细节/核心链路-上位机长连接.md)。

## T

**Task.execute.v2** — 下发给上位机的任务执行指令 op；由 `Task.distributeTask` 组装（`real-controlcenter/src/main/java/cn/testin/service/control/Task.java`）。

**taskid / subtaskid / subsubtaskid** — 任务三级 ID：任务 / 子任务（通常对应一台设备）/ 子子任务（通常对应一条脚本）；taskid 前缀 `tt/wt/pt` 标记老任务调度服务体系，结果回报按此前缀分流。见 [任务下发与结果回传实现](../03-实现逻辑/任务下发与结果回传实现.md)。

## Y

**预约（appointment）** — 设备时段预约（device_appointment/device_appointment_config），AppointmentWorkerThread 每 5 分钟处理；心跳线程维护设备当前预约者。见 [功能总览](../01-产品功能/功能总览.md)。

## Z

**真机（device）** — App 资源形态的被测手机/平板，挂在上位机下，device_info 主档 + 三个视图。见 [db_device 表索引](../../数据库管理/db_device/00-表索引.md)。
