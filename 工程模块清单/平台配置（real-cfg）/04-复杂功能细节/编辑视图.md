# 编辑视图

## 主题定位

「编辑视图」是运营采编侧可配置的视图模板（`realcfg_editing_view`），供采编/门户按模块加载不同的编辑界面。属于**极薄的 DAO 直读直写**配置，无缓存、无广播。

## 入口与数据

入口 `EditingView`（ApiServlet action=cfg），业务实现 `EditingViewServiceImpl`（`cn.testin.business.impl`），POJO `RealcfgEditingView`，表 `realcfg_editing_view`。

关键字段：`key`（视图标识，add 时必填）、`module_name`（所属模块）、`status`（启用状态），其余为视图内容/描述。

## 方法

| op | 方法 | 说明 |
|---|---|---|
| add | `EditingViewServiceImpl.add` | 校验 `key` 非空后 `irealcfgeditingviewdao.insert` |
| remove | `EditingViewServiceImpl.remove` | 按 id `delete` |
| modify | `EditingViewServiceImpl.modify` | 校验 `id` 非空后 `update` |
| get | `EditingViewServiceImpl.getEditingView(id, key)` | id/key 至少一个，`get` 单条 |
| list | `EditingViewServiceImpl.getEditingViewList(moduleName, status)` | 按模块名 + 状态 `list` |

## 要点

- 全部直接透传 `IRealcfgEditingViewDAO`（JDBC 老栈），无额外业务规则，无变更广播。
- `get` 支持 id 或 key 二选一（两者都空才报 `paraInvalid`）。
