# 术语表

> 按拼音/字母排序。每条给"一句话定义 + 深入阅读"。

## A

**action / op** — 老接口协议的两个路由字段：HTTP body JSON 里 `action` 选 service 包（cfg/mcfg/scfg/group/portal），`op` 为 `类名.方法名`（如 `EnvCfg.get`），由 ApiServlet 反射分发。见 [配置读取与缓存实现](../03-实现逻辑/配置读取与缓存实现.md)。

**ApiServlet** — real-common 提供的通用分发 Servlet，real-cfg 把它挂在 `/*`（`Boot.java`），承载 32 个 service 类；与 `/v3/*` 的 Spring MVC 并存。

## C

**configKey** — 菜单功能点（`service_function`）的权限标识串；`control%` 前缀代表设备控制中心功能，`switch` 是保留 key（列表查询被过滤）。见 [权限体系实现](../03-实现逻辑/权限体系实现.md)。

## D

**dsRealcfg / dsMcfg / dsService / dsUser / dsMq** — 数据源 cfgKey，在 `cfg/db/config.json` 声明，启动时由 `DbConfigUtil.loadConfig()` 装配成 proxool 连接池 bean。见 [开发指南](开发指南.md)。

## G

**功能点（service_function）** — 平台菜单/按钮的权限点，树形组织（`parent_id`：0=根目录，-1=菜单附属子操作），角色绑定存 `service_role_function`。见 [权限体系实现](../03-实现逻辑/权限体系实现.md)。

**功能开关** — 两类含义：① `realcfg_function_switch` 表的全局功能启停配置；② `ServiceCfg.openCloseFunction` 按 configKey 前缀级联启停功能点。见 [权限体系实现](../03-实现逻辑/权限体系实现.md)。

## J

**机型档案（Model）** — 手机型号主档（`realcfg_model`），与品牌（`realcfg_brand`）通过视图 `view_model_brand` 关联；区别于设备机型绑定表 `realcfg_device_model`。

## M

**mcfg** — `db_mcfg` 库及同名 action：OpenAPI 侧的角色（`mcfg_role`）、接口（`mcfg_api`）、模块（`mcfg_module`）、应用（`mcfg_app`）配置。见 [权限体系实现](../03-实现逻辑/权限体系实现.md)。

**MODULE_NODE_ID** — 模块节点编号（如 1010001），必须以 `module.id`(101) 开头；通知消息按它做节点隔离，非法值直接拒启（`Boot.java`）。见 [配置读取与缓存实现](../03-实现逻辑/配置读取与缓存实现.md)。

## O

**OEM** — 定制化部署；`ScfgServiceImpl` 通过 `OemApi` 读 core 的系统参数（如 `oem_python_show`）动态裁剪功能菜单。见 [权限体系实现](../03-实现逻辑/权限体系实现.md)。

## S

**设备云（主云 / 子云）** — 设备的调度分组：主云是企业级设备池，子云（`parent_name` 指向主云）挂在主云下；设备与云的绑定存 `realcfg_device_cfg` 的 JSON 数组列。见 [功能总览](功能总览.md)。

**上位机（ucom / ucomid）** — 连接真机的宿主机器；`realcfg_pc_cfg` 存其默认设备云配置，`realcfg_pc_account` 存账号；`GET /v3/realcfg/ucomid` 提供幂等开通。见 [UcomIdController](../07-开放接口文档/基础设施与问题管理/UcomIdController.md)。

**双入口** — 一个进程两套 Servlet：ApiServlet（`/*`，老协议）+ Spring MVC（`/v3/*`，新 REST）。见 [配置读取与缓存实现](../03-实现逻辑/配置读取与缓存实现.md)。

## T

**通知（Notice / redismq）** — 配置变更广播机制：`NoticeUtil.sendNotice` 发 redismq，失败落 `mq_info_notice` 由 200ms 轮询重发；类型见 `CfgConfigEnum.NoticeType`（cleanSource/cleanDeviceCfg/resendNotice）。见 [配置读取与缓存实现](../03-实现逻辑/配置读取与缓存实现.md)。

## X

**项目组（ProjectGroup）** — 企业项目（eid+projectid+type）到设备子云的映射（`realcfg_project_group.devicegroupid`），决定项目能用哪些真机，含 `expiretime` 过期时间。

## Y

**错误归因（error_cause_*）** — 测试失败原因规则库：错误类型（`error_cause_type`）、错误日志（`error_cause_log`）、匹配规则（`error_cause_match_rule`）、操作日志（`error_cause_operate_log`），按 eid+project_id 隔离。

**云服务（上位机云配置）** — 上位机默认携带的主云列表（`realcfg_pc_cfg.clouds`，JSON 数组）；设备未自定义主云时跟随上位机配置。见 [DeviceCfg](../07-开放接口文档/设备与网络配置/DeviceCfg.md)。

## Z

**主云跟随** — 设备自定义主云与上位机配置一致时，`realcfg_device_cfg.clouds` 置空数组表示"跟随上位机"（`DeviceCfgServiceImpl.java`）。
