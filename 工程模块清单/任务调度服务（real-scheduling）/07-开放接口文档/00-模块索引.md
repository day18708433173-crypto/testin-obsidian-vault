# 任务调度服务 模块接口文档索引

> 任务调度服务：任务基础信息初始化、设备匹配与分发、任务调度、报告处理。
> 双入口：3 个 Spring MVC Controller + 3 个 ApiServlet service + 1 个全局异常处理，按功能域组织。

## 核心链路

### 任务初始化
```
RealTest -> [Task.init] -> ITaskService.init()
  -> validateTaskdetail -> initTask -> checkExistData
  -> INSERT task_info_extra -> batchInsert task_info -> batchInsert task_sub_info
  -> INSERT task_release_time_periods -> MQ INIT通知 -> TaskDispatchThread
```

### 设备匹配
```
RealControlCenter(设备心跳) -> [Task.match] -> ITaskService.receive/match
  -> prematch(ES预匹配) -> checkMatchTaskInfos(加锁+防重)
  -> INSERT task_exec_relation -> matchtask(变量验证)
  -> UPDATE task_info(execStatus=ING) -> callCreate(梆梆回调)
```

### 结果上报
```
设备端 -> [Task.precomplete] -> ITaskService.precomplete
  -> UPDATE task_sub_info(execStatus=2) -> 释放账号
设备端 -> [Task.reportResult] -> IResultService.report
  -> INSERT task_result -> MQ解析通知
  -> ResultDispatchThread -> ResultHandlerThread -> RealAnalysis解析
```
