# 核心链路-用户登录

> 基于 平台基础功能服务 syy.release.z7.8.1.0 代码分析

```mermaid
flowchart TD
    A["POST /?action=user&op=Login.login"]
    B["1. 解析参数<br/>landingMode/email/loginMobile/pwd/channel/ip"]
    C["2. landingMode 分流"]
    D["LDAP: AdAuthUtil.auth 认证<br/>按 oem_ldap_init_user 参数<br/>用户不存在时 initBydUser 初始化"]
    E["SSO: 取本地用户并复用其存储密码<br/>（此处无外部 SSO 验证）"]
    F["密码(testPro): 直接用请求密码"]
    G["3. UserService.login"]
    H["checkUserLoginCount + 查用户<br/>(email/登录手机号)"]
    I["状态校验 STATUS_OFF/STATUS_DISABLE<br/>密码比对(明文 equals)"]
    J["密码错误次数锁定<br/>MAX_USER_LOGIN_COUNT=5 → 锁30分钟"]
    K["eid 匹配 + 在线互踢/过期处理"]
    L["4. DbUserOnline.generateSid 生成 SID<br/>写入 MySQL user_online 表（非 Redis）"]
    M["5. 登录后锁定检查<br/>NOT_ACTIVE + OEM_LOCK_USER 时间锁定"]
    N["6. 更新 loginTime / 记录登录日志"]
    O["7. 返回 SID"]

    A --> B --> C
    C -->|ldap| D
    C -->|SSO| E
    C -->|testPro| F
    D --> G
    E --> G
    F --> G
    G --> H --> I --> J --> K --> L --> M --> N --> O
```

## 关键代码位置

- `ApiServlet.java` — 统一入口，`action=user&op=Login.login` 反射路由
- `cn.testin.service.user.Login` — 登录入口：landingMode 分流（ldap/SSO/testPro）、`initBydUser` LDAP 初始化、登录后锁定检查（`NOT_ACTIVE` / `OEM_LOCK_USER` 时间锁定）、更新 loginTime 与登录日志
- `cn.testin.business.impl.user.UserService.login` — 登录核心：`checkUserLoginCount`、按 email/登录手机号查用户、状态校验（`STATUS_OFF`/`STATUS_DISABLE`）、密码比对、错误次数锁定（`MAX_USER_LOGIN_COUNT=5` → 锁 30 分钟）、eid 匹配、在线互踢/过期处理、`DbUserOnline.generateSid` 生成 SID 并写入 `user_online` 表
- `cn.testin.util.ldap.AdAuthUtil` — LDAP/AD 认证（JNDI）
- `cn.testin.dao.user.IUserOnlineDAO` / `db_user.user_online` 表 — SID 在线会话持久化（MySQL，非 Redis）
- `IUserLoginLogService.insertUserLoginLog` — 登录日志记录
