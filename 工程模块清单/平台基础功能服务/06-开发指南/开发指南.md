# 开发指南

> 工程：testin-core（Java 1.8 / Spring Boot 2.3.7.RELEASE，Maven 单模块，artifactId `testin-core`，version 6.0.0）。服务显示名"平台基础功能服务"。先读 [横切-双入口路由机制](../04-复杂功能细节/横切-双入口路由机制.md) 建立入口认识。

## 工程结构

```
src/main/java/cn/testin
├── startup/         启动类 Boot（注册双 Servlet + Filter，排除 Mongo/ES 自动装配）
│   └── interceptor/ 拦截器
├── controller/      Spring MVC 入口（/v3/* 前缀，约 39 个 Controller）
│   ├── plan/        测试计划（13 个：PlanInfo/SubPlanInfo/PlanTask/ExecuteRecord(Task)/策略/设备/定时/周期…）
│   ├── testCase/    测试用例（6 个）
│   ├── notice/      通知 + notice/ops/ 运维告警
│   └── dir|disk|bi|log|quartz + 根级（HeartBeat/Task/Project/User/Enterprise/Report…）
├── service/         ApiServlet 入口（action/op 反射调用，user/email/sms/http/channel/qc/portal/audit…）
├── business/        业务逻辑层（interfaces 接口 + impl 实现）
│   ├── impl/plan/   ExecuteRecordTaskServiceImpl（3300+ 行核心）、PlanInfoServiceImpl、ExecuteRecordServiceImpl
│   └── strategy/plan/ 回调策略（CallbackTypeStrategyEnum + 7 实现）
├── schedule/        后台线程（plan/ 计划调度、email|sms|http|msg 通知分发、action MQ、statistic 统计）
├── api/             远程调用封装：ServiceRemoteV1Api（V1 RPC action/op 风格）、ServiceRemoteV3Api（REST）、
│                    realtask/ realtest/ realweb/ controlcenter/ scheduling/ fileSystem/ datasource/ …
├── dao/             MyBatis Plus Mapper 接口（按库分子包：plan/ testCase/ user/ notice/ realportal/ …）
├── pojo/            数据库实体（db.plan/ db.dbCase/ db.user/ db.notice/ …）
├── dto/             DTO；vo/ 视图对象；common/ 常量枚举；config/ Spring 配置；aop/ 切面；util/ 工具
└── sinosoft/        定制包
```

## 双入口路由（写接口前必读）

| 入口 | 路径 | 路由方式 | 落在哪 |
|---|---|---|---|
| ApiServlet | `/*`（兜底） | `action=包名` + `op=类.方法`，反射调用 | `cn.testin.service.{action}.*` |
| DispatcherServlet | `/v3/*` | Spring MVC 注解路由 | `cn.testin.controller.*` |

注册点在 `Boot.java`（`src/main/java/cn/testin/startup/Boot.java`）：`dispatcherMvcServlet` 映射 `/v3/*`、`cxfServletRegistration` 把 `ApiServlet` 挂到 `/*`。新功能一律写 `/v3/*` Spring MVC Controller；`service/` 下是历史接口，只维护不新增。

## 分层约定

- **Controller**：`@RequestMapping("/<资源>")` + `@PostMapping/@GetMapping`；统一返回 `ResponseResult<T>` 包装；参数用 `@Valid` + DTO。
- **business**：接口放 `business/interfaces/`，实现放 `business/impl/`；跨库事务用 `@DS(Constants.DB_XXX)` 标在方法上（dynamic-datasource，默认 `db_user`）。
- **dao**：MyBatis Plus Mapper 接口，按库分包子；**XML 不放接口同目录**，统一放 `src/main/resources/mybatis/mapper/**`（`mapper-locations: classpath*:mybatis/mapper/**/**.xml`，application.yml）；`map-underscore-to-camel-case: true`，列名下划线、字段驼峰。
- **pojo**：实体按库分包（`pojo/db/plan`、`pojo/db/dbCase`、`pojo/db/user`…），`type-aliases-package: cn.testin.pojo`。
- **枚举/常量**：进 `common/enums/`（如 `TaskTypeEnum`、`PlanExecuteStatusEnum`、`RecordTaskTypeEnum`、`TaskCallbackTypeEnum`），新状态先复用现有枚举。
- **远程调用**：V3 REST 走 `ServiceRemoteV3Api` + `api/{服务}/XxxV3Api` 封装；V1 RPC 走 `ServiceRemoteV1Api.remoteApi(action, op, prefix, request, respType)`；服务地址不在代码里写死，统一从 `service.api.properties` 按前缀名取（`ApiUtil.getServiceApiUrl`）。

## 本地构建与运行

```bash
mvn clean package          # 产物在 target/testin-core/ 下：testin-core.jar + config/ + lib/
java -jar testin-core.jar  # 或 IDE 直接跑 cn.testin.startup.Boot.main
```

- **打包布局**（pom.xml build 段）：`src/main/resources` → `target/testin-core/config/`；工程根 `lib/`（maven 没有的本地 jar）→ `target/testin-core/lib/`；jar manifest 指定 `mainClass=cn.testin.startup.Boot`、`classpathPrefix=lib/`、附加 `Class-Path: config/`——**配置文件全部外置在 config/ 目录**，改配置不用重打 jar。
- **启动脚本**：`src/main/resources/bin/startup.sh`（`java -Xms1024m -Xmx1024m ... -jar testin-core.jar`）。
- **端口**：`server.port=8080`（Undertow 容器）。
- **启动前置**：`Boot.main` 先 `Config.loadConfig()`（加载 config.properties），再 `DbConfigUtil.loadConfig()`，失败直接退出不起 Spring——本地起不来先看这两个加载是否成功。
- **测试**：surefire 默认 skip（`<skip>true</skip>`），单跑用 `mvn test -DskipTests=false -Dtest=ClassName`。

## 配置要点

| 文件 | 内容 |
|---|---|
| `src/main/resources/application.yml` | 9 个数据源（dynamic-datasource + Druid，initial=10/max=40）、Redis（Jedis 池）、mybatis-plus、Quartz、日志 |
| `src/main/resources/config.properties` | 业务路径（log/tmp/通知模板）、LDAP 连接、邮件账号（sendcloud）、文件上传地址 |
| `src/main/resources/service.api.properties` | **全部下游服务地址**（RealTask/RealTest/RealWeb/ControlCenter/RealScheduling/File/Script/DataSource…），环境差异靠部署替换 |
| `src/main/resources/real.common.properties` | real 侧公共配置 |
| `src/main/resources/log4j2.xml` | Log4j2 异步日志（Boot.main 首行设 Disruptor `AsyncLoggerContextSelector`） |
| `src/main/resources/cfg/spring/spring-EsDB.xml` | ES RestHighLevelClient 注入（`@ImportResource` 引入，Boot 同时排除 ES 自动装配） |

- 数据源连接用 `${ENV_VAR:default}` 形式（如 `${TESTINPRO_MYSQL_HOST:mysql.pro.testin.cn}`），密码 Jasypt `ENC(...)`；本地开发靠环境变量覆盖。
- Quartz 是 **RAMJobStore 内存调度**（`PlanInfoScheduledConfig.java` 注释明确"没有指定数据库"），`instanceName=plan_info_scheduled`、线程池 20，可用环境变量覆盖——**重启即丢 Job**，计划定时任务靠 db 里的 `plan_info_scheduled` 表重建。
- 多数据源切换：`@DS` 注解，默认 `db_user`；跨库 JOIN 不存在，跨库查询在代码里分两次查。
- 异步线程池集中在 `config/AsyncConfig.java`（13 个，如 `executeTaskExecutor`、`preTestTaskExecutor`、`emailNoticeExecutor`、`callBackUrlExecutor`），`@Async` 必须指定池名。

## 新增一个功能的标准流程

1. 实体放 `pojo/db/<库>/`，DTO 放 `dto/`；
2. Mapper 接口放 `dao/<库>/`，XML 放 `resources/mybatis/mapper/<库>/`；
3. 业务接口/实现放 `business/interfaces|impl/<域>/`；状态/类型枚举进 `common/enums/`；
4. Controller 放 `controller/<域>/`，路径 `/v3/<资源>` 风格；
5. 涉及下游调用的，在 `api/<服务>/` 加封装方法，地址前缀在 `service.api.properties` 登记；
6. 后台驱动逻辑：简单轮询用 `@Scheduled`（schedule/ 目录，注意抢 Redis 锁防多实例并发），计划级 Cron 用 Quartz（参考 `PlanInfoScheduledConfig`）；
7. 回调类协议改动（回调类型/请求 DTO）要评估下游生产方（任务管理服务 / app处理服务 / web/pc处理服务）同步发版。

## 跨服务修改红线

| 修改对象 | 影响 | 要求 |
|---|---|---|
| 回调 DTO / `TaskCallbackTypeEnum` | 下游→本服务协议 | 两端同改同发版；新增类型还要改 `CallbackTypeStrategyEnum` + `InitCallBackStrategy` |
| `TaskExecuteRecordExecuteRequestDTO` 等提测 DTO | 本服务→任务管理服务/app处理服务 协议 | 同上 |
| V1 RPC action/op 常量（`RemoteApiConstants`） | 旧链路寻址 | 旧服务无版本概念，只可加不可改 |
| `service.api.properties` 前缀名 | 服务寻址 | 全工程引用同一 key，改名全局搜 |
| `execute_record_task` 状态值（`PlanExecuteStatusEnum`） | 前端展示 + 各线程扫描条件 | 11/12/14 子状态对前端映射逻辑同步改 |
