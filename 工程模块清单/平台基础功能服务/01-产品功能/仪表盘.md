# 仪表盘

> 界面入口：顶部左侧菜单「仪表盘」（顶级菜单），路由 `/platform/dash-board/project-statistics`。数据由前端聚合多个服务统计接口，页面本身属平台基础功能服务域。

项目 / 用户维度的数据统计看板，聚合脚本、用例、任务执行等指标，用于度量自动化测试产出与质量。

## 核心能力

- **项目统计**：按统计维度（App 脚本 / Web 脚本 / 桌面脚本 / 测试用例）+ 查询时间范围，展示数据总览。
- **用户统计**：按用户维度统计产出。
- **数据总览指标**：用例数、新增脚本数、更新脚本数、任务执行完成数等。

## 界面字段

| 区域 | 字段 | 说明 |
|---|---|---|
| Tab | 项目统计 / 用户统计 | 统计口径切换 |
| 筛选 | 统计维度 | App脚本 / Web脚本 / 桌面脚本 / 测试用例 |
| 筛选 | 查询时间 | 时间范围 |
| 总览 | 用例数 | 用例总量 |
| 总览 | 新增脚本数 / 更新脚本数 | 脚本产出 |
| 总览 | 任务执行完成数 | 任务执行完成量 |

## 数据来源接口（前端聚合）

| 接口 | 归属服务 | 指标 |
|---|---|---|
| `GET /openapi/v3/script/scripts/count` | 脚本服务 | 脚本数量（按 `script_type`） |
| `GET /openapi/v3/script/scripts/tag_count` | 脚本服务 | 脚本标签统计 |
| `GET /openapi/v3/test_plan/execute_records/plan_infos` | 平台基础功能服务 | 测试计划执行（`plan_info_type`） |
| `GET /openapi/v3/task/execute/finish_count` | 任务管理服务 | 任务执行完成数（`task_type`） |
