# 日志管理

> 界面入口：顶部左侧菜单「项目管理 > 日志管理」，路由 `/platform/log-manage`。接口 `OperateLogController`（`@RequestMapping("/log")`，testin-core）。

记录用户在平台上的操作日志，用于审计与问题定位。页面按「自动化类型」（App / Web / 桌面 / 其他）分 Tab，展示每条操作的对象、类型、内容、操作人、操作时间，支持按操作对象 / 操作类型 / 操作时间筛选，并可查看单条日志详情。

## 核心能力

- **操作日志查询**：列表展示操作对象、操作类型、操作内容、操作人、操作时间，支持条件筛选与分页。
- **操作对象 / 操作类型字典**：操作对象、操作类型由字典接口下发，保证筛选口径一致。
- **操作详情**：点击「查看日志」查看单条操作的完整内容（如「终止任务执行记录，任务执行记录名称：xxx」）。

## 界面字段

| 区域 | 字段 | 说明 |
|---|---|---|
| 筛选区 | 自动化类型 | App / Web / 桌面 / 其他（Tab） |
| 筛选区 | 操作对象 | 操作对象字典 |
| 筛选区 | 操作类型 | 操作类型字典 |
| 筛选区 | 操作时间 | 时间范围 |
| 列表 | 操作内容 | 操作具体描述 |
| 列表 | 操作人 | 触发操作的用户 |
| 列表 | 操作时间 | 操作发生时间 |

## 接口入口

| 接口 | 说明 |
|---|---|
| `GET /openapi/v3/log/logs`（`OperateLogController` `@GetMapping("/logs")`） | 操作日志分页查询，入参 `module_type`（自动化类型）、`project_id` |
| `GET /openapi/v3/log/logs/operate_objects` | 操作对象字典 |
| `GET /openapi/v3/log/logs/operate_types` | 操作类型字典 |
| `GET /openapi/v3/log/logs/{operate_log_id}` | 单条日志详情 |
