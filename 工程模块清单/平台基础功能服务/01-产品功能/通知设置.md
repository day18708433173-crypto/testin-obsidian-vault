# 通知设置

> 界面入口：顶部左侧菜单「项目管理 > 通知设置」，路由 `/platform/notice-manage`。接口 `NoticeEventController` / `NoticeChannelCfgController` / `NoticeLogController`（均 `@RequestMapping("/notice")`，testin-core）。

消息通知的事件与渠道配置。定义「什么情况触发通知（通知事件）」+「通过什么渠道发送（通知渠道）」，并留存通知发送历史（通知记录）。

## 核心能力

- **通知事件**：定义事件类型与触发规则（如「任务执行完毕」事件，触发规则「通过率在 0~100% 范围内」），事件触发后按渠道发送。
- **通知渠道**：配置接收通知的方式（企业微信、钉钉、飞书、微软 Teams 机器人等）。
- **通知记录**：通知发送历史，查看发送时间、内容、渠道。
- **创建事件**：新增事件，设置事件类型 + 触发规则 + 通知方式。

## 界面 Tab

| Tab | 说明 |
|---|---|
| 通知事件 | 事件列表：事件类型、触发规则、通知方式，支持编辑/删除 |
| 通知渠道 | 渠道配置（企业微信/钉钉/飞书/Teams 机器人等） |
| 通知记录 | 已发送通知的历史记录 |

## 接口入口

| 接口 | 说明 |
|---|---|
| `GET /openapi/v3/notice/notice/list`（`NoticeLogController`） | 通知记录分页查询，入参 `project_id` |
| `NoticeEventController`（`/notice`） | 通知事件 CRUD |
| `NoticeChannelCfgController`（`/notice`） | 通知渠道配置 |
