# 存储总览

> 表文档统一集中在 [数据库管理](../../数据库管理/00-数据库总览.md) 维护，本页仅列本服务使用的库并做引用。

平台基础功能服务 使用以下存储层：

## MySQL（9 个库）

| 库名 | 用途 | 索引页 |
|------|------|--------|
| [db_user](../../数据库管理/db_user/00-表索引.md) | 用户、企业、项目、权限、SSO 认证 | [00-表索引](../../数据库管理/db_user/00-表索引.md) |
| [db_plan](../../数据库管理/db_plan/00-表索引.md) | 测试计划、执行记录、计划调度 | [00-表索引](../../数据库管理/db_plan/00-表索引.md) |
| [db_case](../../数据库管理/db_case/00-表索引.md) | 测试用例、用例步骤、用例目录 | [00-表索引](../../数据库管理/db_case/00-表索引.md) |
| [db_notice](../../数据库管理/db_notice/00-表索引.md) | 通知渠道（邮件/短信/企微）、消息模板 | [00-表索引](../../数据库管理/db_notice/00-表索引.md) |
| [db_common](../../数据库管理/db_common/00-表索引.md) | 公共数据：操作日志、定时任务、服务器监控、目录信息 | [00-表索引](../../数据库管理/db_common/00-表索引.md) |
| [db_portal](../../数据库管理/db_portal/00-表索引.md) | 真机门户：任务表（分表）、版本条件、执行结果 | [00-表索引](../../数据库管理/db_portal/00-表索引.md) |
| [db_cross](../../数据库管理/db_cross/00-表索引.md) | 跨端任务管理 | [00-表索引](../../数据库管理/db_cross/00-表索引.md) |
| [db_admin](../../数据库管理/db_admin/00-表索引.md) | 后台管理：设备执行日志、角色权限、脚本清理规则 | [00-表索引](../../数据库管理/db_admin/00-表索引.md) |
| [db_bi](../../数据库管理/db_bi/00-表索引.md) | BI 统计：设备使用、脚本使用、任务统计等多维报表 | [00-表索引](../../数据库管理/db_bi/00-表索引.md) |

### 备注：不属于 平台基础功能服务 直接管理的库
以下库在 pocinit 中有 DDL，但不属于 平台基础功能服务 直接管理（由其他微服务负责），此处仅做说明：

- **db_analysis** -- 分析数据（由 analysis 服务管理）
- **db_client** -- 客户端/执行端管理（由 client 服务管理）
- **db_service** -- 微服务注册与配置
- **db_task** -- 任务分发与调度
- **db_device** -- 设备管理
- **db_device_monitor** -- 设备监控
- **db_file** -- 文件存储
- **db_mcfg** -- 配置管理
- **db_mq** -- 消息队列记录
- **db_operations** -- 运维数据
- **db_pc** -- PC 端数据
- **db_real** -- 真机测试数据
- **db_realcfg** -- 真机配置
- **db_source** -- 数据源
- **db_third** -- 第三方集成
- **db_thirdparty** -- 第三方服务

## MongoDB（未直接使用）
平台基础功能服务 自身不直接操作 MongoDB。关联微服务（如 task 服务）使用 MongoDB 存储执行日志等大数据量文档。

## Elasticsearch
- **EsPortalSummary** -- 存储真机门户的测试任务摘要，用于快速检索和聚合统计。
- 相关类：`EsPortalSummaryDAO`、`EsPortalSummaryServiceImpl`

## Redis
- **用途**：缓存、分布式锁、消息队列（Action 事件）、心跳检测、Token 管理
- 相关类：`RedisService`、`JedisConfig`、`RedisKeyConstant`
- 关键 Key 前缀定义在 `RedisKeyConstant` 中（计划信息缓存、设备锁、任务队列等）
