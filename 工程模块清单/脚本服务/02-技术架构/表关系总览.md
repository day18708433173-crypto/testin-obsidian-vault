# 表关系总览

## 数据库

所有表均位于 `db_file` 数据库（MySQL，`mysql.pro.testin.cn:3306`）。

## 核心实体关系

### 脚本（script_file）为中心

```
script_file (脚本主表)
  ├── script_step (步骤, scriptid FK)
  ├── script_step_fast_search (步骤快速搜索, 通过 script_no)
  ├── script_relation (依赖关系, script_id / parent_script_id FK)
  ├── script_third_relation (第三方关联, script_no FK)
  ├── script_tag (标签, script_no FK)
  ├── script_check (校验状态, scriptId FK)
  ├── script_check_status_sync (校验同步, script_id FK)
  ├── script_at_last (最新追踪, script_id FK)
  ├── script_recover_info (恢复信息, script_no FK)
  ├── script_process_data (过程数据, script_no FK)
  ├── script_result (执行结果, 通过 resultfile_id 关联)
  ├── script_dir_child (目录归属, script_no FK)
  └── suite_script (套件关联, scriptid FK)
```

### 目录（script_dir）为中心

```
script_dir (目录表)
  └── script_dir_child (目录-脚本关联, script_dir_id FK)
        └── script_file (脚本, 通过 script_no)
```

### 脚本组（script_group）为中心

```
script_group (脚本组表)
  └── suite_group_script (套件-脚本组关联, groupId FK)
```

### 套件（suite_info）为中心

```
suite_info (套件表)
  ├── suite_script (套件-脚本, suiteId FK)
  ├── suite_group_script (套件-脚本组, suiteId FK)
  ├── suite_app (套件-App, suite_id FK)
  └── suite_resource (套件-AI资源, suite_id FK)
        └── ai_resource (AI标注资源, resource_id FK)
```

### AI 资源标注

```
ai_resource (AI标注资源, 独立主表)
  └── suite_resource (套件关联, resource_id FK)
view_suite_app (视图: suite_info ⋈ suite_app, 用于套件-包匹配校验)
```

### App（common_app）为中心

```
common_app (通用App, appid)
  └── package_file (应用包, appid FK)
        └── suite_app (套件-包关联, pkgid FK)
```

### 文件（common_file）为中心

```
common_file (通用文件)
  ├── script_file (脚本文件, fileid FK)
  ├── package_file (应用包文件, fileid FK)
  └── script_result (结果文件, resultfile_id FK)
```

### 语音管理

```
voice_library (语音库)
  └── voice_content_detail (语音内容, library_id FK)
dbc_file (独立, 无直接外键)
```

### 参数与数据源

```
script_param (脚本参数)
  ├── script_param_data (参数数据源数据, 通过 ScriptParamDataMapper 管理)
  └── script_param_source (参数数据源配置, 通过 ScriptParamSourceMapper 管理)
```

### 控件

```
script_control (脚本控件)
  └── script_control_sequence (控件序列, projectid+appid FK)
```

### 其他独立表

以下表相对独立，通过 projectid、eid 等维度字段与业务关联：

- `form_resource` — 表单资源
- `box_status_info` — Box 状态
- `tab_config` — Tab 配置
- `python_script` — Python 脚本
- `script_action_log` — 操作日志
- `script_bind_config` — 脚本绑定配置
- `app_sub_info` — App 子信息

## 说明

- 数据库未强制使用物理外键约束，以上关系基于业务逻辑和字段命名约定推导。
- `script_no` 是脚本的业务唯一标识号，在多张表中作为关联字段出现。
- `eid`（企业ID）和 `projectid`（项目ID）是常见的多租户隔离维度。
