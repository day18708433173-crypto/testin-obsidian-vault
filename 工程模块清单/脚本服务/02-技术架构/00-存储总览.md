# 脚本服务 存储总览

> 表文档统一集中在 [数据库管理](../../数据库管理/00-数据库总览.md) 维护，本页仅列本服务使用的库并做引用。

本模块使用两类存储：**MySQL（db_file，持久化）** 与 **Redis（任务队列/缓存）**。MongoDB/ES 本模块未使用。

## MySQL：db_file

| 属性 | 值 |
|------|-----|
| 数据库类型 | MySQL |
| 数据库名 | db_file |
| 连接地址 | mysql.pro.testin.cn:3306 |
| 表/视图总数 | 41（40 表 + 1 视图） |

## Redis

任务队列与缓存（`queue:action_log`、`Script.parseKey.queue`、`Script.importKey.queue`、`parseAppQueue` 等），详见 [Redis 存储总览](../../数据库管理/脚本服务-redis/00-Redis总览.md)。

## 说明

- 所有表均位于 `db_file` 数据库（MySQL，地址 `mysql.pro.testin.cn:3306`）。
- 数据访问层基于 MyBatis（Mapper 接口 + XML），script_action_log 除外（经 Redis 队列异步落库，见表页说明）。
- 时间字段以 `Long` 类型存储 Unix 时间戳（毫秒）或以 `Date` 类型存储。
- 逻辑删除字段 `isdelete` / `is_delete` 使用 `Short` 类型表示（0=未删除，1=已删除）。
