# 功能总览

> 按功能域组织的清单：每个域一句话定位 + 核心能力 + 接口文档入口（V1=ApiServlet 反射接口，V3=REST 管理台接口）。接口级出入参见 [07-开放接口文档索引](../07-开放接口文档/00-模块索引.md)。

## 脚本管理

> 界面入口：[App/Web/桌面脚本管理页](脚本管理.md) `/platform/testManager/test/script/{app,web,pc}`。

脚本全生命周期管理：条件分页查询、创建空脚本、更新（名称/标签/设计人）、批量删除/移动/标签、回收站（软删/批量恢复/硬删）、导入导出（异步队列）、跨项目批量复制（异步）、无效脚本重检、标签统计与 CSV 下载、脚本版本升级修复工具。

| 入口 | 形态 | 文档 |
|---|---|---|
| `ScriptController`（`/v3/script`） | V3 | [ScriptController](../07-开放接口文档/脚本管理/ScriptController.md) |
| `Script`（action=script，47 个 op） | V1 | [Script](../07-开放接口文档/脚本管理/Script.md) |
| `RecycleBin` / `CleanScript` | V1 | [RecycleBin](../07-开放接口文档/脚本管理/RecycleBin.md) / [CleanScript](../07-开放接口文档/脚本管理/CleanScript.md) |
| `ExportScript` | V1 | [ExportScript](../07-开放接口文档/脚本管理/ExportScript.md) |
| `ScriptUpgradeController`（`/v3/scripts/version_upgrade`） | V3 | [ScriptUpgradeController](../07-开放接口文档/脚本管理/ScriptUpgradeController.md) |

实现链路：[脚本管理与转用例实现](../03-实现逻辑/脚本管理与转用例实现.md)、[核心链路-脚本复制](../04-复杂功能细节/核心链路-脚本复制.md)、[核心链路-脚本导出](../04-复杂功能细节/核心链路-脚本导出.md)、[核心链路-脚本解析与导入](../04-复杂功能细节/核心链路-脚本解析与导入.md)。

产品功能页：[脚本管理](脚本管理.md)（官方页面，含批量复制/导入导出规则）；[脚本校验](脚本校验.md)（校验状态展示 + 无效脚本重检 + 有效脚本作为导出/复制/转用例前置条件）。

## 脚本步骤

> 界面入口：[脚本管理页](脚本管理.md)内的步骤编辑。

步骤查询与步骤级操作（按 scriptNo 取步骤树、步骤 fast search）。仅 V1：`ScriptStep`（action=script，op=ScriptStep.*），见 [ScriptStep](../07-开放接口文档/脚本步骤/ScriptStep.md)。

## App 与控件

> 界面入口：[脚本管理页](脚本管理.md)/提测时的 App 包与控件选择，详见 [App与应用包管理](App与应用包管理.md)。

App 包查询与提测选包支撑：按 packageId/MD5 查包、按项目/套件分页列包、版本列表、按 MD5 取下载 URL、签名信息补全、包移除；App 基本信息与子信息；控件（script_control）查询。

| 入口 | 形态 | 文档 |
|---|---|---|
| `AppPackage` | V1 | [AppPackage](../07-开放接口文档/App与控件/AppPackage.md) |
| `App` / `AppSubInfo` | V1 | [App](../07-开放接口文档/App与控件/App.md) / [AppSubInfo](../07-开放接口文档/App与控件/AppSubInfo.md) |
| `Appcontrol` | V1 | [Appcontrol](../07-开放接口文档/App与控件/Appcontrol.md) |

实现链路：[AppPackage包查询实现](../03-实现逻辑/AppPackage包查询实现.md)。

## 用例转换

> 界面入口：无独立页面，供平台基础功能服务组装用例时调用。

把"主脚本 + CALL 子脚本链"转成接口自动化用例的三件套接口（取编号/取步骤/取目录），供平台基础功能服务组装用例。仅 V3：`TestCaseController`（`/v3/script/test_case/script_transform_case/*`），见 [TestCaseController](../07-开放接口文档/用例转换/TestCaseController.md)，实现见 [脚本管理与转用例实现](../03-实现逻辑/脚本管理与转用例实现.md)。

第三方平台（MS 平台等）脚本绑定关系管理：`script_third_relation`。仅 V1：`thirdparty` 包下的 `Script`，见 [thirdparty-Script](../07-开放接口文档/第三方集成/thirdparty-Script.md)。

## Python 脚本

Python 脚本（`python_script`）管理 + XML-RPC 远程执行/调试/函数发现（下游 `xmlrpcservice`）。仅 V3：`pythonController`，见 [pythonController](../07-开放接口文档/Python脚本/pythonController.md)。

## 基础设施

> 界面入口：无独立页面（后端能力）。

- 文件通用查询与缓存清理：`FileApi`（含 `cleanCacheByFileId`，跨服务缓存一致性关键入口）——[FileApi](../07-开放接口文档/基础设施/FileApi.md)
- 脚本执行结果查询：`Result`——[Result](../07-开放接口文档/基础设施/Result.md)
- Tab 配置：`TabConfig`——[TabConfig](../07-开放接口文档/基础设施/TabConfig.md)
- 健康检查：`HeartBeatController`——[HeartBeatController](../07-开放接口文档/基础设施/HeartBeatController.md)

## 页面/使用方速查

| 使用方 | 用什么能力 | 入口 |
|---|---|---|
| V3 管理台-脚本管理页 | 列表/编辑/删除/移动/标签/回收站/导入导出/复制 | V3 `/v3/script/*` |
| V3 管理台-套件页 | 套件与包/脚本绑定 | V3 `/v3/suite/*` |
| 平台基础功能服务 | 脚本转用例三件套 | V3 `/v3/script/test_case/script_transform_case/*` |
| app处理服务/任务管理服务 | 执行取脚本 ZIP、取 App 包信息 | V1 `action=script/app` |
| 数据源 | 按条件取 scriptNo 列表 | V3 `/v3/script/scripts/script_nos` |
| 文件管理服务 | 上传后清文件缓存 | V1 `op=FileApi.cleanCacheByFileId` |
