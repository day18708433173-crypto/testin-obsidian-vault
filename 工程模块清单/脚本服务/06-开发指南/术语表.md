# 术语表

> 脚本服务域术语速查。每条给"一句话定义 + 深入阅读"。按拼音/字母排序。

## A

**ApiServlet** — V1 入口 Servlet（`/*` 映射）：按 `action=包名` + `op=类.方法` 反射调用 `cn.testin.service.*` 下的类，平台内部 RPC 的主要形态。见 [横切-双入口路由机制](../04-复杂功能细节/横切-双入口路由机制.md)。

**AppPackage（应用包）** — 上传解析后的 APK/IPA/HAP：`package_file` 存包版本、`common_app` 存应用、`common_file` 存文件 URL/MD5。本服务只做查询与管理，上传解析在文件管理服务。见 [AppPackage包查询实现](../03-实现逻辑/AppPackage包查询实现.md)。

**action / op** — V1 路由参数：`action` 定位包（script/app/suite/ai/voice/form/file/result/tab/thirdparty），`op` 定位 `类.方法`。

## C

**CALL 步骤** — 类型为 `CALL` 的脚本步骤，表示"调用子脚本"（`stepcallscriptno` 指向子脚本 scriptNo）；脚本转用例要求主脚本全部由 CALL 步骤组成。见 [脚本管理与转用例实现](../03-实现逻辑/脚本管理与转用例实现.md)。

**CommonFile / CommonApp 缓存** — `common_file`/`common_app` 的 JVM 内 Guava 缓存（容量 1000、写后 2 分钟过期），失效入口只有 `FileApi.cleanCacheByFileId`（仅 file 级）。

## D

**db_file** — 本服务唯一 MySQL 库（约 40 张表），与文件管理服务共享。见 [存储总览](../02-技术架构/00-存储总览.md)。

**DispatcherServlet（V3）** — Spring MVC 入口（`/v3/*` 映射），V3 管理台与平台基础功能服务使用。见 [横切-双入口路由机制](../04-复杂功能细节/横切-双入口路由机制.md)。

## H

**回收站** — 脚本软删除暂存区：`isdelete` 三级（未删/已删/硬删），支持恢复（含同名冲突处理：保留两者/替换）与硬删除。见 [脚本管理与转用例实现](../03-实现逻辑/脚本管理与转用例实现.md)。

## J

**脚本（Script）** — 平台最小测试资产，XML/ZIP 实体存文件存储，元数据在 `script_file`。双重标识见下两条。

**scriptId** — `script_file` 行主键：每次保存产生新版本行，历史版本共存；查"当前脚本"要取该 scriptNo 下最新 scriptId。

**scriptNo** — 项目内脚本编号（面向用户的稳定标识），跨表关联（目录/套件/依赖/校验）基本都用它。

**脚本校验（Check）** — 脚本有效性检测（URL 可达、步骤合法、依赖与环形），引擎在文件管理服务，状态写 `script_check`；本服务只发起重检。见 [核心链路-脚本校验](../04-复杂功能细节/核心链路-脚本校验.md)。

## S

**数据源（DataSource）** — 外部数据源服务：脚本参数化取值、数据源导入导出；脚本改名会经 `DataSourceApi.syncSourceName` 同步。脚本侧参数表为 `script_param`/`script_param_source`/`script_param_data`。

**套件（Suite）** — 应用级测试套件（`suite_info`）：绑定多个 App 包（`suite_app`）、脚本（`suite_script`）、AI 资源（`suite_resource`）。

## W

**文件管理服务** — 兄弟服务（fileupload/filecloud）：负责脚本录制上传、App 包上传解析、脚本校验引擎；与本服务共享 `db_file` 表。注意其仓内 `cn.testin.api.file.FileApi` 是调本服务的客户端封装，不是服务端。

## X

**XML-RPC（xmlrpcservice）** — Python 脚本引擎的远程协议：执行/调试/函数发现经 Apache XmlRpcClient 调下游 `xmlrpcservice`（地址在 `service.api.properties`）。

## Y

**用例转换（脚本转用例）** — 把"主脚本 + CALL 子脚本链"转成接口自动化用例：本服务 `/v3/script/test_case/script_transform_case/*` 三接口供数据，用例表落在平台基础功能服务。见 [脚本管理与转用例实现](../03-实现逻辑/脚本管理与转用例实现.md)。

## Z

**V1 / V3** — 本服务两代接口形态的简称：V1=ApiServlet 反射 RPC，V3=Spring MVC REST。同功能常有两个实现（新层 `mvc.service` 是 Spring Bean，旧层 `file.service` 手动 new），改代码先确认层。见 [开发指南](开发指南.md)。
