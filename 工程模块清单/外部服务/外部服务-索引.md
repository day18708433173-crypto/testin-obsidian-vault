## 脚本服务 通信架构

```
filesystem
  ├── V1 Action/Op (ApiUtil.doPress)
  │   ├── UserManager → testin-core（用户/项目/在线/参数，含 OEM 系统参数）
  │   ├── FileUpload → fileupload（文件存储）
  │   └── DataSource → datasource-manage（数据源配置）
  ├── V3 REST (ServiceRemoteV3Api)
  │   └── InterfaceCase（接口用例查询，stub）
  ├── HTTP REST
  │   └── Admin（导出文件磁盘清理注册，stub）
  └── HTTP GET
      └── ScriptCheck → fileupload（脚本校验端点）
```
