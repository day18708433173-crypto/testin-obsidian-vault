# 数据库字段字典-用例与任务

> 用例域与任务/计划域全部 12 张表的**字段级**数据字典（列名/类型/键/可空/注释，来源：测试库 `information_schema` 实查）。
> 表级总览与关系图见 [数据库表结构](数据库表结构.md)；业务语义见 [用例管理实现](../../接口自动化/03-实现逻辑/用例管理实现.md)、[测试任务实现](../../接口自动化/03-实现逻辑/测试任务实现.md)、[测试计划实现](../../接口自动化/03-实现逻辑/测试计划实现.md)。
> 同组字典：[数据库字段字典-接口与脚本](数据库字段字典-接口与脚本.md) · [数据库字段字典-报告与环境数据](数据库字段字典-报告与环境数据.md) · [数据库字段字典-治理与支撑](数据库字段字典-治理与支撑.md)

**通用阅读约定**：`PRI`=主键、`MUL`=非唯一索引、`UNI`=唯一索引；无说明时 `create_time`/`update_time` 为毫秒时间戳（bigint）；标注 JSON 的列结构契约在代码里，数据库无约束。


## test_case（测试用例表）

| 列名 | 类型 | 键 | 可空 | 注释 |
|---|---|---|---|---|
| id | varchar(50) | PRI | NO | ID |
| case_number | int(11) |  | YES | 用例编号 |
| project_id | varchar(50) | MUL | NO | 项目ID |
| case_module_id | varchar(50) | MUL | YES | 用例模块ID |
| module_path | varchar(1000) |  | YES | 模块路径 |
| name | varchar(255) |  | YES | 用例名字 |
| tag | varchar(500) |  | YES | 标签 |
| type | varchar(50) |  | YES | 用例类型(正例、反例) |
| priority | varchar(50) |  | YES | 优先级(P0、P1、P2、P3、P4) |
| status | varchar(50) |  | YES | 用例状态(待评审、待设计、设计中、已启用、已废弃) |
| case_step | longtext |  | YES | 用例步骤 |
| description | text |  | YES | 用例描述 |
| last_result | varchar(255) |  | YES | 最后一次执行结果 0：失败 1：成功 |
| maintainer_id | varchar(255) |  | YES | 维护人ID |
| maintainer_name | varchar(255) |  | YES | 维护人姓名 |

| update_user_name | varchar(64) |  | YES | 更新人姓名 |
| create_time | bigint(13) |  | NO | 创建时间 |
| update_time | bigint(13) |  | NO | 修改时间 |
| is_deleted | tinyint(4) |  | YES | 是否删除，0否，1是 |
| execution_status | varchar(255) |  | YES | 执行状态(0:未执行 1:执行中 2:执行完成 3:执行停止中 4:执行中断) |
| report_id | varchar(50) |  | YES | 最后一次执行报告ID |
| debug_report_id | varchar(50) |  | YES | 最后一次调试报告ID |
| execute_on_failure | varchar(50) |  | NO | 失败是否执行后续步骤:0-不执行 1-执行 |
| execution_mode | varchar(50) |  | NO | 执行方式:0-自动执行 1-手动调试 |


**字段注解：**
- `case_step`：步骤 JSON **快照**（冗余自步骤表），两边可能不一致——以 `test_case_step` 为准，快照用于展示与执行固化。
- `report_id`：最后一次执行报告；报告被清理后查询侧会置空自愈（不是数据异常，见 [用例管理实现](../../接口自动化/03-实现逻辑/用例管理实现.md)）。
- `execution_status` 与 `execution_mode` 是字符串存数字，比较时注意类型。

## test_case_step（测试用例步骤表）

| 列名                 | 类型           | 键   | 可空  | 注释                    |
| ------------------ | ------------ | --- | --- | --------------------- |
| id                 | varchar(50)  | PRI | NO  | ID                    |
| project_id         | varchar(50)  |     | NO  | 项目ID                  |
| create_user_id     | varchar(50)  |     | YES | 创建人ID                 |
| update_user_id     | varchar(50)  |     | YES | 修改人ID                 |
| create_time        | bigint(13)   |     | NO  | 创建时间                  |
| update_time        | bigint(13)   |     | NO  | 修改时间                  |
| name               | varchar(512) |     | YES | 步骤名称                  |
| case_id            | varchar(50)  | MUL | NO  | 用例ID                  |
| script_id          | varchar(50)  | MUL | YES | 脚本ID                  |
| dataset_id         | varchar(50)  | MUL | YES | 关联数据集ID               |
| dataset_details    | longtext     |     | YES | 数据集数据JSON             |
| step_order         | int(11)      |     | YES | 步骤顺序                  |
| type               | int(11)      |     | YES | 步骤类型(1:关联脚本 2:自建)     |
| is_controller      | tinyint(5)   |     | YES | 是否是控制器(1:是）           |
| controller_type    | int(10)      |     | YES | 控制器类型(1:foreach循环迭代器) |
| controller_content | text         |     | YES | 控制器内容                 |
| status             | tinyint(4)   |     | NO  | 是否启用 1-启用 0-禁用        |


**字段注解：**
- ⚠️ **`script_id` 是多态外键**：`type=1` 指向 `test_script_copy`，`type=2` 指向 `test_script`，控制器步骤 type 为 null——联表先判 type（见 [开发约定与常见坑](../../接口自动化/05-常见问题/开发约定与常见坑.md)）。
- `controller_content`：控制器配置 JSON，含子步骤 `stepIds`——删步骤必须同步剔除，残留死 id 会被静默跳过（见 [控制器与流程编排](../../接口自动化/04-复杂功能细节/控制器与流程编排.md)）。
- `dataset_details`：步骤级数据集覆盖（勾选的数据行/列，JSON）。

| 列名               | 类型           | 键   | 可空  | 注释                                      |

| id               | varchar(50)  | PRI | NO  | ID                                      |

| create_user_id   | varchar(50)  |     | YES | 创建人ID                                   |
| update_user_id   | varchar(50)  |     | YES | 修改人ID                                   |

| update_time      | bigint(13)   |     | NO  | 修改时间                                    |
| name             | varchar(255) |     | YES | 任务名称                                    |
| state            | tinyint(4)   |     | YES | 任务状态                                    |
| last_result      | tinyint(4)   |     | YES | 最后一次执行结果                                |
| task_number      | int(11)      |     | YES | 任务编号                                    |
| executor         | varchar(500) |     | YES | 负责人(执行人)                                |
| case_info        | longtext     |     | YES | 用例信息                                    |
| is_del           | tinyint(4)   |     | YES | 是否删除，0否，1是                              |
| task_module_id   | varchar(50)  | MUL | YES | 任务模块id                                  |
| uuid             | varchar(50)  |     | YES | 任务唯一id                                  |
| env_id           | varchar(50)  |     | YES | 环境id                                    |
| env_name         | varchar(50)  |     | YES | 环境名称                                    |
| execution_status | varchar(10)  |     | YES | 执行状态(0:未执行 1:执行中 2:执行完成 3:执行停止中 4:执行中断) |
| report_id        | varchar(50)  |     | YES | 报告id                                    |
| tag              | varchar(500) |     | YES | 标签                                      |
| source           | varchar(255) |     | YES | —                                       |
| is_time          | tinyint(4)   |     | YES | 是否定时(1:是)                               |
| retest_num       | int(11)      |     | YES | 重测次数                                    |


**字段注解：**
- `case_info`：用例信息 JSON **快照**（执行瞬间固化用），实时关联以 `test_task_case` 为准。
- `report_id`：指向该任务**最后一次**执行的报告（不是全部历史；历史在 `test_task_rel_report`）。
- `is_del` 逻辑删除（注意与 `is_deleted` 命名不同）。

| 列名 | 类型 | 键 | 可空 | 注释 |
