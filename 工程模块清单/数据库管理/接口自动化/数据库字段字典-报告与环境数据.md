# 数据库字段字典-报告与环境数据

> 报告域与环境/数据域全部 12 张表（含 1 个视图）的**字段级**数据字典（列名/类型/键/可空/注释，来源：测试库 `information_schema` 实查）。
> 表级总览与关系图见 [数据库表结构](数据库表结构.md)；业务语义见 [测试报告与分享实现](../../接口自动化/03-实现逻辑/测试报告与分享实现.md)、[环境与配置管理实现](../../接口自动化/03-实现逻辑/环境与配置管理实现.md)、[数据集与数据枚举实现](../../接口自动化/03-实现逻辑/数据集与数据枚举实现.md)。
> 同组字典：[数据库字段字典-接口与脚本](数据库字段字典-接口与脚本.md) · [数据库字段字典-用例与任务](数据库字段字典-用例与任务.md) · [数据库字段字典-治理与支撑](数据库字段字典-治理与支撑.md)

**通用阅读约定**：`PRI`=主键、`MUL`=非唯一索引、`UNI`=唯一索引；无说明时 `create_time`/`update_time` 为毫秒时间戳（bigint）；标注 JSON 的列结构契约在代码里，数据库无约束。


## test_report（测试报告表）

| 列名 | 类型 | 键 | 可空 | 注释 |
|---|---|---|---|---|
| id | varchar(50) | PRI | NO | ID |
| project_id | varchar(50) |  | NO | 项目ID |
| name | varchar(255) |  | NO | 报告名称 |
| type | int(2) |  | YES | 报告类型 "0:script 1:case 2:task 3:batch" |
| case_total_count | int(20) |  | YES | 场景/用例总数 |
| case_success_count | int(20) |  | YES | 场景/用例成功数 |
| case_fail_count | int(20) unsigned |  | YES | 场景/用例失败数 |
| status | int(2) unsigned |  | YES | 状态 0:未开始,1:执行中,2:已完成 |
| take_time | bigint(20) unsigned |  | YES | 执行耗时 |
| pass_rate | varchar(10) |  | YES | 通过率 |
| last_supplement_id | varchar(50) |  | YES | 最后一次补测id |
| supplement_total | int(11) |  | YES | 补测总数 |
| create_time | bigint(20) |  | NO | 创建时间 |
| update_time | bigint(20) |  | NO | 修改时间 |
| used_interface_count | int(10) |  | YES | 测试过的接口数量 |
| unused_interface_count | int(10) |  | YES | 没有测试的接口数量 |
| interface_total | int(10) |  | YES | 接口总数量 |
| used_interface_rate | varchar(10) |  | YES | 接口使用率 |
| permanent_flag | int(10) |  | YES | 是否永久保存(1:永久保存) |
| is_time | tinyint(4) |  | YES | 是否定时(1:是) |
| case_tags | varchar(255) |  | YES | 提测用例标签 |
| dataset_tags | varchar(255) |  | YES | 提测数据集标签 |
| env_id | varchar(50) |  | YES | 环境id |


**字段注解：**
- `permanent_flag`：=1 永久保存，**报告定时清理的豁免标记**（见 [定时调度体系](../../接口自动化/03-实现逻辑/定时调度体系.md)）。
- `status`：0 未开始、1 执行中、2 已完成。
- 接口覆盖率四列（`used/unused_interface_count`、`interface_total`、`used_interface_rate`）是执行后统计快照。

## test_report_detail（测试报告详情表）

| 列名 | 类型 | 键 | 可空 | 注释 |
|---|---|---|---|---|
| id | int(255) | PRI | NO | 主键ID |
| report_id | varchar(64) | MUL | NO | 报告ID |
| case_id | varchar(64) |  | NO | 场景/用例ID |
| case_name | varchar(255) |  | YES | 用例名称 |
| case_num | int(11) | MUL | YES | 用例编号 |
| content | longtext |  | YES | 报告内容(详情) |
| exe_result | varchar(20) |  | YES | 执行结果 成功,失败 |
| create_time | bigint(20) |  | YES | 创建时间 |
| update_time | bigint(20) |  | YES | 修改时间 |
| machine_id | varchar(64) |  | YES | 执行机id |
| data_group_name | varchar(255) |  | YES | 关联数据组名字(以用例为单位) |
| retest_num | int(11) |  | YES | 重测次数 |
| analysis_id | int(11) |  | YES | 分析原因ID |
| analysis_desc | varchar(255) |  | YES | 分析原因描述 |
| analysis_user | varchar(255) |  | YES | 分析原因人 |
| supplement_id | varchar(50) | MUL | YES | 补测ID |


**字段注解：**
- ⚠️ 任务下发时**预插槽位**（`exe_result` 为空 = 未执行），执行结果按 `(report_id, case_num, machine_id)` 对位回写——`case_num` 错位是报告卡死的根因（见 [批次结果聚合](../../接口自动化/03-实现逻辑/批次结果聚合.md)）。
- `content`：步骤级完整明细（JSON longtext）——本表 170 万行 × 大字段，查询务必带 `report_id` 或 `case_num` 索引条件。

## test_report_share（报告分享表）

| 列名             | 类型           | 键   | 可空  | 注释           |
| -------------- | ------------ | --- | --- | ------------ |
| id             | int(11)      | PRI | NO  | 主键           |

| report_id      | varchar(255) | MUL | NO  | 报告id         |
| expire_time    | datetime     |     | YES | 过期时间         |
| context        | varchar(255) |     | YES | 分享的详细信息      |

## test_environment（测试环境表）

| 列名 | 类型 | 键 | 可空 | 注释 |
|---|---|---|---|---|
| id | varchar(50) | PRI | NO | ID |
| name | varchar(50) |  | YES | 环境名字 |
| project_id | varchar(50) |  | YES | 项目id |
| create_time | bigint(20) |  | NO | 创建时间 |
| update_time | bigint(20) |  | NO | 修改时间 |
| description | varchar(255) |  | YES | 描述 |
| domain | varchar(255) |  | YES | 域名 |
| config | text |  | YES | 配置信息 |
| is_deleted | tinyint(4) |  | YES | 是否删除，0否，1是 |
| status | int(10) |  | YES | 启用状态，0启用，1禁用 |
| maintainer | varchar(255) |  | YES | 维护人 |
| platform_id | varchar(50) |  | YES | 平台环境ID |


**字段注解：**
- `config`：一个 JSON 装下该环境**全部协议配置**（HTTP/DB/Dubbo/T2…）——改配置项要走级联写波及所有环境（见 [环境与配置管理实现](../../接口自动化/03-实现逻辑/环境与配置管理实现.md)）。
- `status`：**0=启用，1=禁用**（反直觉）；`platform_id` 映射主平台环境。
