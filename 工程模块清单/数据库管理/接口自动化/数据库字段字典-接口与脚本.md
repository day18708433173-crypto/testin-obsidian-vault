# 数据库字段字典-接口与脚本

> 接口域与脚本域全部 9 张表的**字段级**数据字典（列名/类型/键/可空/注释，来源：测试库 `information_schema` 实查）。
> 表级总览与关系图见 [数据库表结构](数据库表结构.md)；业务语义见 [接口管理实现](../../接口自动化/03-实现逻辑/接口管理实现.md)、[脚本管理实现](../../接口自动化/03-实现逻辑/脚本管理实现.md)。
> 同组字典：[数据库字段字典-用例与任务](数据库字段字典-用例与任务.md) · [数据库字段字典-报告与环境数据](数据库字段字典-报告与环境数据.md) · [数据库字段字典-治理与支撑](数据库字段字典-治理与支撑.md)

**通用阅读约定**（适用于全组字典，下文不再逐表重复）：

- 键列：`PRI`=主键、`MUL`=有索引（非唯一）、`UNI`=唯一索引、空=无索引。
- 无特殊说明时，`create_time`/`update_time` 为毫秒级 Unix 时间戳（bigint），`create_user_id`/`update_user_id` 为操作人。
- 标注"JSON"的列存的是 JSON 字符串，**结构契约在代码里，数据库无约束**。

## test_interface（接口定义表）

| 列名 | 类型 | 键 | 可空 | 注释 |
|---|---|---|---|---|
| id | varchar(50) | PRI | NO | ID |
| project_id | varchar(50) |  | NO | 项目id |
| name | varchar(512) |  | NO | 接口名字 |
| method | varchar(50) |  | YES | 请求类型 |
| protocol | varchar(50) |  | NO | 协议(HTTP、DUBBO、T2、SQL) |
| path | varchar(1000) |  | YES | 路径 |
| description | text |  | YES | 描述 |
| environment_id | varchar(50) |  | YES | 环境id |
| request_param | longtext |  | YES | 请求参数 |
| status | varchar(64) |  | YES | 状态(设计中、已启用、已废弃) |
| module_path | varchar(1000) |  | YES | 模块路径 |
| module_id | varchar(50) | MUL | YES | 模块路径ID |
| create_user_id | varchar(50) |  | YES | 创建人ID |
| update_user_id | varchar(50) |  | YES | 修改人ID |
| tags | varchar(1000) |  | YES | 标签 |
| create_time | bigint(13) |  | NO | 创建时间 |
| update_time | bigint(13) |  | NO | 修改时间 |
| is_default_mock | tinyint(4) |  | NO | 0-非默认 1-默认 |
| interface_number | int(11) |  | YES | 接口编号 |
| server_id | varchar(50) | MUL | YES | 服务ID |
| response | longtext |  | YES | 返回参数 |


**字段注解：**
- `request_param` / `response`：JSON 大字段，无 schema——前端对七个协议参数块有默认值兜底（见 [接口管理实现](../../接口自动化/03-实现逻辑/接口管理实现.md)）。
- `is_default_mock`：同 path 接口只能有一个默认 Mock，是 Mock 请求路由依据（见 [Mock服务](../../接口自动化/04-复杂功能细节/Mock服务.md)）。
- `environment_id`：默认环境，开放接口创建时未传则为空。
- `module_id` 挂统一模块树 `test_module`（`test_interface_module` 是 0 行遗留表）。

**字段注解：**

- `assertion_id` → `test_script_assertion.id`：断言独立存表，复制/生成副本时**必须深拷贝**（见 [脚本管理实现](../../接口自动化/03-实现逻辑/脚本管理实现.md)）。
- `script_type`：1 功能脚本、2 空脚本、3 性能脚本。
