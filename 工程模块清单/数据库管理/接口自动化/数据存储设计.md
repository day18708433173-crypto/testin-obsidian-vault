# 数据存储设计

> 全平台库-服务映射见 [数据库管理总览](../00-数据库总览.md)。

## 一句话结论

**平台自身的持久化只有两处：MySQL（业务数据）+ Redis（任务队列 / 执行状态 / 会话）。** MongoDB、HBase、Phoenix、Oracle 等都是**被测对象**（作为测试步骤的数据源），不是平台存储。

## MySQL — 业务主库

- 库名默认 `testin_api_db`，HikariCP 连接池，MySQL 5.1.46 驱动（同时打包了 ojdbc6 Oracle 驱动，供测试步骤连 Oracle 用）。
- **52 张表 + 1 视图的完整数据字典见 [数据库表结构](数据库表结构.md)**（含核心表 ER 图与字段详解）。
- 连接配置支持环境变量覆盖：`TESTINPRO_DB_HOST/PORT/NAME/USER/PASSWORD`（见 `src/main/resources/application-test.yml` datasource 段）。
- MyBatis + PageHelper 分页；`application.yml` 里全局配置：`map-underscore-to-camel-case: true`、`default-statement-timeout: 25000`、关闭 mybatis 日志实现。
- **mapper XML 与接口同目录**（`src/main/java/cn/testin/mapper/*.xml`），靠 pom build resources 拷入 classpath，不在 `resources/` 下。
- 表结构靠 `dao/`（DO）与 `mapper/` 反推；`resources/generatorConfig.xml` 是 MyBatis Generator 配置（`mvn mybatis-generator:generate`）。

## Redis — 任务总线 + 状态中心

Redis 在本平台身兼四职：

1. **任务队列**：每台执行机一个专属 list，服务端 `lpush`、执行端 `brpop`（key：`RedisKeyUtil.getRunnerLinterRedisKey(machineId)`）。
2. **任务载体**：JMX 脚本本体存 Redis（key：`RedisKeyUtil.getJmeterRunIdRedisKey(...)`），队列里只放引用。
3. **执行状态/结果**：执行中状态、批次进度、结果回写。
4. **会话**：`spring-session-data-redis` 依赖在 pom 里，HTTP session 存 Redis。

所有 key 集中在 `src/main/java/cn/testin/commons/utils/RedisKeyUtil.java`——**排查任务丢失/重复时先看这里**，完整清单见 [Redis通信与Key设计](../../接口自动化/03-实现逻辑/Redis通信与Key设计.md)。

注意两套客户端：

| 使用方 | 实现 | 位置 |
|---|---|---|
| 服务端 | spring-data-redis | `src/main/java/cn/testin/config/redisConfig/` |
| 执行端 | 手写 Jedis 封装（JedisPoolManager） | `src/main/java/cn/testin/runner/jedisConfig/` |

执行端的 Redis 连接不走配置文件，而是**启动位置参数**（host/port/db/password），见 [执行端Runner详解](../../接口自动化/03-实现逻辑/执行端Runner详解.md)。

## 被测数据源（非平台存储）

平台支持在测试步骤中直接操作以下数据源，连接信息配在 [环境与配置管理](../../接口自动化/01-产品功能/环境与配置管理.md) 里：

| 数据源 | 用途 | 代码位置 |
|---|---|---|
| MySQL / Oracle | SQL 步骤、数据准备/断言 | `service/DataBaseService.java` |
| MongoDB | 结果集校验（需部署机装 mongo shell，路径配置 `mongodbshell.path.v4`） | `service/nosql/` |
| HBase | 大数据校验 | `service/nosql/`（hbase-client 2.4.3） |
| Phoenix | HBase SQL 层 | `service/nosql/`（phoenix 5.1.3） |

详见 [数据库与NoSQL测试](../../接口自动化/04-复杂功能细节/数据库与NoSQL测试.md)。
