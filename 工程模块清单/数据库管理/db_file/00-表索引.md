# db_file 库表索引

> 数据库：`db_file`
> 共享服务：文件管理服务（fileupload 工程）、脚本服务（filesystem / filemanagement 工程）、数据源（datasource-manage 工程，仅只读关联查询）
> 分支：syy.release.z7.8.1.0
> 数据源文件：`pocinit/src/mysql/db_file.sql`
> 文件管理服务 Mapper 路径：`fileupload/src/main/java/cn/testin/filecloud/dao/mapping/`

db_file 库被三个服务共享：文件管理服务偏上传/解析/校验链路，脚本服务偏 V3 管理台全量字段，数据源仅做只读关联查询。同一张表的详情文档已合并为一篇，存于本目录，文内按服务分小节标注各自视角。

## 数据源侧（只读关联查询）

> 数据源（datasource-manage 工程）仅关联查询以下表获取脚本参数源信息，不做写入。

| 表名 | 说明 | 引用场景 |
| --- | --- | --- |
| script_param_source | 脚本参数源配置 | 查询脚本关联的数据源信息 |
| script_param_data | 脚本参数数据 | 查询脚本参数的具体数据 |
| script_file | 脚本文件信息 | 查询脚本基本信息 |

> 注：这些表的主数据由 script/file 相关服务管理，数据源仅做只读关联查询。
> 策略：只读引用表不单独建表详情页，字段以代码中 `cn.testin.pojo.third` 包实体（ScriptParamSource / ScriptParamData / ScriptFile 等）为准。

## 存储过程 / 函数

| 名称 | 类型 | 说明 |
|---|---|---|
| `getParentScripts(scriptNo)` | FUNCTION | 递归查找指定脚本的所有父级脚本，返回逗号分隔的 script_no 列表 |
| `script_to_last()` | PROCEDURE | 全量刷新 script_at_last 表，按 script_no 分组取最大 script_id，写入最新脚本记录 |
