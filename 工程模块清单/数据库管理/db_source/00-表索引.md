# db_source — 表索引

> 数据库：`db_source`（数据源 主库）
> 包含三套数据源表族：legacy（source_config 体系）、用例数据源（case_ 体系）、普通数据源（normal_ 体系），以及全局变量、标签、SQL 管理。

## 表清单

### legacy 数据源表族

| 表名 | 实体类 | 说明 |
| --- | --- | --- |
| [source_config](source_config.md) | `SourceConfig` | 数据源配置主表（树形结构：目录/数据源/全局表/实例表/SQL管理/SQL） |
| [datatable_config](datatable_config.md) | `DatatableConfig` | 数据表行列配置（行列顺序、行列最大值） |
| [datatable_col_config](datatable_col_config.md) | `ColConfig` | 数据表列定义（变量名、类型、scope、报告可见性） |
| [datatable_values](datatable_values.md) | `DatatableValues` | 数据表单元格值（含引用类型、同步状态） |
| [datatable_tag_config](datatable_tag_config.md) | `TagConfig` | 数据表行标签关联 |
| [tag_info](tag_info.md) | `TagInfo` | 标签定义 |
| [source_sql](source_sql.md) | `Sql` | SQL 表达式管理 |

### 用例数据源表族

| 表名 | 实体类 | 说明 |
| --- | --- | --- |
| [case_source](case_source.md) | `CaseSource` | 用例数据源树（目录/实例表/数据源） |
| [case_column_info](case_column_info.md) | `CaseColumnInfo` | 用例数据源列定义 |
| [case_value_info](case_value_info.md) | `CaseValueInfo` | 用例数据源单元格值 |
| [case_table_config](case_table_config.md) | `CaseTableConfig` | 用例数据源表行列配置 |
| [case_source_relation](case_source_relation.md) | `CaseSourceRelation` | 用例与数据源绑定（case_id → case_source_id + case_table_row_id） |
| [case_source_tag_config](case_source_tag_config.md) | `CaseSourceTagConfig` | 用例数据源行标签关联 |

### 普通数据源表族
