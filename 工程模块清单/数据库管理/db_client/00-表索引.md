# SQL/db_client/ -- 库索引

客户端库，由 设备控制中心 模块通过 getClientdao (JDBC) 和 MyBatis Mapper 读写。

## 表

| 表名 | 用途 | 详页 |
|------|------|------|
| client_info | 客户端主信息表 | [client_info](db_client/client_info.md) |
| client_info_refresh | 客户端信息刷新辅助表 | [client_info_refresh](db_client/client_info_refresh.md) |
| client_info_source | 客户端来源/资源标记 | [client_info_source](db_client/client_info_source.md) |
| client_process | 客户端执行流程记录 | [client_process](db_client/client_process.md) |
| pc_device_action_log | PC设备操作日志（存储在db_client库） | [pc_device_action_log](db_client/pc_device_action_log.md) |

## 视图
