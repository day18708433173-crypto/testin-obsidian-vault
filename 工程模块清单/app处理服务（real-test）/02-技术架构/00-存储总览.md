# 存储总览

> 表文档统一集中在 [数据库管理](../../数据库管理/00-数据库总览.md) 维护，本页仅列本服务使用的库并做引用。

real 模块集（平台配置 / 设备控制中心 / 任务调度服务 / app处理服务）使用以下存储层：

## MySQL（11 个库）

| 库名 | 用途 | 索引页 |
|------|------|--------|
| [db_realcfg](db_realcfg/00-表索引.md) | 云真机配置库（品牌/机型/设备源/环境/功能开关等） | [00-表索引](db_realcfg/00-表索引.md) |
| [db_mcfg](db_mcfg/00-表索引.md) | openapi 配置库（接口/接入方/角色/授权） | [00-表索引](db_mcfg/00-表索引.md) |
| [db_service](db_service/00-表索引.md) | 平台服务配置库（功能菜单/角色-功能授权） | [00-表索引](db_service/00-表索引.md) |
| [db_device](db_device/00-表索引.md) | 设备库（设备信息/流程/资产/预约/分组/锁定） | [00-表索引](db_device/00-表索引.md) |
| [db_pc](db_pc/00-表索引.md) | PC/上位机库（PC信息/浏览器流程） | [00-表索引](db_pc/00-表索引.md) |
| [db_client](db_client/00-表索引.md) | 客户端库（客户端信息/流程） | [00-表索引](db_client/00-表索引.md) |
| [db_task](../../数据库管理/db_task/00-表索引.md) | 任务调度库（任务匹配/下发/执行/回收/日志） | [00-表索引](../../数据库管理/db_task/00-表索引.md) |
| [db_device_monitor](db_device_monitor/00-表索引.md) | 设备监控库（报警日志/监控参数） | [00-表索引](db_device_monitor/00-表索引.md) |
| [db_quartz](db_quartz/00-表索引.md) | 定时任务库（模板/执行流水） | [00-表索引](db_quartz/00-表索引.md) |
| [db_real](db_real/00-表索引.md) | 真机测试库（适配任务/报告分享/免费额度） | [00-表索引](db_real/00-表索引.md) |
| [db_user](../../数据库管理/db_user/00-表索引.md) | 用户库（跨库只读引用） | [00-表索引](../../数据库管理/db_user/00-表索引.md) |

## Redis

| Key / 用法 | 使用模块 | 说明 |
|------------|----------|------|
| `queue:operate_log` (List, LPUSH) | 平台配置 | 问题原因操作日志队列，异步消费落入 error_cause_operate_log |
| `RedisDAOImpl` 通用 String (setex/get/del) | 平台配置 | 按 dbName 选择实例的通用缓存，默认过期 600s |
| redismq 发布 (`PublishFactory.publish`) | 平台配置 | 配置变更通知发布，失败时落 外部服务/notice-manager 重发 |
| protocol:* (ProtocolDAOImpl) | 设备控制中心 | 协议生命周期存储，含过期机制 |
| 任务匹配队列 (TaskInfoDAOImpl) | 设备控制中心 | BRPOP 获取待匹配设备/PC/Client |
| 消息队列 (QueueDAOImpl) | 设备控制中心 | MessageDispatchThread 消费 |
| 通用键值 (KeyValDAOImpl) | 设备控制中心 | 通用缓存 |
| 用户信息缓存 (UserInfoDAOImpl) | 设备控制中心 | 用户相关缓存 |
| 升级信息 (UpgradeDAOImpl) | 设备控制中心 | 设备升级状态缓存 |
| alarm:silence:* | 设备控制中心 | 报警 30min 静默期 |
| `:device:task:` Hash | 任务调度服务 | 设备-任务关系缓存 |
| Task.init 防重 Key (`reqId_taskid`) | 任务调度服务 | 分布式锁 NX 1h |
| task_run_info:* (TaskRunInfoDAOImpl) | app处理服务 | 任务实时运行状态 |
| data_run_info:* (DataRunInfoDAOImpl) | app处理服务 | 数据运行信息缓存 |
| script_collect:* (ScriptCollectDAOImpl) | app处理服务 | 脚本收集结果缓存 |
| init_task:* | app处理服务 | 无App快速提测初始化任务 |
| 心跳检查 | 全模块 | Redis 连通性健康检查 |
