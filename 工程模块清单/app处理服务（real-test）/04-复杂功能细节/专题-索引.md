## 端到端业务全流程

> 从用户操作视角出发，串联 app处理服务 → NoticeServiceImpl → scheduling → controlcenter 的跨模块端到端业务大流程。

| 流程 | 文件 | 触发入口 | 涉及模块 |
|------|------|----------|----------|
| 创建任务 | [核心链路-任务创建](核心链路-任务创建.md) | app处理服务 TaskController.taskAdd() / Task.add() | app处理服务 → scheduling → cfg → MQ → Portal |
| 补测复测 | [核心链路-补测复测](核心链路-补测复测.md) | app处理服务 Task.retest() / scriptRetest() / repeatTest() | app处理服务 → scheduling → MQ → controlcenter |
| 任务取消与异常恢复 | [核心链路-任务取消与异常恢复](核心链路-任务取消与异常恢复.md) | app处理服务 Task.cancel() / controlcenter 设备离线 | app处理服务 → scheduling → controlcenter → MQ → TestPlan |
| 定时任务 | [核心链路-定时任务](../../任务调度服务（real-scheduling）/04-复杂功能细节/核心链路-定时任务.md) | QuartzJob.execute() → IQuartzJobService.execute → TaskServiceImpl.addNew() | Quartz → app处理服务 → scheduling → MQ |
| 结果回收与报告通知 | [核心链路-结果回收与报告通知](核心链路-结果回收与报告通知.md) | scheduling reportResult → actionReport → 6条串联通知链 | scheduling → app处理服务 → ES → 邮件/企微/钉钉 |
