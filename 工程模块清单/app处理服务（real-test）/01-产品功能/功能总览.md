# 功能总览

> 本页是 app处理服务（real-test）功能维度的总索引：每个功能块一句话定位 + 入口 + 深入阅读链接。接口级明细见 [07-开放接口文档索引](../07-开放接口文档/00-模块索引.md)，代码级细节见各专题。

## 任务创建与执行

> 界面入口：[应用管理页](任务提测.md) `/platform/app-manage` 发起提测（选 App 包 → 脚本 → 设备 → 策略），或 [任务管理页](任务管理.md) `/platform/executeManager/auto/app` 新建任务。

任务生命周期管理是本服务的核心：创建（含模板/测试计划/定时场景）、取消、执行控制（暂停/恢复）、执行状态查询。

- **双入口创建**：ApiServlet `op=Task.add`（`real-test/src/main/java/cn/testin/service/app/Task.java`）与 MVC `POST /v3/task`（`real-test/src/main/java/cn/testin/mvc/controller/TaskController.java`），殊途同归到三表入库 + 通知链。链路见 [APP任务执行链路实现](../03-实现逻辑/APP任务执行链路实现.md)、专题 [核心链路-任务创建](../04-复杂功能细节/核心链路-任务创建.md)。
- **取消与控制**：`Task.cancel`（`real-test/src/main/java/cn/testin/service/app/Task.java`）、`execute`/`pause`/`resume`，经 `scheduling.TaskApi.cancel` 透传到任务调度服务。异常恢复见专题 [核心链路-任务取消与异常恢复](../04-复杂功能细节/核心链路-任务取消与异常恢复.md)。
- **分享**：`Task.share`/`shareInfo`生成 skey 写 `real_report_share`，报告可免登访问。
- **取消与异常恢复（自然语言版）**：用户取消（含批量、第三方、欠费、多端联动）与设备异常自动取消/恢复的规则，见 [任务取消与异常恢复](任务取消与异常恢复.md)。

## 补测复测

> 界面入口：[任务管理页](任务管理.md) `/platform/executeManager/auto/app` 执行记录上的任务操作（设备/脚本/批量补测）。

三种形态，全部复用任务调度服务的 `Task.init` 补测模式入库，只补增量子任务：

| 形态 | 入口 op | 粒度 |
|---|---|---|
| 设备补测 | `Task.retest`（`real-test/src/main/java/cn/testin/service/app/Task.java`） | 换设备，原脚本重跑 |
| 脚本补测 | `Task.scriptRetest`→ `RetestServiceImpl.scriptRetest`（`real-test/src/main/java/cn/testin/business/impl/RetestServiceImpl.java`） | 指定子子任务重跑 |
| 批量补测 | `Task.repeatTest`→ `TaskServiceImpl.repeatTest`（`real-test/src/main/java/cn/testin/business/impl/TaskServiceImpl.java`） | 设备 + 脚本任意组合 |

主干见 [补测复测实现](../03-实现逻辑/补测复测实现.md)，细节见专题 [核心链路-补测复测](../04-复杂功能细节/核心链路-补测复测.md)；跨模块视角见 [端到端-补测](../../跨模块链路/端到端-补测.md)。三种模式的自然语言版规则（只增量不破坏、原任务须已完成、统计去重等）已并入 [任务管理](任务管理.md) 的"任务操作-补测复测"小节。

## 报告与导出

> 界面入口：[任务管理页](任务管理.md) `/platform/executeManager/auto/app` 执行记录详情的报告查看与 Excel/PDF 导出，详见 [报告概述](报告概述.md)。

执行结果回收后生成多形态报告：

- **报告查询**：ApiServlet `action=report` 的 `Report`（27 op：列表/步骤详情/脚本摘要/截图/错误分类）与 MVC `ReportController`、`TaskReportController`（含东北证券定制汇总）。
- **Excel 报告**：`Excel.create/generate/reportExcel`（`real-test/src/main/java/cn/testin/service/report/Excel.java`），由 `REPORT_GENERATE` 通知异步生成。
- **PDF 报告**：`Pdf` + 后台线程 `PDFThread`（`real-test/src/main/java/cn/testin/schedule/pdf/PDFThread.java`，StartRunner 启动，HTML→PDF）。
- **测试计划导出**：`TestPlanController`（`/realtest` 下 Excel 导出 + 分享链接导出）。
- 回收与生成链路见专题 [核心链路-结果回收与报告](../04-复杂功能细节/核心链路-结果回收与报告.md) / [核心链路-结果回收与报告通知](../04-复杂功能细节/核心链路-结果回收与报告通知.md)。
- **收尾流程（自然语言版）**：结果两段式上报、多维度汇总、Excel/PDF 生成与完成通知的完整收尾流程，见 [结果回收与报告](结果回收与报告.md)；邮件、企微/钉钉/飞书机器人、短信、HTTP 回调等通知渠道与重试、延迟、防重规则，见 [通知能力](通知能力.md)。

## 性能与问题分析

> 界面入口：[任务管理页](任务管理.md) `/platform/executeManager/auto/app` 报告内的性能图表与问题分析。

- **性能数据**：ApiServlet `action=analysis` 的 `Performance`（图表数据/导出）与 MVC `PerformanceController`；设备级性能存于 `pmreal_device_detail`。
- **问题分析**：`AnalysisReport` / `AnalysisTask`（报告分析列表、子任务摘要、错误信息修改）与 `ProblemAnalysisReportController`；异常统计走 `Stat`（`action=report`）。
- **安全检测**：`Safety`（`action=app`，加固安全检测 CRUD）。

## 定时任务

> 界面入口：[任务管理页](任务管理.md) `/platform/executeManager/auto/app` 的定时任务模版管理，详见 [定时任务](定时任务.md)。

Quartz 体系：模板（`quartz_job_info`）+ 执行流水（`quartz_job_statement`）。

- **管理入口**：ApiServlet `ScheduledJob`（15 op：增删改查/执行/暂停/停止/恢复）+ 辅助查询 `Quartz`（5 op）+ MVC `QuartzJobStatementController`。
- **触发执行**：`QuartzJob.execute`（`real-test/src/main/java/cn/testin/quartz/QuartzJob.java`）→ `IQuartzJobService.execute` 组装参数创建真实任务 → 进入正常创建链路；流水回写 `recordStatement`。
- 跨模块视角见 [端到端-定时任务](../../跨模块链路/端到端-定时任务.md)。cron 定时触发自动创建真实任务的模板、执行留痕与重启恢复机制（自然语言版）见 [定时任务](定时任务.md)。

## 测试资源

> 界面入口：[提测流程](任务提测.md)（应用管理/任务管理）中的脚本、参数、账号等资源选择。

提测依赖的周边资源管理：

| 功能 | 入口 | 说明 |
|---|---|---|
| 脚本资源 | `ScriptList`（action=script，7 op） | 脚本列表/应用版本/Suite/App 列表/收藏夹 |
| 参数来源 | `ParamSource`（action=app） | 数据源参数分配策略 |
| 测试账号 | `Account`（action=app） | 账号匹配与释放 |
| 抽查参考 | `SpotReference`（action=report） | 抽查测试参考信息 |
| 免费额度 | `FreeQuota`（action=free） | 免费额度新增/修改/查询/扣减 |
| 结果上报 | `TestResult` / `TestProcess`（action=app，各 1 op） | 任务调度服务回传结果/过程数据的接收端 |
