# app处理服务 模块接口文档索引

> 测试执行引擎：App 模块任务创建/取消/复测、报告生成与导出、性能分析、定时任务模板管理。
> 双入口：9 个 Spring MVC Controller + 20 个 ApiServlet service + 1 个全局异常处理，按功能域组织。

## 测试计划与任务（9 个）

| 文档 | 入口 | 职责 |
|------|------|------|
| [TaskController](测试计划与任务/TaskController.md) | WebMvc `/task` | 任务 CRUD：创建、查询、脚本重置、用户适配、测试计划结果发送（8 接口） |
| [TestPlanController](测试计划与任务/TestPlanController.md) | WebMvc `/realtest` | 测试计划 Excel 导出（含分享链接导出，2 接口） |
| [TaskReportController](测试计划与任务/TaskReportController.md) | WebMvc `/realtest` | 任务报告详情、汇总（含东北证券定制，3 接口） |
| [QuartzJobStatementController](测试计划与任务/QuartzJobStatementController.md) | WebMvc `/quartz_job_statement` | 按 taskId 删除定时任务记录（1 接口） |
| [Task](测试计划与任务/Task.md) | ApiServlet (action=app) | 任务生命周期：创建/取消/补测/分享/邮件/执行控制（28 op） |
| [ScheduledJob](测试计划与任务/ScheduledJob.md) | ApiServlet (action=app) | 定时任务增删改查/执行/暂停/停止/恢复（15 op） |
| [Quartz](测试计划与任务/Quartz.md) | ApiServlet (action=app) | 定时任务辅助查询（应用名/渠道/Suite/版本，5 op） |
| [TestResult](测试计划与任务/TestResult.md) | ApiServlet (action=app) | 测试结果上报（1 op） |
| [TestProcess](测试计划与任务/TestProcess.md) | ApiServlet (action=app) | 测试过程数据上报（1 op） |
