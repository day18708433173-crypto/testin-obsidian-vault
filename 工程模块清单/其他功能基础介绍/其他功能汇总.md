# 其他功能汇总

> 本文档汇总自官方文档中心（test.pro.testin.cn/docs）的自动化产品功能文档，覆盖 App / Web / PC 三条产品线，共 25 篇。这些内容属于各自动化产品（应用管理、脚本录制、控件/输入、性能采集等）而非后端服务代码，故合并至此归档。每节末尾保留原始来源 URL 以便溯源。

## App 自动化产品

### 快速开始

> 来源：http://test.pro.testin.cn/docs/app/start/

App 自动化平台整体使用流程：配置环境（可选）→ 创建应用 → 录制脚本 → 新建任务 → 查看任务执行明细与报告。

- **配置环境（可选）**：UI 测试环境管理可配置三方服务 hosts / 数据库连接（当 UI 测试需调用数据库等三方服务辅助操作时）；证券行业可通过 T2 连接管理配置交易柜台开放接口（T2 接口）。
- **创建应用**：应用是 App 自动化测试的目标，在应用管理页面点「创建应用」创建测试应用。
- **录制脚本**：脚本是测试步骤的集合。打开脚本管理页面点「录制脚本」→ 选择设备 → 映射屏下拉栏「安装APP」安装并自动启动应用 → 编写脚本（应用安装/关闭/卸载等管理操作、屏幕点击/滑动等事件操作、变量赋值/处理/检查、引入三方脚本、适配已定义环境）。
- **新建任务**：任务是测试用例的集合。任务管理页面点「开始测试/App提测」，指定应用、添加脚本、选择终端，定义执行方式/重测次数/数据源/执行环境后创建。
- **任务执行明细与报告**：任务管理界面查看历史任务明细与报告，可管理执行/停止状态；报告详情页展示脚本测试概况（执行概况、问题统计、设备性能）、脚本执行报告、设备执行报告、每条语句执行前后截图对比。

### 快速使用鸿蒙NEXT设备

> 来源：http://test.pro.testin.cn/docs/app/start_HarmonyOS_NEXT/

使用鸿蒙 NEXT 设备做自动化功能测试和回归测试。支持设备系统 iOS/Android/HarmonyOS/HarmonyOS NEXT，安装包格式 .ipa/.apk/.hap。

- **应用管理**：鸿蒙 NEXT 设备安装包为 .hap 格式。
- **接收测试需求**：确定关键功能 → 确认测试范围与数据要求 → 编写测试用例步骤、定义期望结果。
- **录制自动化脚本**：将用例转为自动化脚本，任务提测时选数据覆盖实现复用。

平台支持能力（脚本步骤）：

| 类型 | 脚本步骤 |
|---|---|
| AI模式 | AI点击、AI双击、AI长按、AI输入、检查…存在/不存在、变量赋值、如果…存在/不存在、AI if 存在/不存在目标对象、AI for循环、全表检查、安全键盘 |
| 控件模式 | 控件输入（输入文本/变量/随机文本/随机中文/随机数字/安全键盘/短信验证码）、控件操作（点击/双击/长按）、IF存在文本/变量值/设备平台、检查包名/文本变量、应用操作 |
| 功能栏 | 数据获取和处理、检查界面持续变化、if满足表达式条件、循环控制 |
| 任务报告 | 下载 Excel/PDF 报告 |

暂不支持（预计 9 月支持）：任务报告-应用日志数据；AI模式-性能埋点、表格赋值；功能栏-HDC操作。

- **任务提测**：按业务场景组装脚本提交测试，数据驱动覆盖所有测试数据。
- **分析任务报告**：脚本测试结果分析（概况/问题/标签执行/标签问题）、用例执行详细报告、问题分析报告。
- 鸿蒙 NEXT 与安卓设备执行情况对比：以普通交易-买入任务为例，脚本相似度 95%（鸿蒙 NEXT 用了 5 个控件步骤），覆盖 25 条数据，可在报告中对比两类设备执行情况。

### 应用管理

> 来源：http://test.pro.testin.cn/docs/app/application_manage/

管理同一项目内的所有应用包（暂仅支持 App 自动化测试）。

- **创建应用**：设置应用名称、icon、备注。
- **上传 App 安装包**：同一应用可上传多版本，相同版本只能上传一次。上传 HarmonyOS NEXT 应用(.hap) 若需同时上传动态共享包(.hsp)，打包成 .zip（仅含 .hap/.hsp 且不含文件目录）上传。上传成功自动解析 App 名称与包名。
- **高级设置/签名证书**：签名证书为安装包必属属性，可打入包内或通过「高级配置」配置；无签名的包超级管理员可配通用证书注入（可能影响加固/签名检查类 App）。
- **管理 App 安装包**：支持筛选、下载、删除、查看测试记录。
- **iOS 测试包安装**：苹果对 ipa 安装有 AdHoc/InHouse/Testflight 三种方式，推荐 AdHoc，提前将 Apple 设备 udid 签入 ipa。

### 应用操作

> 来源：http://test.pro.testin.cn/docs/app/app_operation/

在脚本步骤中对应用做安装、启动、清理数据、关闭、卸载操作，并监听崩溃。

- **安装应用**：安装策略有「卸载安装」（清缓存）、「覆盖安装」（保留缓存，Android 可选清除缓存）、「保留已安装应用」；可选「使用最新上传的安装包」「iOS 证书重签」。
- **启动应用**：安装后通过启动应用步骤打开待测应用（仅能启动当前设备已安装的应用）。
- **清理应用数据**：Android 可系统清理缓存；iOS 框架不支持清理缓存，只能卸载安装。清理后自动退出应用。
- **关闭应用**：关闭应用回到桌面。
- **卸载应用**：卸载已安装应用回到桌面。
- **应用崩溃监听**：捕获脚本某范围步骤内的应用崩溃；从监听步骤后开始监听，崩溃信息记录在任务报告日志（logcat 过滤关键词 `am_crash`），忽略崩溃后不再监听。

### 脚本编写

> 来源：http://test.pro.testin.cn/docs/app/script/

操作步骤是记录用户在 App/Web/PC 上一系列操作的步骤，是组成自动化脚本的最小单元，可单步或连续执行。

- **控件树**：App 敏感界面禁止截屏导致映射屏黑屏时，通过控件树显示界面组件及文本，确保录制成功。开启录制 → 映射屏切为控件 → 开启控件树 → 右键滑动/点击/输入 → 跳转正常页后关闭控件树。注：黑屏时开启控件树无法使用 AI 步骤录制。

### 录制

> 来源：http://test.pro.testin.cn/docs/app/transcribe/

三种录制模式 + 导航栏。

- **控件模式**：操作屏幕自动生成步骤（点击/长按/左滑/右滑/上滑/下滑）；屏幕右键操作可插入检查点、IF 判断控件是否存在、循环、性能埋点等，所有操作基于控件录制，跨尺寸/分辨率/版本机型均可执行。
- **图像模式**：左键取图框选识别区域（不小于 16×16）后右键显示图像操作列表，支持数据标注、基础操作（点击/双击/长按/输入/安全键盘/滑动轨迹）、性能埋点、检查点、IF 判断图像、循环、区域监控、特征色检查等，可单双指操作。
- **AI 模式**：自动识别页面文字，点击文字生成自然语言语法步骤；右键可点击、检查、if 判断、监听文本、变量赋值、性能埋点。
- **导航栏**：仪表盘（放大观察截图）、模式选择（AI/图像/控件）、区域截图（框选区域变量赋值）、刷新控件、更多操作（安装 APP、切换清晰度、放大镜、关闭手机）。

### 控件模式

> 来源：http://test.pro.testin.cn/docs/app/control/

基于界面元素属性定位元素，识别准确、速度快，适用于控件树不变的场景；无法识别自定义控件，依赖 ID/XPath 等属性，跨平台（iOS/Android/鸿蒙）适配差时建议用 AI 模式。

- **开启录制**：映射屏切为控件模式（映射屏即手机操作界面模块）。
- **选取控件**：鼠标悬停显示控件（红色边框），小范围移动可精确选取嵌套控件。
- **右键录制控件步骤**：
  - 数据标注：标注图片元素供后续 AI 步骤识别图片更精准，标注管理模块可查看。
  - 检查点：检查界面存在控件内容。
  - if(存在/不存在控件)：按条件控制后续步骤路径；可用 if 设备操作系统 适配 iOS/Android 差异；也可 if 存在文本/变量值。
  - 循环开始：重复执行直至满足条件（常配合 if 存在控件 / AI if）。
  - 赋值给变量：获取界面文本数据赋值（文本被"…"截取场景）。
  - 操作：点击/双击/长按/滑动/标准滑屏，配置项含「界面稳定后再执行」「点击后没进入新界面尝试再次点击」「尝试将控件移到屏幕中间」。
  - 输入：输入变量/文本/随机文本/随机字母/随机中文/随机数字/模拟键盘/短信验证码/安全键盘。
  - 输入短信验证码：进入短信应用按发送人号码倒序取第一条验证码输入。
- **设置元素查找策略**：控件支持文本、ID、Class（类型）、XPath 四个属性，各自有必选/可选/忽略三种判断条件。必选=优先查找条件（之间是与关系），可选=辅助缩小范围，忽略=不参与。控件文本和 XPath 文本部分支持通配符 `*`。操作类步骤 Class/ID 必选；输入步骤 Class/ID 必选、文本忽略；if 存在文本/变量值文本必选。
- **步骤配置项**：当找到多个（找不到或选第几个）、超时时间（全局/自定义）、前置时间、滚屏查找、滚屏次数。
- **全表内容赋值-控件方式**：获取有表头/无表头列表数据（支持横向/纵向滑动），暂仅支持 Android 应用列表。

### 输入步骤

> 来源：http://test.pro.testin.cn/docs/app/input_method/

Android 输入底层走 ADB 或复制粘贴（上位机配置控制），iOS 走系统接口。提供多种输入方式：

- **AI 输入**：点击输入框聚焦后用 AI 输入。适用页面支持截屏且存在明确目标对象。
- **控件输入**：查找指定控件输入。适用防截屏黑屏（开控件树）或控件树不变场景。
- **ALT键+鼠标右击**：控件模式下无需检测键盘即可回放输入（防截屏黑屏也适用）。
- **安全键盘输入**：防止敏感信息被窃取，仅安全键盘输入框场景。
- **图片输入**：图像识别定位元素输入，用于非文字（图片）场景。
- **使用技巧**：输入不完整可增加「输入间隔」配置；想用控件输入却只显示安全键盘时，选择红框范围小一点。

### App列表数据全链路校验

> 来源：http://test.pro.testin.cn/docs/app/table_check/

通过「检查全表内容」快速校验 App 列表数据正确性（如当日委托界面的股票名称/委托时间/委托价格与数据库是否一致）。三步骤：获取期望内容（数据库或接口）→ 获取实际内容（界面显示）→ 数据校验。核心是把期望与实际分别存为数组变量，数组比对，可组合变量处理或 Python 脚本预处理。

- **获取期望内容**：① 数据库操作 SQL 查询（需提前配置数据库连接）；② HTTP 接口请求赋值。
- **获取实际内容**：全表内容赋值获取界面数据（AI 方式适配多执行端；控件方式仅 Android）。
- **数据校验**：功能栏「检查/检查全表内容」比对两组数据，校验失败字段红色标识。
- **任务执行报告**：提测后查看期望、实际与检查结果。

### 采集应用性能耗时

> 来源：http://test.pro.testin.cn/docs/app/performance/

采集脚本某范围步骤内应用的性能耗时（埋点耗时、上行/下行流量）。

- **操作**：功能栏「其他/性能埋点」，将步骤放在「性能开始」「性能结束」之间；埋点结束可设置结束标志元素（AI 方式或控件方式）。
- **耗时达标值**：应用执行操作允许的最大耗时（ms）；可设置「大于达标值继续/终止脚本」及测试结果通过/不通过。
- **测试报告**：任务执行后查看埋点耗时、上行/下行流量；埋点耗时含结束标志元素查找时间，建议仅作参考；支持下载 Excel 报告。

### 弱网参数配置

> 来源：http://test.pro.testin.cn/docs/app/network/

安卓手机通过 Wi-Fi 模拟不同网络环境测试应用响应速度。可新增弱网类型，配置上行/下行要求，任务提测时脚本在安卓设备上执行可使用设置的网络环境。

### AI不适用的场景

> 来源：http://test.pro.testin.cn/docs/app/ailimit/

- **显示不全或隐藏的文字**：无法在图像显示的内容识别不到（AI 只能识别"…"，控件可识别全部）。
- **部分相似度高的内容**：如"0"/"o"、"i"/"1"、"x"/"X" 等易识别不准，可临时加变量处理步骤用正则替换处理。

## Web 自动化产品

### Web-快速开始

> 来源：http://test.pro.testin.cn/docs/web/

Web 自动化平台整体使用流程：配置环境（可选）→ 录制脚本 → 新建任务 → 查看任务明细与报告。

- **配置环境（可选）**：UI 测试环境管理配置三方服务 hosts / 数据库连接；证券行业可配 T2 连接管理。
- **录制脚本**：打开脚本管理页面点「录制脚本」→ 选择设备 → 浏览器/访问 URL 打开待测网站 → 编写脚本（前进/后退/新建页签/切换页签、变量赋值/处理/检查、引入三方脚本）；多窗口操作用「浏览器/打开浏览器窗口」新建窗口。
- **新建任务**：任务管理页点「开始测试」，添加脚本、选择浏览器、定义执行方式/重测次数/数据源/执行环境。
- **任务执行明细与报告**：任务管理界面查看历史明细与报告，管理执行/停止状态；报告展示脚本测试概况、脚本执行报告、设备执行报告、语句执行前后截图对比。

### Web-任务提测

> 来源：http://test.pro.testin.cn/docs/web/task/

把所有相关脚本组织成任务集合，可重复执行（重测触发）。

- **选择脚本**：可选脚本、脚本组；单脚本失败默认继续执行，可开启「失败终止运行」；支持设置脚本执行后清除 Cookie、不关闭浏览器窗口。
- **选择执行终端**：选择浏览器作为终端；终端状态有空闲 / online（调试中，需等释放）/ 测试（执行中，需等结束）。
- **完善测试信息**：
  - 执行选项：普通执行（按执行终端分配 / 按脚本分配两种策略）或数据驱动（每行数据下发脚本，随机分配终端）。
  - 数据源：不同测试环境数据隔离；不选则按脚本声明变量默认值。
  - 数据源下标签：按标签筛选实例表数据，多标签取并集。
  - 是否发送邮件：执行结束发报告邮件，默认不发。
  - 执行环境：默认系统环境或自定义。
  - 执行策略：测试结果标记为跳过、设备集中调度、脚本失败重测次数、步骤全局超时时间、设备不可用时的策略（等待恢复 / 标记跳过）。
- **提交测试**：平台校验业务配置、用户信息、通知参数（手机号/邮箱）、录屏策略、终端可用性、环境配置，任一不通过即拒绝。
- **定时任务**：可设为定时执行。

### 控件模式（Web）

> 来源：http://test.pro.testin.cn/docs/web/control/

基于界面元素属性定位（依赖控件 ID/Name 等），识别准确速度快，适用于控件属性不常变化的场景；属性常变化建议 AI 模式。

- **开启录制**：映射屏切为控件模式。
- **选取控件**：鼠标悬停显示控件（红框），小范围移动精确选取嵌套控件。
- **右键录制步骤**：支持点击、双击、输入文本/变量、下拉框内容选择、单选框、复选框、文件上传、赋值给变量、图形验证码、图片相似度、数据标注、表单操作、表格操作。
- **输入**：输入变量/文本，配置「清空输入框」。
- **文件上传**：支持上传文件、使用变量两种方式。
- **图形验证码**：识别随机图形验证码赋给变量 `${verification_code}`，设置长度/类型（数字/字母/数字+字母），一般需循环多次识别。
- **图片相似度**：获取界面图片与期望图片 URL 的相似度，检查图片显示是否正确。
- **数据标注**：标注图片元素供后续 AI 识别。
- **元素查找策略**：支持控件文本、ID、Name、Tag、Type、XPath 六种属性。
- **步骤配置项**：当找到多个（找不到/选第几个）、超时时间（全局/自定义）、前置时间。

### 浏览器操作

> 来源：http://test.pro.testin.cn/docs/web/browser_operation/

- **访问 URL**：加载待测网页；配置项含输入 URL、使用变量（数据驱动访问不同 URL）、证书验证、设置参数。
- **前进/后退/刷新**：页面导航。
- **清空 Cookie**：保护隐私、解决旧 Cookie 加载问题。
- **关闭页签**：浏览器多页签时关闭页签。

### 浏览器多窗口

> 来源：http://test.pro.testin.cn/docs/web/browser_multi_terminal/

录制时支持同时打开两个浏览器窗口，数据独立不互通（可分别登录不同账户）。

- **适用场景**：不同网站并行操作（如客户端申请开户 + 后台审核）。
- **步骤**：打开浏览器窗口（暂仅支持一个自定义窗口，与默认窗口数据隔离）、切换浏览器窗口（以窗口名为标识）、关闭浏览器窗口（仅支持关闭新开窗口）。
- 默认使用无痕模式。
- **常见问题**：暂仅支持开一个新窗口；子脚本打开窗口回放失败需手动切回默认浏览器；改窗口名会同步修改用到该名称的步骤；删除「打开浏览器窗口」步骤后需先用「关闭浏览器窗口」关掉已开窗口。

### 全表校验（Web）

> 来源：http://test.pro.testin.cn/docs/web/table_check/

一次性获取界面表格全部内容并与预期比较，迅速判定表格正确性。详细说明见 PC 侧 GUI表格数据全链路校验。

### 浏览器安装及设置

> 来源：http://test.pro.testin.cn/docs/web/install/

首次使用需 Web 测试机环境初始安装（企业客户已默认配置完成）。

- **安装浏览器**：Windows64（Chrome 120.0.6099.216 / FireFox 107.0，驱动放到 selenium-runner.properties 配置路径）；Linux（信创环境，银河麒麟等，以 FireFox 为例，解压 tar.bz2 到 /opt、创建软链接、装 geckodriver）；Mac（Safari 开发菜单勾选「允许远程自动化」）。
- **初始化设置**：分辨率设置为必配项（user-mapping.xml / selenium.runner.properties）。
- **其他设置**：指定浏览器版本（browser.properties 的 driver.path / app.path）、关闭无痕模式（profile.path / profile.name）、浏览器缩放比例（默认 100%）、IE 浏览器设置（去保护模式、IE11 BFCACHE 注册表）。

### 浏览器更新设置

> 来源：http://test.pro.testin.cn/docs/web/browserInstall/

浏览器自动更新可能导致 driver 版本不兼容，推荐手动更新。各系统禁止自动更新方式：

- Windows64：Chrome（host 加 `127.0.0.1 update.googleapis.com` / `tools.google.com`）；FireFox（distribution/policies.json 设 DisableAppUpdate）。
- Ubuntu：Chrome（/etc/default/google-chrome 加 repo_add_once=false）；FireFox（apt-mark hold firefox）。
- MacOS：Chrome（chmod 000 ~/Library/Google）；FireFox（about:config 改 app.update.auto=false 或 policies.json）。

## PC 自动化产品

### PC-快速开始

> 来源：http://test.pro.testin.cn/docs/pc/start/

桌面自动化平台整体使用流程：配置环境（可选）→ 录制脚本 → 新建任务 → 查看明细与报告。

- **配置环境（可选）**：同 Web（UI 测试环境 / T2 协议）。
- **录制脚本**：选设备 → 应用操作/启动应用打开应用 → 编写脚本（切换/关闭应用、关闭进程、变量、三方脚本）；内嵌浏览器场景见内嵌浏览器。
- **新建任务**：任务管理页点「开始测试」，添加脚本、选桌面终端、定义执行方式/重测次数/数据源/执行环境。
- **任务明细与报告**：同 Web。

### PC-任务提测

> 来源：http://test.pro.testin.cn/docs/pc/task/

与 Web 任务提测基本一致（创建任务/选择脚本/选择终端/完善测试信息/执行策略/提交/定时），区别在终端选择：

- **选择执行终端**：选择桌面终端。若勾选一个设备会同时勾选另一个，检查是否为克隆机器（硬件识别一致导致桌面 ID 一致），可在 localconfig.ini 加 `useAccountIdAsPcId=true`（需重启上位机）。

### 应用操作（PC）

> 来源：http://test.pro.testin.cn/docs/pc/script_system/

对桌面应用启动、切换、关闭应用、关闭进程。

- **启动应用**：选择待测应用（系统自动获取已安装程序）；绿色免安装应用可「创建快捷方式」或「填写应用启动路径」；配置项含应用名称、应用路径、实例名称（多实例区分）、启动参数（如 Chrome 的 --headless / --incognito 等）。
- **切换应用**：把指定应用实例切到前端（暂仅 Windows），靠实例名称区分不同实例。
- **关闭应用**：安全退出程序（区别于关闭进程）。
- **关闭进程**：直接强制关闭进程（可能丢数据，如写库场景）；配置项含进程名称、找不到进程时是否返回错误（默认报错）。

### 内嵌浏览器

> 来源：http://test.pro.testin.cn/docs/pc/script_browser/

适用于客户端内嵌浏览器的场景，连接内嵌浏览器以 Web 自动化方式操作。依赖 Python 环境。

- **支持框架**：Chromium Embedded Framework (CEF)。
- **Chrome 内嵌浏览器配置**：selenium.runner.properties 配 webview.browser.path，驱动路径格式「浏览器名称\版本号\Driver\驱动文件」。
- **连接前置信息**：远程调试端口（询问开发）、版本号（chrome://inspect）、URL 唯一标识（开发提供或逐个获取）、加载 URL（localhost:端口）。
- **连接浏览器**：选择浏览器类型/版本 + 端口号，是后续所有操作前提。
- **切换页签**：多内嵌页面时明确指定要操作的页面（Web 页签名称 + URL 唯一标识）。
- **前进/后退/刷新/清空 Cookies**：页内操作。

### GUI表格数据全链路校验

> 来源：http://test.pro.testin.cn/docs/pc/table_check/

一次性获取界面表格全部内容并与预期比较（如股票活跃度分析表的证券代码/买入额/卖出额）。

- **获取期望内容**：数据库 SQL 查询、HTTP 接口请求（JSON 数组或 JSONPath 提取）、Python 脚本处理（多接口/多 SQL 需处理时）。
- **获取表格显示内容**：复制方式（右击复制/CTRL+C，CSV 转数组，优先）、导出文件方式（导出 CSV 读文件）、AI/控件方式（表格赋值，可框选目标表格）。
- **表格内容检查**：选择期望内容数组变量、界面表格内容数组变量，设置检查规则（匹配条件支持等于/数值等于/包含；期望内容用 getVal(字段名) 或表达式；常用函数 getEnum(f,e)、getVal(f)）。
- **测试步骤调试/报告**：回放显示检查结果，失败内容红色背景定位问题；报告显示检查结果、原始/处理后期望、界面表格内容。
