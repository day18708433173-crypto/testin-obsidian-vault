# 前端架构

## 工程形态

`testin-api-frontend` 是私有云主平台的 **iframe 子系统**，没有独立登录页，登录态由主平台注入（见 [登录态与主平台集成](../03-实现逻辑/登录态与主平台集成.md)）。

技术栈（版本全部精确锁定，`save-prefix=''`，升级需格外谨慎）：

| 类别 | 选型 | 版本 |
|---|---|---|
| 框架 | Vue | 3.2.41 |
| 语言 | TypeScript | 4.6.4 |
| 构建 | Vite | 3.2.0 |
| UI | Element Plus | 2.2.19 |
| 状态 | Pinia | 2.0.27 |
| 路由 | vue-router | 4（**hash history**） |
| HTTP | axios | 1.1.3 |
| 代码编辑 | vue3-ace-editor / ace-builds | 2.2.2 / 1.12.5 |
| 表格数据编辑 | handsontable（数据集） | 12.3.1 |
| JSON 展示 | vue-json-viewer | 3 |
| 图表 | echarts | 5.4.1 |
| 文档 | vitepress | 1.0.0-alpha.61（`docs/` 目录） |

> 构建目标 **chrome71**（`@vitejs/plugin-legacy` + 显式 polyfills 列表，见 `vite.config.ts`）——低版本浏览器兼容是硬约束，写新语法/新 API 前要确认已被 polyfill 或转译覆盖。

## 目录结构

```
src/
├── api/                # API 函数层，一个模块一个文件（case.ts、task.ts、env.ts...）
├── assets/
├── components/
│   ├── RequestParameters/  # ★ 请求编辑核心：请求头/体/前置后置/断言/变量，
│   │                       #   覆盖 HTTP、Dubbo、TCP、WebSocket
│   └── Response/           # 响应展示
├── directives/permission/  # v-auth 指令 + authKey 常量（const.ts）
├── layouts/
├── router/               # 路由 + 全局守卫（sid 校验）
├── stores/               # Pinia（permission 等）
├── utils/
│   ├── Http.ts             # ★ 唯一 axios 实例
│   ├── Login.ts            # 主平台登录态接收
│   └── components/         # 公共组件（unplugin-vue-components 自动注册）
├── views/                # 页面，一模块一目录：
│   │                     #   api / script / case / testTask / scheduleTask / testPlan
│   │                     #   envList / dataSet / enum / machine / protocolConfig / t2Config
│   │                     #   report / share / recycleBin / problem / main
├── global.d.ts / vite-env.d.ts  # 全局业务类型（Api、Mock、JsonSchema、JSONValue...）
└── mixin.less            # 全局自动注入的 Less mixin/变量
```

每个 `views/<模块>/` 通常是 `index.vue`（入口）+ `components/` + `config.ts`（该模块表格列/搜索项配置）。README 里的目录树已过时，以实际 `src/views/` 为准。

## 关键机制速览

- **HTTP 层**：唯一 axios 实例在 `src/utils/Http.ts`，baseURL 是相对路径 `api/v1`（无前导 `/`）；拦截器自动注入 `projectId` / `sid` / `userId` 与 `Sid` / `projectId` 请求头；`code === 200` 成功。详见 [前端HTTP层与响应约定](../03-实现逻辑/前端HTTP层与响应约定.md)。
- **权限两层**：路由级 `meta.authKey` + 元素级 `v-auth`，详见 [权限体系](../03-实现逻辑/权限体系.md)。
- **编辑锁**：rename/copy/delete/save 前统一调 `checkLockedByApi`，详见 [编辑锁机制](../03-实现逻辑/编辑锁机制.md)。
- **组件自动注册**：`src/utils/components/` 由 `unplugin-vue-components` 扫描注册，Element Plus 由 `ElementPlusResolver` 按需引入；`components.d.ts` / `auto-imports.d.ts` 是生成文件，**不要手改**。
- **别名**：`@` → `src`；Less 全局自动注入 `src/mixin.less`。

## 列表页标准组合

```
┌──────────────────────────────────────────────┐
│ TreeList(模块树) │  TableSearch(搜索)         │
│                  ├──────────────────────────│
│                  │  el-table + ApiPagination │
│                  │  （列用 template #default │
│                  │   取值，不要用 prop）      │
└──────────────────────────────────────────────┘
弹窗: CommonDialog    执行入口: RunDialog
```

> **el-table-column 不要用 `prop` 取值**（element-plus 在低版本浏览器的 bug，值不显示），必须：
> ```vue
> <el-table-column label="请求路径">
>   <template #default="{ row }">{{ row.path }}</template>
> </el-table-column>
> ```

## 构建与验证

```bash
pnpm i          # 必须 pnpm（README 明确要求）
pnpm dev        # 端口 3001，/api/v1 代理到 http://api-test.pro.testin.cn
pnpm build      # 三步：vitepress build docs && vue-tsc && vite build
pnpm lint:fix
```

- **没有测试运行器**，验证靠 `pnpm build`（含 vue-tsc 类型检查）+ dev 页面自测。
- CI（`.workflow/*.yml`）用 node 14 跑 `npm install && npm run build`，产物取 `./dist`。
- 构建产物文件名按**构建时间戳目录**输出（`YYYYMMDDHHmm/[name]-[hash].js`，见 `vite.config.ts` 的 `getNowDate()`），用于 CDN/缓存隔离——不要改成固定 `assets/` 路径。
- manualChunks 把 element-plus、ace-builds 单独拆 chunk，其余 node_modules 进 vendor。
