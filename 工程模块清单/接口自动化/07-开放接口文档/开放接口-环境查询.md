# 开放接口-环境查询

> 查询项目下的测试环境列表。环境的业务含义见 [环境与配置管理](../01-产品功能/环境与配置管理.md)。

## POST /open/env/list

查询指定项目下的全部环境，按更新时间倒序返回。

### 请求

| 项 | 值 |
|---|---|
| 方法 / 路径 | `POST /open/env/list` |
| Content-Type | `application/json` |
| 鉴权 | `Sid` 请求头（见 [开放接口总览](开放接口总览.md)） |

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| thirdProjectId | string | **是** | 项目 ID（主平台项目 ID）。为空报参数校验错误 |

**请求示例：**

```bash
curl -X POST 'http://<host>/open/env/list' \
  -H 'Content-Type: application/json' \
  -H 'Sid: <sid>' \
  -d '{"thirdProjectId": "1"}'
```

### 响应

`R` 包装（`code === 0` 成功），`data` 为环境对象数组：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 环境 ID（后续 `task/create`、`Task.run` 的 `envId` 用这个） |
| name | string | 环境名称 |
| projectId | string | 所属项目 |
| domain | string | 默认域名/主机 |
| config | string | 环境全量配置（**JSON 字符串**，含各协议配置项） |
| status | int | 启用状态：**0=启用，1=禁用**（注意是反的） |
| maintainer | string | 维护人 |
| platformId | string | 主平台环境 ID（与主平台环境映射） |
| description | string | 描述 |
| createTime / updateTime | long | 毫秒时间戳 |

**响应示例（节选）：**

```json
{
  "code": 0,
  "msg": "成功",
  "data": [
    {
      "id": "2c4eb367-cb79-4fc5-9638-6d10bd963b6c",
      "name": "测试环境",
      "projectId": "1",
      "domain": "http://10.0.0.1:8080",
      "config": "{\"httpConfig\":{...},\"databaseConfig\":[...]}",
      "status": 0,
      "maintainer": "zhangsan",
      "platformId": "100",
      "description": "日常联调环境",
      "createTime": 1690000000000,
      "updateTime": 1690100000000
    }
  ]
}
```

### 注意事项

1. 返回的是项目下**全部环境**（含已禁用的，`status=1`），不做过滤；触发执行时应选用启用状态的环境。
2. `config` 是字符串形式的 JSON，需要二次解析；结构与环境配置页的配置项对应（见 [环境与配置管理](../01-产品功能/环境与配置管理.md)）。
3. 逻辑删除的环境（界面上已删除）不会出现在结果里。
4. 典型用法：CI 流水线启动时先调本接口按名称找到目标环境的 `id`，再传给执行类接口。
