# 开放接口-脚本查询

> 脚本（可执行的请求实例）的目录树、列表与参数查询。脚本的业务含义见 [脚本管理](脚本管理.md)。三个端点通常配合使用：`dirList` 拿目录树 → `scriptList` 按目录分页找脚本 → `scriptParams` 看脚本绑定了哪些数据参数。

## POST /open/script/dirList

查询项目下的**脚本目录树**（模块树中类型为 SCRIPT 的部分）。

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| thirdProjectId | string | **是** | 项目 ID |

**响应（`R` 包装）**：`data` 为目录树节点数组，树形嵌套：

| 字段 | 类型 | 说明 |
|---|---|---|
| scriptDirId | string | 目录 ID |
| parentDirId | string | 父目录 ID（根节点为 null） |
| name | string | 目录名 |
| children | array | 子目录（同结构递归） |

```bash
curl -X POST 'http://<host>/open/script/dirList' \
  -H 'Content-Type: application/json' -H 'Sid: <sid>' \
  -d '{"thirdProjectId": "1"}'
```

```json
{"code": 0, "msg": "成功", "data": [
  {"scriptDirId": "bbeb5d21-...", "parentDirId": null, "name": "支付模块",
   "children": [{"scriptDirId": "cc12...", "parentDirId": "bbeb5d21-...", "name": "下单", "children": []}]}
]}
```

## POST /open/script/scriptList

分页查询脚本。传目录 ID 时**包含其所有子目录**下的脚本。

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| thirdProjectId | string | **是** | 项目 ID |
| scriptDirId | string | 否 | 目录 ID（来自 dirList）；不传则查全部目录 |
| page | int | **是** | 页码，最小 1 |
| pageSize | int | **是** | 每页条数，最小 1 |
| scriptName | string | 否 | 按脚本名模糊过滤 |

**响应**：`data` 为分页对象：

| 字段 | 类型 | 说明 |
|---|---|---|
| listObject | array | 脚本对象列表（见下） |
| itemCount | long | 总条数 |
| pageCount | long | 总页数 |

脚本对象主要字段：`id`、`name`、`protocol`、`method`、`path`、`status`、`tags`、`scriptNumber`（脚本编号）、`moduleId`、`interfaceId`（关联接口）、`scriptType`（1功能 2空 3性能）、`createUserName`、`updateTime` 等。

```bash
curl -X POST 'http://<host>/open/script/scriptList' \
  -H 'Content-Type: application/json' -H 'Sid: <sid>' \
  -d '{"thirdProjectId": "1", "scriptDirId": "bbeb5d21-...", "page": 1, "pageSize": 20}'
```

## POST /open/script/scriptParams

批量查询脚本**绑定的数据集参数**（键值对列表）——执行前想知道脚本会带哪些变量时用它。

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| thirdProjectId | string | **是** | 项目 ID |
| scriptIds | array&lt;string&gt; | 否 | 脚本 ID 列表 |

**响应**：`data` 为数组：

| 字段 | 类型 | 说明 |
|---|---|---|
| scriptId | string | 脚本 ID |
| paramList | array | 参数键值对 `[{"k": "变量名", "v": "变量值"}]` |

```json
{"code": 0, "msg": "成功", "data": [
  {"scriptId": "cea7a127-...", "paramList": [{"k": "userId", "v": "1001"}, {"k": "amount", "v": "99.5"}]}
]}
```

### 注意事项

1. **paramList 只来自脚本绑定的数据集**：脚本没绑数据集时 `paramList` 为空（不是脚本里定义的全部变量）。
2. `scriptParams` 对不存在的脚本 ID **静默跳过**（结果里直接没有这一项），不报错。
3. 数据集参数取自数据行首列非空的行；列名对应不上的值会被丢弃（详见 [数据集与数据枚举实现](../03-实现逻辑/数据集与数据枚举实现.md)）。
4. `scriptList` 的 `page`/`pageSize` 从 1 开始且有非空校验，传 0 或缺失会报参数校验错误（`10005`）。
