# 快速上手指南

## 第一周目标

1. 把两个工程跑起来（前端 dev + 后端服务端）；
2. 读懂 [任务执行链路](../03-实现逻辑/任务执行链路.md)——这是全平台的主干；
3. 按 [功能总览](功能总览.md) 点一遍测试环境页面，把页面和代码模块对上号。

## 工程获取与环境要求

| 工程 | 路径 | 环境要求 |
|---|---|---|
| 后端 | `api-test/testin-api-backend` | JDK 1.8 + Maven（无 mvnw），依赖走阿里云 mirror |
| 前端 | `api-test/testin-api-frontend` | Node（CI 用 14）+ **pnpm**（必须，README 明确要求） |

两个目录各自是独立 git 仓库，git 操作要带 `-C <子项目路径>`。

## 跑通前端（10 分钟）

```bash
cd testin-api-frontend
pnpm i
pnpm dev        # http://localhost:3001，/api/v1 已代理到 http://api-test.pro.testin.cn
```

- 页面是 iframe 子系统，直接访问根路径会因缺 `sid` 跳 `/unauthorized`——正常开发从主平台入口跳进，或在 URL 上补 `?sid=...&projectId=...`（细节见 [登录态与主平台集成](../03-实现逻辑/登录态与主平台集成.md)）。
- 验证改动靠 `pnpm build`（含 vue-tsc 类型检查）+ dev 页面自测，**没有单元测试运行器**。

## 跑通后端（本地服务端）

```bash
cd testin-api-backend
mvn package            # 产物在 deploy/（不是 target）
mvn spring-boot:run    # 或按 startup.sh 的 classpath 方式启动
```

- 服务端端口 8526；`spring.profiles.active` 默认 `test`，本地切 `dev`。
- 需要可用的 MySQL 与 Redis（profile yml 里的地址，可用环境变量覆盖）。
- 想让前端直连本地后端：改 `vite.config.ts` 的 proxy target 为 `http://127.0.0.1:8526`，**同时取消注释 `rewrite: path => path.replace(/^\/api\/v1/, '')`**（后端没有 `/api/v1` 前缀，生产环境由网关剥离）。

## 跑通执行端（可选，验证执行链路时）

```bash
mvn package -f runnerPom.xml
java -cp ... cn.testin.runner.RunnerApplication <HTTP_PORT> <REDIS_HOST> <REDIS_PORT> <REDIS_DB> <REDIS_PASSWORD|"EMPTY_PASSWORD">
```

详见 [执行端Runner详解](../03-实现逻辑/执行端Runner详解.md)。本地验证完整执行链路的最小组合：MySQL + Redis + 服务端 + 一台执行机。

## 推荐阅读顺序

```
第 1 天  产品概述 → 功能总览（点页面）
第 2 天  总体架构 → 后端双形态架构 → 前端架构
第 3 天  任务执行链路 → Redis通信与Key设计 → 执行端Runner详解
第 4 天  登录态与主平台集成 → 前端HTTP层与响应约定 → 权限体系 → 编辑锁机制
第 5 天  按工作内容选读 04-复杂功能细节 专题
```

## 第一个 PR 怎么下手

| 任务类型 | 入口文档 |
|---|---|
| 加一个前端页面/列表 | [前端开发指南](前端开发指南.md) + 抄一个 `src/views/` 现有模块 |
| 加一个后端接口 | [后端开发指南](后端开发指南.md) + 抄一个现有 controller |
| 改执行逻辑 | [任务执行链路](../03-实现逻辑/任务执行链路.md) + [JMX生成与解析](../03-实现逻辑/JMX生成与解析.md)，**注意两端同改同发** |
| 修 bug | 先查 [开发约定与常见坑](../05-常见问题/开发约定与常见坑.md) 和对应 FAQ 文档 |

## 三条铁律

1. **不要把父目录 testin-core / testin-frontend 那套约定带进来**（那边 `/openapi/v3`、`code===0`、Arco Design；这边 `/api/v1`、`code===200`、Element Plus）。
2. 改 `JmeterRunRequestDTO`、`RedisKeyUtil` 等跨端协议时，**服务端和执行端两个产物都要重新构建部署**。
3. 提交前前端跑 `pnpm build`、后端跑 `mvn package`，都要绿。
