# 后端开发指南

> 工程：`api-test/testin-api-backend`（Java 1.8 / Spring Boot 2.3.1）。先读 [后端双形态架构](../02-技术架构/后端双形态架构.md) 建立整体认识。

## 分层与代码位置

```
controller/   REST 入口，@RequestMapping("/case") + @GetMapping("/list") 风格
service/      业务层（execution/ jmeter/ nosql/ plan/ openApi/ 子包）
mapper/       MyBatis mapper 接口 + XML（XML 与接口同目录！）
dao/          DO；entity/ 放实体与 DTO
commons/      constants/（枚举常量，总入口 ApiTestConstants）utils/ Response/ exception/
```

## 新增一个后端功能的标准流程

1. **DTO/entity**：放 `entity/`，DO 放 `dao/`。
2. **mapper 接口 + XML**：放 `mapper/` 下同包位置；分页用 PageHelper。
3. **service 接口/实现**：业务逻辑层；常量进 `commons/constants/`（尽量并进现有枚举文件，参考 `ApiTestConstants` 的组织方式）。
4. **controller**：`@RequestMapping("/<资源>")` 风格，无统一前缀；返回体沿用 `commons/Response/` 的包装（成功码 200）。
5. **权限**：受控功能在 `KeyInterceptor` 的 configKey 体系里登记，并与前端 `authKey` 对齐（见 [权限体系](../03-实现逻辑/权限体系.md)）。
6. **锁**：资源有 rename/copy/delete/save 语义的，接入 [编辑锁机制](../03-实现逻辑/编辑锁机制.md)。
7. **定时任务**：复杂/可触发的挂 xxl-job handler（`xxljob/` 目录），简单轮询用 `@Scheduled`（`schedule/` 目录）——取舍见 [定时调度体系](../03-实现逻辑/定时调度体系.md)。

## 约定清单

### JSON
- 三套并存：fastjson（主）、org.json、gson。**新代码一律 fastjson**。
- `Application.main` 第一行是 `ParserConfig.getGlobalInstance().setSafeMode(true)`（漏洞修复），**不要绕过 autoType 限制**，不要往 fastjson 反序列化里放不可信类型。

### 日志
- 统一 log4j2（`resources/log4j2.xml`）；logback 已排除，jcl/jul/slf4j/1.2-api 桥全部指向 log4j2。
- 业务代码用 `commons/utils/LogUtil` 或 lombok `@Slf4j`。

### 配置
- profile 制：`application.yml` + `application-dev/test/prod.yml`，默认 active=test。
- 环境差异化配置写成 `${ENV_VAR:default}` 形式（如 `${TESTINPRO_DB_HOST:10.33.84.100}`），容器部署靠环境变量注入。
- 主平台地址统一写 `http://openapi.pro.testin.cn`——启动脚本会全局 sed 替换成 `${OPENAPI_URL}`。

### 依赖管理
- 新依赖先想**类加载顺序**：lib 目录按文件名字典序加载，与 JMeter 冲突的包靠命名靠前优先（system scope jar 的约定，见 [后端双形态架构](../02-技术架构/后端双形态架构.md)）。
- easyexcel 已排除 `poi-ooxml-schemas`（与 poi 5.2.3 自带 lite 冲突），不要再引回。
- 测试框架可用但 surefire 默认 skip：`mvn test -DskipTests=false -Dtest=ClassName`。

### 数据库
- mapper XML 与接口**同目录**放 `src/main/java/cn/testin/mapper/` 下，不要建 `resources/mapper/`。
- MyBatis Generator：`resources/generatorConfig.xml`，`mvn mybatis-generator:generate`。
- `map-underscore-to-camel-case: true`，SQL 列名下划线、Java 字段驼峰。

## 跨端修改红线

| 修改对象 | 影响 | 要求 |
|---|---|---|
| `JmeterRunRequestDTO` 等传输 DTO | 服务端↔执行端序列化协议 | 两端同改，两个 pom 产物同时重新构建部署 |
| `RedisKeyUtil` 的 key 结构 | 任务队列/载体寻址 | 同上；灰度期考虑新旧 key 兼容 |
| 执行结果结构 | 报告展示链路 | 前后端报告渲染同步评估 |
| controller 路径/出入参 | 前端 `src/api/` | 两端联调；成功码保持 200 体系 |
