# 产品概述

## 这是什么

接口自动化测试平台（api-test）是面向测试/开发团队的**接口级自动化测试平台**，作为私有云主平台的一个子系统运行（以 iframe 嵌入，账号/项目/权限都继承自主平台）。它解决四类问题：

1. **接口资产管理**：把分散的接口定义（HTTP、Dubbo、gRPC、TCP、WebSocket、FIX、T2 等协议）统一登记、按模块树组织，可一键导入 Swagger 等外部定义。
2. **用例编排**：把接口/脚本组装成带前置后置处理、断言、变量传递、条件/循环控制的测试用例，支持数据集驱动。
3. **批量执行与调度**：测试任务（手动/定时）驱动用例在远程执行机上批量运行，测试计划做跨迭代组织与跟踪。
4. **结果闭环**：报告聚合展示、失败原因分析、免登分享协作、回收站防误删。

## 用户与使用场景

| 角色 | 典型场景 |
|---|---|
| 测试工程师 | 录入接口 → 编排用例 → 挂定时任务 → 看报告、分析失败原因 |
| 开发工程师 | 单接口调试（"调一下"）、用 Mock 做替身、造测试数据 |
| 测试负责人 | 看项目概览与用例分析、跟踪测试计划进度 |
| CI/CD 流水线 | 通过开放接口触发任务、拉取报告做质量门禁 |

## 典型使用动线

```mermaid
graph LR
    A[维护接口<br/>导入/手工录入] --> B[编写脚本<br/>填参数/断言]
    B --> C[编排用例<br/>步骤+控制器+数据集]
    C --> D[组装任务<br/>选环境/执行机]
    D --> E[执行<br/>手动/定时]
    E --> F[查看报告<br/>分析失败]
    F -->|发现问题| C
    F -->|分享协作| G[生成分享链接]
```

## 与主平台的关系

- 本平台**没有自己的账号体系**：用户、项目、权限都来自私有云主平台，在主平台登录后进入本平台即可直接使用。
- 数据按**项目隔离**：切换主平台项目后，本平台内的接口、用例、任务等全部随之切换。
