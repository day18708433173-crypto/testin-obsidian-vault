# 平台配置 OpenAPI 接口文档

> 平台配置（real-cfg）服务全部 HTTP 接口的 Swagger 风格汇总。目标服务 `testin-aio-real-cfg:8080`，网关 mkey `realcfg` / `env`。
>
> 数据来源：[01-API路由映射表](../01-API路由映射表.md)（db_mcfg 库 view_role_api 实时数据）+ 本地代码仓 `D:\programfile\major\java\testin\workspace\real\real-cfg`（分支 `syy.release.z7.8.1.0`）。
>
> 转发模式标记：🟢 V1 原生（ApiServlet 按 `action`/`op` 反射调用）；🔵 V3 透传（Spring MVC Controller）。

## 通用返回结构

- **V1（ApiServlet，action/op）**：`{"code": 0, "message": "...", "data": {...}}`，`code=0` 表示成功。`data` 内常用子字段：
  - `result`（Integer）：写操作影响行数或 `1/0` 结果标志
  - `objInfo`（JSONObject）：单条查询结果
  - `list`（JSONArray）：列表结果
  - `page` / `pageSize` / `totalRow` / `totalPage`（Integer）：分页信息
- **V3（Spring MVC）**：`ResponseResult<T>` = `{"code": 0, "msg": "...", "data": {...}}`（成功 code 取自 `CommonConstants.SUCCESS_CODE`）。`data` 常见类型：
  - `BaseResponseDTO`：`{"result": Integer}`
  - `PageInfoList<T>`：`{"totalRow", "totalPage", "pageSize", "page", "list"}`
  - `ResultListResponseDTO<T>`：`{"list": [...]}`
  - 具体 DTO / `List<T>`

### `mcfg.AppCfg.add` 新增接入方
| 属性 | 值 |
|---|---|
| 转发模式 | 🟢 V1 原生 |
| HTTP 方法 | POST |
| 路径 | ApiServlet?action=mcfg&op=AppCfg.add |
| 鉴权 | needLogin=0 |

**返回参数**（data）：
| 字段 | 类型 | 说明 |
|---|---|---|
| result | Integer | 1 成功 / 0 失败 |
