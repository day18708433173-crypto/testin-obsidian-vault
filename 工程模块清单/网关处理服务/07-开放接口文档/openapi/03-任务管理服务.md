# 任务管理服务 OpenAPI 接口文档

> 代码仓库：`real-task`（分支 `syy.release.z7.8.1.0`），Controller 位于 `cn.testin.controller.task` 包。
> 网关路由：模块 `real_task` → `http://testin-aio-real-task:8080`。全部为 🔵 V3 透传（passThroughType=1）。

## 通用返回结构

所有接口统一返回封装 `ResponseResult<T>`（对应路由表口径中的「BaseResponseDTO」），JSON 结构为：

| 字段 | 类型 | 说明 |
|---|---|---|
| code | Integer | 状态码，0 为成功（`CommonConstants.SUCCESS_CODE`） |
| msg | String | 提示信息 |
| data | T | 业务数据，类型随接口而定 |

分页类接口 `data` 为 `BasePageListResponseDTO<T>`：

| 字段 | 类型 | 说明 |
|---|---|---|
| page | Integer | 当前页 |
| pageSize | Integer | 每页大小 |
| totalPage | Integer | 总页数 |
| totalRow | Long | 总行数 |
| list | JSONArray | 当前页数据列表 |

## 通用约定

- 所有接口 `needLogin=1`，网关侧需携带 `sid`；HTTP 模块还需 `apikey` + `mkey`。
- 请求体均为 JSON（`application/json`），GET 接口参数为 query 参数；标注 `@UnderlineToCamel` 的 GET 接口支持下划线命名（如 `task_execute_record_id`）自动转驼峰绑定。
- 「必填」依据：`@RequestBody` DTO 上的 `@NotNull/@NotBlank` 注解、方法上的 `@Valid`，以及 Controller 内 `checkProjectId()/checkUserId()`（空则抛参数异常）等显式校验。
- 路径变量以代码实际变量名标注（如 `{task_template_id}`），网关路由表中的 `{param1}` 为占位符。
