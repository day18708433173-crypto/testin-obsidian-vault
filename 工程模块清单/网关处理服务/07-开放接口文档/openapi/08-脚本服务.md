# 脚本服务 OpenAPI 接口文档

> 目标服务：`testin-aio-filesystem:8080`，模块 mkey：`script` / `apppackage` / `suite` / `file`。
> 数据来源：[01-API路由映射表](../01-API路由映射表.md)（db_mcfg 库 `view_role_api`）+ 代码仓 `D:\programfile\major\java\testin\workspace\filemanagement`（分支 `syy.release.z7.8.1.0`）。
> 对应接口索引：[脚本服务 接口索引](../../../脚本服务/07-开放接口文档/00-模块索引.md)。

## 通用返回结构

- **V1（ApiServlet，`action`/`op`）**：`{"code": 0, "message": "...", "data": {...}}`，`code=0` 表示成功；`data` 内字段键名由 `ApiResponse` 常量定义：`result`（受影响行数/结果值）、`object`（单对象）、`list`（列表）、`page`、`pageSize`、`totalRow`、`totalPage`。
- **V3（Spring MVC，`@RestController`）**：统一 `ResponseResult<T>`，形如 `{"code":0,"message":"...","data":{...}}`；分页接口 `data` 为 `PageInfoList<T>`（含 `list`、`total`、`page`、`pageSize`）。

## 转发模式说明

| 标记 | 模式 | pass_through_type | 说明 |
|---|---|---|---|
| 🟢 | V1 原生 | 0 | `api_action` 为短格式（`script`、`suite`、`form`、`tab`、`voice`、`thirdparty`、`ai`、`app`、`file`） |
| 🔵 | V3 透传 | 1 | `api_action` 为 URL 格式，直连 Spring MVC 控制器 |
| 🟡 | V3→V1 转换 | 0 | URL 格式 + `special_api_action`/`special_api_op` 非空，转成 V1 方法 |
