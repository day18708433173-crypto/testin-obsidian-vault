## 转发模式说明

| 标记 | 含义 | 判定依据 |
|---|---|---|
| 🟢 V1原生 | action/op JSON 模式（ApiServlet `/*`） | `pass_through_type=0` 且 `api_action` 为包名（非 `/` 开头） |
| 🔵 V3透传 | RESTful 直通转发 | `pass_through_type=1` |
| 🟡 V3→V1转换 | RESTful URL 转 V1 action/op | `pass_through_type=0` 且 `special_api_action`/`special_api_op` 指定 V1 目标 |

网关 V3 URL 规则：`/v3/{mkey}{api_action}`，`/v3` 前缀剥除后与 Controller `@RequestMapping` 精确匹配。

## 通用返回结构

**V1（action/op JSON 模式）**：`{code, message, data}`，`code=0` 成功（部分接口为 `{error_code, msg, data}`）。

**V3（RESTful，ResponseResult 包装）**：

| 包装类 | 结构 |
|---|---|
| `ResponseResult<T>` | `{ code, msg, data }`，`code=0` 成功 |
| `BaseDataResultDTO` | `{ Long result }`（影响行数/主键） |
| `BaseResultDTO` | 通用结果对象 |
| `BaseListResponseDTO<T>` | `{ list }` |
| `BasePageListResponseDTO<T>` | `{ page, pageSize, totalPage, totalRow, list }` |
| `BaseList<T>` | `{ list }`（ProjectController 使用） |
