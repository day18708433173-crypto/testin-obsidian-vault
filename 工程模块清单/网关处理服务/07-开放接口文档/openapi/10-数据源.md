# 数据源 OpenAPI 接口文档

> 代码仓库：`datasource-manage`（分支 `syy.release.z7.8.1.0`）
> 目标服务：`http://testin-aio-datasource-manage:8080/openapi`
> 网关模块：V1 原生走 `mkey=datasource-manage`（module_id=1003）；V3 透传走 `mkey=datasource`（module_id=1005）。
> 说明：db_mcfg 中 V3 透传接口归属的模块 `mkey` 为 `datasource`（非 `datasource-manage`），故本文 V3 路径统一写为 `/v3/datasource/...`；与《01-API路由映射表》10 节标题名 `datasource-manage` 略有差异，以 db_mcfg 为准。

## 通用返回结构

### V1 原生（action/op 模式）

```
{ "action": "source", "op": "SourceConfigCtrl.add", "code": 0, "msg": "成功", "data": { ... } }
```

- 顶层字段：`action`、`op`（回显）、`code`（0 成功，非 0 失败，见 `CommonCode`）、`msg`、`data`。
- `data` 节点按结果类型变化（见 `GenericBaseService.packageResult`）：
  - 返回 List → `data.list: [...]`
  - 返回分页 IPage → `data.list` + `data.page/pageSize/totalRow/totalPage`
  - 返回单个对象/布尔 → `data.data: <对象>`（注意：单对象会再包一层 `data`）
  - 少数方法手工组装：`getById` → `data.objInfo`；`selectSourceConfig` → `data.result`；`batchDeleteInstanceTable`/`batchReplaceVarValue` → `data.successCount/failCount`
- 请求业务参数放在请求体 `data` 节点（解析后即 `ApiRequest.reqjson`），与 `apikey/mkey/action/op/sid/timestamp` 同级。

### V3 透传（BaseResponseDTO）

```
{ "code": 0, "msg": "成功", "data": { ... } }
```

- 对应 `ResponseResult<T>`：`code`（0 成功）、`msg`、`data`。
- `data` 常见包装：`ResponseListDTO`（`data.list`）、`PageInfoList`（`data.totalRow/totalPage/pageSize/page/list`）、`ResultDTO`（`data.result`）、`ResultListDTO`（`data.list`）。

## 一、SourceConfigCtrl（V1 原生 · 数据源配置管理）

> 类路由 `/source/SourceConfigCtrl`；op = 方法名。全部 needLogin=1。请求参数位于 `data` 节点。

### 新增数据源节点 `source.SourceConfigCtrl.add`

| 属性 | 值 |
|---|---|
| 转发模式 | 🟢 V1 原生 |
| HTTP 方法 | POST（action/op） |
| 路径 | `action=source&op=SourceConfigCtrl.add` |
| 鉴权 | needLogin=1 |
| 说明 | 新增目录/数据源/全局表/实例表/SQL 节点 |

**请求参数**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| name | String | 是 | 名称 |
| type | Integer | 是 | 节点类型：0目录 1数据源 2全局表 3实例表 4SQL管理 5具体SQL |
| parentId | Long | 是 | 父节点 id（根目录传 0） |
| sourceId | Long | 是 | 所属数据源 id（type=1 时先传 0） |
| projectid | Integer | 否 | 项目 id |
| eid | Integer | 否 | 企业 id |
| sqlId | Long | 否 | 关联 SQL id |
| scriptNo | Integer | 否 | 脚本编号 |
| scriptType | Integer | 否 | 脚本类型 |
| envId / dbAlias / dbConfigId | Integer/String/Integer | 否 | 数据库/环境相关 |
| updateBy | String | 否 | 更新人 |

**返回参数**

| 字段 | 类型 | 说明 |
|---|---|---|
| data.data | SourceConfig | 新增后的节点实体（id/eid/projectId/sourceId/parentId/name/type/sqlId/bind/scriptNo/scriptType/envId/dbAlias/dbConfigId/currentOrder/updateBy/createtime/updatetime/status） |
