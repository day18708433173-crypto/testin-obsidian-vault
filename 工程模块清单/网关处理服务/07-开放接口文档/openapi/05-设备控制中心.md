# 设备控制中心 OpenAPI 接口文档

> 云真机平台控制中心（real-controlcenter）：与上位机（ucom）长连接、设备管理（App/Web/Pc/鸿蒙）、任务下发与结果回报、设备在线统计、设备预约、机柜管理。
> 本文覆盖路由表「## 5. 设备控制中心」全部接口：V1 原生（action/op）、V3 透传（Spring MVC）、V3→V1 转换。字段信息来自代码仓 `real-controlcenter`（分支 `syy.release.z7.8.1.0`），无法从代码确认的字段标注「（代码未确认）」。
> 数据来源：[01-API路由映射表](../01-API路由映射表.md) + [real-controlcenter 模块索引](../../../设备控制中心（real-controlcenter）/07-开放接口文档/00-模块索引.md)。

## 通用返回结构

- **V1（ApiServlet，action/op）**：统一返回 `{"code": 0, "msg": "...", "data": {...}}`，`code=0` 表示成功。
  - `data` 内常用字段：`result`（操作结果/请求 reqid）、`page`/`pageSize`/`totalRow`/`totalPage`/`list`（分页）、`objInfo`（单对象）、`list`（列表）。
  - 注：字段名为 `msg`（代码常量 `ApiResponse.RES_MSG="msg"`），非 `message`。
- **V3（Spring MVC @RestController）**：统一 `ResponseResult<T>`，形如 `{"code":0,"message":"...","data":{...}}`；分页接口 `data` 为 `PageInfoList`（内含 `totalRow`/`totalPage`/`pageSize`/`page`/`list` 等）；单结果包装为 `BaseResponseDTO`（`data` 内为字符串/数字）；列表包装为 `ResultListResponseDTO`（`data.list`）。
- 下文「返回参数」表仅列 `data` 内的字段（V1 为 `data.*`，V3 为 `data.*`），外层 `code`/`msg`（`message`）不再重复列出。
