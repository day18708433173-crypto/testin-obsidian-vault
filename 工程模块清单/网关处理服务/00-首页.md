# 网关处理服务（proxy-openapi）

> 统一 API 网关，对外部请求进行认证、鉴权、校验、拦截与转发，是所有外部调用方的唯一入口。

## 一句话定位

外部系统通过 apiKey/sid/sig 接入 Testin 平台的统一网关，负责身份认证、接口权限校验、请求参数校验/过滤/增强，然后通过 RPC 或 HTTP 将请求代理转发到内部目标服务。

## 核心职责

- **统一认证**：apiKey + timestamp + sid + sig（MD5 排序签名）多因子校验
- **四层鉴权**：McfgApp → McfgModule → McfgApi → McfgRole，配置驱动、实时生效
- **请求编排**：checkJson 校验入参、fieldJson 字段过滤、ignoreJson 字段裁剪、additionalJson 字段增强、bodyRequestFieldReplaceKeys 格式转换
- **双模代理**：RPC（ICE，无 httpHosts 时）与 HTTP 透传（有 httpHosts 时），含 GET query 拼接、multipart/form-data 透传、queryParamKeys/pathPlaceholderParamKeys 转换
- **响应处理**：resultCheckJson 校验出参、responseFieldReplaceKeys 格式转换、ignoreJson 字段裁剪
- **缓存热更新**：Redis pub/sub 订阅 `real.cfg` 和 `usermanager` 频道，配置变更实时刷新 LocalCache
