# 术语表

## A

**apiKey** — 接入应用的唯一标识（32 位字符串），由平台配置服务签发，存入 `mcfg_app.api_key`。每个请求必须携带，网关通过它查找 McfgApp。见 [产品概述](../01-产品功能/产品概述.md)。

**ApiProxyServlet** — V1 网关入口 Servlet，匹配 `/*`，最低优先级（`@Order(2)`），仅处理未被 V2/V3 截获的请求。JSON-RPC 风格，body 内 `action` + `op`。`cn/testin/web/servlet/ApiProxyServlet.java`。

**ApiV3ProxyServlet** — V3 网关入口 Servlet，匹配 `/v3/*` 和 `/openapi/v3/*`，高优先级（`@Order(1)`）。RESTful 全方法，支持路径占位符、query→body 映射、passThroughType=1 透传。`cn/testin/web/servlet/ApiV3ProxyServlet.java`。

**AppConfig** — McfgApp 的行为配置 JSON（`app_config` 字段），包含 `checkIp`（IP 白名单校验）、`checkTimestamp`（时间戳校验）、`checkSig`（签名校验，当前未启用）、`ignoreSid`（跳过 sid 注入）、`onlineUserInfo`（在线用户信息模式）。

## B

**bodyRequestFieldReplaceKeys** — V3 请求编排配置项，在请求发送前重命名 body JSON 的字段名（如驼峰→下划线）。仅 V3 支持。见 [请求响应转换引擎](../04-复杂功能细节/横切-请求响应转换引擎.md)。

**bindEid** — McfgApp 绑定的企业 ID，用于校验用户所属企业与接入应用的一致性（`commAuth` 中比对 `UserOnline.eid` 与 `app.bindEid`）。

## C

**checkKeys** — 请求编排配置项，校验请求 body 中必须存在的字段（支持嵌套路径），缺失则返回 `paraInvalid`。`ApiProxyServlet.handleCheck()`。

**commAuth** — 通用认证鉴权方法，每个 Servlet 版本的 Util 类各有一套：`ApiUtil.commAuth`（V1）、`ApiV2Util.commAuth`（V2）、`ApiV3Util.commAuth`（V3）。执行 apiKey→App→Role→Module→Api 四层校验 + sid 登录态校验 + IP/时间戳检查 + 用户信息注入。

**CORSFilter** — 跨域过滤器（`@Component`），自动为所有响应添加 CORS 头，对 OPTIONS 预检请求直接返回 200。`cn/testin/startup/CORSFilter.java`。

## D

**doPress** — Servlet 的核心处理方法：`ApiProxyServlet.doPress`（V1）、`ApiV3ProxyServlet.doPress`（V3）。内含完整的 preCheckDealRequest → checkRequest → preExecuteRequest → executeRequest → postDealResponse 流水线。

**doPressWithPassThrough** — HTTP 透传方法（`HttpServiceImpl.doPressWithPassThrough`），保留原始 HTTP 方法/headers/query/body 直接转发到目标服务，返回原始响应（含 Set-Cookie、octet-stream）。仅 V3 `passThroughType=1` 时触发。

## F

**fieldKeys** — 请求编排配置项，白名单过滤：只保留响应 JSON 中 `fieldKeys` 列出的字段（支持嵌套对象/数组）。`ApiProxyServlet.handleField()`。

## H

**httpHosts** — McfgModule 的 HTTP 目标地址列表（`;` 分隔多地址），非空时网关走 HTTP 模式转发。每次请求随机取一个地址实现简单负载均衡（`McfgModule.getHttpHost()`）。

**Hundsun 定制** — 恒生客户适配逻辑：请求携带 `hundsunInfo`（productNo/projectId/productName/...），网关通过 `ProjectApi.hengsunCustomize()` 映射为 Testin 内部 sid/projectid/userid。仅 V1 支持（`ApiProxyServlet.conversionRequest()`）。

## I

**ignoreKeys** — 请求编排配置项，黑名单裁剪：从请求 body 或响应 JSON 中删除 `ignoreKeys` 列出的字段。`ApiProxyServlet.handleIgnore()`。

**ignoreSid** — 跳过 sid 用户信息注入的标记。三种触发方式：① McfgApp.appConfig.ignoreSid=1；② mkey 为 `prodatatrans` / `saasdatatrans`（数据同步模块）；③ McfgApi.ignoreSidKeys.infoBySid=1（接口级配置）。

**ICE** — ZeroC ICE（Internet Communications Engine）RPC 框架，网关的 RPC 转发模式底层。Locator 地址在 `iceclient.properties` 中配置。`RpcServiceImpl` 通过 `ApiUtil.doPress(prefixName, json)` 走 ICE 调用。

## L

**LocalCache** — 本地内存缓存（Guava 风格），配置：10 段 × 50000 容量，60 分钟过期，5 分钟清理间隔。存储 McfgApp/McfgModule/McfgApi/UserOnline/Project/Enterprise 等配置数据。`cfg/spring/Spring-LocalCache.xml`。

**LocalCacheServlet** — 缓存管理入口 `/localcache/*`，支持 `?key=...` 参数手动清除指定缓存项。`cn/testin/web/servlet/LocalCacheServlet.java`。

**LockUtil** — 本地锁工具（基于 KEY 对象的 synchronized），用于缓存加载时的双重检查锁，防止并发 RPC 击穿。来自 `real-common` 外部依赖。

## M

**McfgApp** — 网关配置中的"应用"实体，一个 apiKey 对应一个 McfgApp。含应用状态（STATUS_ON/STATUS_OFF）、角色列表、IP 白名单、bindEid、secretKey/ivKey 等。缓存 key：`IAppService.app.{apiKey}`。

**McfgApi** — 网关配置中的"接口权限"实体：定义 action+op（V1）/ url+method（V3）→ 所属模块 + needLogin + protocolConfig（编排规则 JSON）。按 roleId 分组缓存。缓存 key：`IApiService.roleapi.{roleId}`（V1）或 `IApiService.roleapi.v3.{roleId}`（V3）。

**McfgModule** — 网关配置中的"模块"实体：mkey 唯一标识一个后端服务模块。含 rpcPrefixName（RPC 寻址前缀）或 httpHosts（HTTP 地址列表）、模块状态。缓存 key：`IModuleService.module.mkey.{mkey}`。

**McfgRole** — 网关配置中的"角色"实体，通过 McfgRoleApi 中间表关联一组 McfgApi。

**MessageDispatchThread** — Redis pub/sub 消息分发线程，从 BlockingPool 拉取 `NoticeMessage`，通过线程池（核心 5/最大 50）分发给 `MessageHandlerThread` 处理。`cn/testin/schedule/mq/MessageDispatchThread.java`。

## P

**passThroughType** — V3 转发模式标记（protocolConfig 字段）：0 = 走 V3→V1 转换（构建 V1 风格 body），1 = 直接透传原始请求。详细判定见 [多版本入口](../04-复杂功能细节/横切-多版本入口（V1-V2-V3）.md)。

**protocolConfig** — McfgApi 的请求/响应编排规则 JSON 字段，定义了 checkKeys/fieldKeys/ignoreKeys/additionalKeys/resultCheckKeys 等所有编排行为。

## Q

**queryParamKeys** — V3 请求编排配置项，将 URL query 参数映射到 body JSON 字段（支持 Integer/Long/Boolean 类型转换）。仅 V3。`ApiV3ProxyServlet.transformToDataJson()`。

## R

**responseFieldReplaceKeys** — V3 响应编排配置项，在响应返回前递归重命名 JSON 字段名（如非驼峰→驼峰）。仅 V3。

**resultCheckKeys** — V1 响应编排配置项，校验响应 JSON 中必须包含的字段（典型用途：校验 `projectid` 在用户项目列表中）。仅 V1。`ApiProxyServlet.handleCheckResult()`。

**rpcPrefixName** — McfgModule 的 RPC 寻址前缀（如 `RealCfg`、`UserManager`），httpHosts 为空时用于 ICE RPC 路由。

## S

**sid** — Session ID，用户登录态令牌。来源优先级：① header `sid`；② Cookie `authtoken_pro`；③ body `onlineUserInfo`（email+eid→查用户表）；④ body `onlineUserInfo.thirdPartyUserid`（第三方 ID 映射）。

**SigUtil** — MD5 签名工具：递归排序 JSON key + secretKey → MD5。当前作为客户端工具存在，服务端 `commAuth` 中 `checkSig` 配置已读但签名校验未实际接线。

**specialApiAction / specialApiOp** — McfgApi 的特殊字段，用于 V3→V1 转换模式：将 V3 请求的 URL 映射到 V1 风格的 action/op。例如 realtest `/task/share GET` → special: `app.Task.share`。

## U

**UserOnline** — 用户在线信息（会话对象），含 sid/expireTime/eid/userid/username/projectid/userprojectids。通过 `OnlineApi.getUserOnline(sid)` 查询，缓存 key：`IUserService.onlineuser.{sid}`。
