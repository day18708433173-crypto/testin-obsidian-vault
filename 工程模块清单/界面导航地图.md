## 无独立左侧菜单页的服务

这些服务纯后端或由其它页面承载，无专属左侧菜单：

| 服务             | 界面承载方式                      |
| -------------- | --------------------------- |
| 文件管理服务         | 无独立页；上传/解析由脚本录制、App 上传等操作触发 |
| 任务调度服务         | 无独立页；旧链路调度，设备心跳触发匹配         |
| 平台配置（real-cfg） | 无独立页；网关/配置中心，管理台后台配置        |
| 网关处理服务         | 无独立页；所有 `/openapi/*` 请求的入口  |

## 通用布局（每个页面都加载）

每个页面进入时都会调用一批公共接口：`/openapi/v3/user/*`（用户/项目/角色/功能开关）、`/openapi/v3/ControlCenter/device|web/online_count`（在线数）、`/openapi/v3/user/users/online_nums`。页面顶部固定：项目列表、管理中心、帮助文档、在线人数、设备统计、企业管理员姓名、当前项目切换。
